[Singleton Functions](/docs/durable-execution/flow-control/singleton?ref=changelog) is a new Flow Control feature that allows exclusive execution of an Inngest function.

Unlike [Rate Limiting](/docs/durable-execution/flow-control/rate-limiting?ref=changelog) which discard events given a configured time window, Singleton Functions discard events (or cancel runs) only if an execution is already running.

Learn more about Singleton Functions in the [documentation page](/docs/durable-execution/flow-control/singleton?ref=changelog).
