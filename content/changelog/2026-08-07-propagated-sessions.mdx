A run with sessions will now propagate its sessions into runs that it kicks off. Set sessions on just your root run, and then easily see the root run and all child runs together on the Sessions page.

This is especially useful for AI agents and long-running workflows where one user action can fan out into multiple functions. Sessions show run counts, failures, recent activity, and the functions involved for each session.

Read the [Sessions docs](/docs/features/events-triggers/sessions?ref=changelog-propagated-sessions) to start sending sessions.
