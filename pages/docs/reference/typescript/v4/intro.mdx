# TypeScript SDK

> Install the TypeScript SDK, create a client, and find every API it offers.

<Info>
  This is the reference for TypeScript SDK v4. Upgrading from v3? See the [migration guide](/docs/reference/typescript/v4/migrations/v3-to-v4). Apps still on v3 can use the [v3 reference](/docs/reference/typescript/v3/intro).
</Info>

The TypeScript SDK defines durable functions, sends events, and serves your functions from Node.js, Bun, Deno, and edge runtimes. It supports every Inngest feature, including [Realtime](/docs/realtime), [Sandboxes](/docs/sandboxes) (beta), and [Agent Evals](/docs/agent-evals). See [feature support](/docs/sdks#feature-support) to compare it with the other SDKs.

## Install

<CodeGroup>
```shell {{ title: "npm" }}
npm install inngest
```
```shell {{ title: "pnpm" }}
pnpm add inngest
```
```shell {{ title: "yarn" }}
yarn add inngest
```
```shell {{ title: "bun" }}
bun add inngest
```
</CodeGroup>

## Create a client

Create one client for your app. Use it to define functions and send events:

```ts {{ title: "src/inngest/client.ts" }}
import { Inngest } from "inngest";

export const inngest = new Inngest({ id: "my-app" });
```

Next, [create a function](/docs/reference/typescript/v4/functions/create) and [serve it](/docs/reference/typescript/v4/serve) from your app. The [TypeScript quick start](/docs/durable-execution/quick-start/typescript-quick-start) walks through a full example.
