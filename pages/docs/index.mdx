# Introducing Inngest

> Build durable, observable, failure-resistant code with sandboxing, agent evals, and A/B tests built in.

Inngest is the platform for building durable workflows and agents that survive failures, without managing orchestration infrastructure. Write functions in your existing code and add steps. Inngest runs each step, saves its result, and retries failed work from the step that failed.

<WelcomeGrid />

## The Inngest platform

Durable execution, isolated Sandboxes, outcome scores, and live updates all share the same run, so you can follow the whole job in one trace.

<PlatformGrid />

For example, a support agent can call tools and run code in a Sandbox while it answers a request. Inngest retries failed steps and records the work in a trace. When feedback arrives later, a score links it to the run and experiment variant, so you can compare the outcomes of agent changes.
