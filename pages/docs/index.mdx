# Overview to Inngest
> Build durable, observable, failure-resistant code with sandboxing, online evals, and A/B tests built in.

<br />
**Inngest is the platform for building durable, observable workflows and agents that survive failures, without managing orchestration infrastructure.**

Write functions in your existing code and add steps to your logic.  Inngest coordinates each run, saves completed step results, and retries failed work from where the last step failed.

Inngest also adds isolated sandboxes, live updates, and outcome tracking to the same run, so you can see what happened and continue improving your product.

### What you get

1. **Workflows** coordinate steps, retries, waits, and flow control, so you can build long-running jobs and agents without writing your own orchestration.
2. **Sandboxes** run code in isolated microVMs. Inngest coordinates their lifecycle with the workflow and shows their activity in traces within runs.
3. **Online Evals** connect scores and later feedback to the run and variant that produced them. Compare changes to a step or a whole workflow against real outcomes.

For example:

> A support agent can call tools and run code in a Sandbox while answering a request. Inngest retries failed steps and records the work in a trace. When feedback arrives later, a score links it to the run and experiment variant, so you can compare the outcomes of agent changes.

## Explore Inngest

- [Durable Execution](/docs/durable-execution): Coordinate durable work with functions, steps, waits, and retries.
- [Sandboxes](/docs/sandboxes): Run code in isolated microVMs as part of the work.
- [Online Evals](/docs/online-evals): Score outcomes and compare changes to steps and workflows.
- [Realtime](/docs/realtime): Stream progress from durable runs to your users through typed channels and topics.
