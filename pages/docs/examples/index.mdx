# Examples

> Start from a working example to build durable workflows, isolated code execution, and outcome tracking faster.

Choose the result you want, then follow an example that shows the relevant Inngest APIs in context.

## Finish work reliably

- [TypeScript quick start](/docs/durable-execution/quick-start/typescript-quick-start) builds a durable workflow and runs it locally. [Go](/docs/durable-execution/quick-start/go-quick-start) and [Python](/docs/durable-execution/quick-start/python-quick-start) quick starts cover those languages.
- [Durable endpoints](/docs/durable-execution/durable-endpoints) shows how a request can start work that survives retries.
- [Fan-out](/docs/durable-execution/guides-and-advanced/patterns/fan-out) runs independent work in parallel. [Working with loops](/docs/durable-execution/guides-and-advanced/patterns/working-with-loops) handles repeated work with stable steps.
- [Schedules and delayed starts](/docs/durable-execution/guides-and-advanced/events-and-triggers/schedules-and-delayed-starts) starts work at a chosen time.

## Run code in isolation

- [Sandboxes quick start](/docs/sandboxes/quick-start) starts a Sandbox, runs a command, and inspects the result.
- [Managed lifecycle](/docs/sandboxes/features/managed-lifecycle) shows how a durable function manages Sandbox work and cleanup.

## Measure outcomes

- [Agent Evals quick start](/docs/agent-evals/quick-start) connects a session, a score, and an experiment.
- [Score with an LLM judge](/docs/agent-evals/guides/llm-judge) grades agent answers with a model and a deterministic tool-use check.
- [Experiments](/docs/agent-evals/experiments) compares a step or an entire workflow path using production outcomes.

## Show progress

- [Realtime quick start](/docs/realtime/quick-start) publishes progress from a durable function to a signed-in browser.
- [Channels and topics](/docs/realtime/channels-and-topics) defines the messages a client can receive.
