# Agent Evals guides
> Grade answers with a model, score user feedback, compare models, roll out rewrites, and control eval costs.

These guides build on the [Quick start](/docs/agent-evals/quick-start). Each one covers a single task from start to finish.

## Score results

- [Score with an LLM judge](/docs/agent-evals/guides/llm-judge) grades answers against a rubric with a model, and adds a cheap deterministic check.
- [Score user feedback](/docs/agent-evals/guides/user-feedback) records a thumbs-up, a resolved ticket, or ground truth that arrives after the run.

## Compare changes

- [Compare models and prompts](/docs/agent-evals/guides/compare-models-and-prompts) splits traffic between two answer strategies and scores each by later feedback.
- [Roll out a workflow rewrite](/docs/agent-evals/guides/workflow-rewrite) canaries a multi-step path and ramps it up as results come in.
- [Read results and roll out](/docs/agent-evals/guides/interpreting-results) explains how to compare variants and decide when to ship.

## Operate evals

- [Manage eval costs](/docs/agent-evals/guides/cost-management) shows how to count runs, steps, scores, and model calls, and how to choose which runs to score.

## Next steps

- [Best practices](/docs/agent-evals/best-practices) lists the measurement rules that keep comparisons meaningful.
- [Troubleshooting](/docs/agent-evals/troubleshooting) helps find missing or misattributed scores.
