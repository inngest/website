# Integrations

> Trigger functions from database changes and send Inngest metrics to your monitoring tools.

Connect Inngest to the services you already run. Set each one up from the **Integrations** section of the Inngest dashboard.

- [Neon](/docs/platform-and-operations/integrations/neon): start functions when rows change in your Neon Postgres database.
- [Datadog](/docs/platform-and-operations/integrations/datadog): send function and event metrics to Datadog, with no agent to configure.
- [Prometheus](/docs/platform-and-operations/integrations/prometheus): scrape Inngest metrics into Prometheus, Grafana, or a compatible tool.
