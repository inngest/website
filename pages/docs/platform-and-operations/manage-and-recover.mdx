# Manage and recover

> Recover failed runs, stop work during an incident, and manage the keys your apps use.

Fix the cause first, then pick the action that matches how much work you need to change:

- [Rerun a run](/docs/platform-and-operations/rerun-a-run): recover one run.
- [Replay runs in bulk](/docs/platform-and-operations/replay-runs-in-bulk): recover a selected set of failed or cancelled runs.
- [Bulk cancellation](/docs/durable-execution/guides-and-advanced/cancellation/bulk-cancellation): stop many existing runs by function and time range.
- [Pause and resume functions](/docs/platform-and-operations/pause-and-resume-functions): stop new runs during maintenance or an incident.

Manage the credentials your apps use to send events and talk to Inngest:

- [Keys and access](/docs/platform-and-operations/keys-and-access): choose between event keys, signing keys, and API keys.
- [Rotate event and signing keys](/docs/platform-and-operations/rotate-event-and-signing-keys): replace a key without downtime.
