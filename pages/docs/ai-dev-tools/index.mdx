# AI and MCP

> Give your coding agent current Inngest knowledge and direct access to your functions and runs.

Plugins and skills teach your agent how to write Inngest code. MCP and the CLI let it run that code, send test events, and inspect runs, so it can build and debug in one loop.

## Recommended setup

<Steps>
  <Step title="Install the plugin or skills">
    Add the Inngest plugin for Claude Code or Codex, or the portable skills for other agents. See [Agent plugins and skills](/docs/ai-dev-tools/agent-skills).
  </Step>
  <Step title="Connect Inngest MCP">
    Add the Dev Server MCP endpoint for local work, and Cloud MCP when your agent needs to inspect deployed environments. See [Inngest MCP](/docs/ai-dev-tools/mcp).
  </Step>
  <Step title="Build against the Dev Server">
    Start the [Dev Server](/docs/local-development), then ask your agent to send a test event and inspect the run it starts.
  </Step>
</Steps>

## LLM Docs

An LLM-friendly version of the Inngest docs is available in two formats:

- [inngest.com/llms.txt](https://www.inngest.com/llms.txt) - a table of contents for smaller context windows or tools that can crawl selected docs.
- [inngest.com/llms-full.txt](https://www.inngest.com/llms-full.txt) - the full docs in markdown format.
