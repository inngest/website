# Sandboxes quick start

> Run Python in an isolated Sandbox from a durable function and read the trace.

## What you need

- A TypeScript Inngest app connected to an Inngest Cloud environment. [Node.js quick start →](/docs/durable-execution/quick-start/typescript-quick-start)
- Node.js 20.5 or newer.
- `INNGEST_SIGNING_KEY` set in your **server** environment only.
- SDK v4. [Migrate from v3 →](/docs/reference/typescript/v4/migrations/v3-to-v4)

## Install and enable

```bash
npm install inngest@latest
```

```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";

export const inngest = new Inngest({
  id: "sandbox-demo",
  middleware: [sandboxMiddleware()],
});
```

## Run code

<AnnotatedCode>

```typescript {{ title: "inngest/functions/run-in-sandbox.ts" }}
import { inngest } from "../client";

export const runInSandbox = inngest.createFunction(
  { id: "run-in-sandbox", triggers: { event: "sandbox/demo.requested" } },
  async ({ event, step }) => {
    const stats = await step.sandbox.python<{ mean: number; n: number }>(
      "stats",
      `return {"mean": sum(values) / len(values), "n": len(values)}`,
      { input: { values: event.data.values } },
    );

    const listing = await step.sandbox.sh("list", "uname -a && ls /");

    return { stats, listing };
  },
);
```

<Annotation id="input" lines="6-10" tease="input becomes variables" title="Input and return" href="/docs/sandboxes/features/run-code?ref=docs-sandboxes-quick-start" linkText="Run code">
`input` keys become variables, and `return` sends a typed value back.
</Annotation>

<Annotation id="sh" lines="12" tease="shell too" title="Shell" href="/docs/sandboxes/features/run-code?ref=docs-sandboxes-quick-start" linkText="Run code">
Each statement boots, runs, and destroys its own Sandbox.
</Annotation>

</AnnotatedCode>

Register `runInSandbox` in your `serve()` handler, then send this event:

```json
{ "name": "sandbox/demo.requested", "data": { "values": [3, 5, 10] } }
```

```json
{ "stats": { "mean": 6, "n": 3 }, "listing": "Linux ... \nbin\ndev\netc\n..." }
```

## Keep one Sandbox

```typescript {{ title: "TypeScript" }}
await using sb = await step.sandbox.create("work");

await sb.$`npm init -y && npm install lodash`;
const version = await sb.$`node -p "require('lodash').VERSION"`.text();
```

## What you can do

- **Break it.** Run `ls /missing` and the row turns red. [Exit codes →](/docs/sandboxes/features/exit-codes?ref=docs-sandboxes-quick-start)
- **Read the trace.** Each statement is one SANDBOX group. [Traces →](/docs/sandboxes/features/traces?ref=docs-sandboxes-quick-start)
- **Reuse a Sandbox.** `await using` or `group.sandbox()`. [Managed lifecycle →](/docs/sandboxes/features/managed-lifecycle?ref=docs-sandboxes-quick-start)

## How it works

- Each statement is a durable step with its own Sandbox.
- Without `await using`, a Sandbox is destroyed when the run ends.
