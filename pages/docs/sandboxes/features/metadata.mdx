# Sandbox and snapshot metadata

> Tag Sandboxes and snapshots, then find them again.

- **Tag on create.** Add `metadata` to a Sandbox or snapshot. [Tag a resource →](#tag-a-resource)
- **Filter lists.** Exact match on one or more pairs. [Find by tag →](#find-by-tag)
- **See it everywhere.** Returned by the API, shown in the dashboard and the Dev Server UI.

## Tag a resource

<AnnotatedCode>

```typescript {{ title: "TypeScript" }}
const sb = await step.sandbox.create("scratch", {
  metadata: { team: "growth", job: event.data.jobId },
});

const snapshot = await sb.snapshot(
  "snapshot-prepared",
  { name: "node-deps", metadata: { stage: "prepared" } },
  { timeout: "5m" },
);

console.log(sb.metadata);
```

<Annotation id="create" lines="1-3" tease="set once, on create" title="Create" href="/docs/sandboxes/limits?ref=docs-sandboxes-metadata" linkText="Limits">
Metadata is immutable. Creating the same name with different metadata is a conflict.
</Annotation>

<Annotation id="snapshot" lines="5-9" tease="same option on snapshots" title="Snapshot" href="/docs/sandboxes/features/snapshots-and-restore?ref=docs-sandboxes-metadata" linkText="Snapshots">
Snapshots take their own metadata. Clones don't inherit it.
</Annotation>

<Annotation id="read" lines="11" tease="always an object" title="Read it back" href="/docs/sandboxes/reference?ref=docs-sandboxes-metadata#snapshots-and-clones" linkText="Reference">
`{}` when none was set.
</Annotation>

</AnnotatedCode>

## Find by tag

```typescript {{ title: "TypeScript" }}
const { items } = await inngest.sandboxes.list({
  metadata: { team: "growth", job: "j_123" },
});

await step.sandbox.snapshots.list("find", {
  metadata: { stage: "prepared" },
});
```

```bash {{ title: "REST" }}
GET /v2/sandboxes?metadata[team]=growth&metadata[job]=j_123
```

## How it works

- Keys and values are strings. Keys starting with `inngest.` are reserved.
- A list returns resources matching every pair you pass.
- Inngest sets `inngest.run_id` on [run-owned](/docs/sandboxes/features/run-owned?ref=docs-sandboxes-metadata#find-by-run) resources.
- [Limits →](/docs/sandboxes/limits?ref=docs-sandboxes-metadata)
