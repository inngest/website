# Snapshots and restore

> Save a prepared Sandbox and clone new ones from it.

- **Skip setup.** Install once, clone for every job. [Cloning →](/docs/sandboxes/features/cloning?ref=docs-sandboxes-snapshots-and-restore)
- **Name it.** Find the newest snapshot later with `snapshots.list({ name })`. [Name a snapshot →](#name-a-snapshot)
- **Keep it past the run.** Pass `owner: "persistent"`. [Run-owned →](/docs/sandboxes/features/run-owned?ref=docs-sandboxes-snapshots-and-restore#snapshots-follow-the-same-rule)
- **See it in the trace.** One SNAPSHOT group per snapshot. [Traces →](/docs/sandboxes/features/traces?ref=docs-sandboxes-snapshots-and-restore#tools-and-snapshots)

The direct client drops the step IDs and needs manual cleanup.

```typescript {{ title: "TypeScript" }}
const snapshot = await sandbox.snapshot({ name: "node-deps" }, { timeout: "5m" });

try {
  const clone = await snapshot.clone({ runningTimeout: "2m" });
  await clone.destroy();
} finally {
  await snapshot.delete();
}
```

## Name a snapshot

- One `CREATING` or unexpired `READY` snapshot holds a name. Reuse fails with `sandbox_snapshot_name_taken`.
- Names are case-sensitive, up to 255 characters, with no control characters or edge whitespace.
- For a base reused across many runs, use an image. [Image or snapshot? →](/docs/sandboxes/features/base-images?ref=docs-sandboxes-snapshots-and-restore#image-or-snapshot)

## How it works

- A snapshot is crash-consistent. Flush databases first.
- It expires at a server-defined `expiresAt` and counts against account quotas.
- Statuses are `CREATING`, `READY`, `DELETING`, `DELETED`, `FAILED`, and `LOST`. Clone only `READY`.
- The SDK waits up to five minutes for `READY`. A timeout does not stop creation, so list before retrying.
- Create has no idempotency key. After `operation_ambiguous`, list recent snapshots first.
- A snapshot taken in a function belongs to the run. Its owner is never inherited from the source.
- There is no in-place restore. Clone, or [pause and resume →](/docs/sandboxes/features/pause-and-resume?ref=docs-sandboxes-snapshots-and-restore)
