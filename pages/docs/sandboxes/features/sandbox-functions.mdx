# Sandbox functions and agents

> Define code that runs in a Sandbox once, call it like a function, and give it to an agent as a tool.

- **Define once.** Code, runtime, and schema become a typed function. [Define →](#define-a-function)
- **Call it anywhere.** Validated input, typed output. [Call it →](#call-it)
- **Give it to an LLM.** `.tool()` plus adapters for the AI SDK, Anthropic, OpenAI, and MCP. [Give it to an LLM →](#give-it-to-an-llm)
- **Run the agent loop.** Every model and tool call is a retryable step. [The agent loop →](#the-agent-loop)
- **Start from ready-made tools.** SQL, Python, charts. [Ready-made →](#ready-made-tools)

```typescript {{ title: "inngest/sandbox/run-sql.ts" }}
import { sandbox } from "inngest/experimental";
import { z } from "zod";

export const runSql = sandbox.fn({
  name: "run_sql",
  description: "Run a SQL query against a CSV the user uploaded.",
  runtime: "python@3.12",
  schema: {
    input: z.object({ csvUrl: z.string().url(), query: z.string() }),
    output: z.object({ rows: z.array(z.record(z.unknown())) }),
  },
  code: `
    import duckdb
    rows = duckdb.sql(f"SELECT * FROM read_csv('{csvUrl}') WHERE {query}").fetchall()
    return {"rows": rows}
  `,
});
```

## Call it

```typescript {{ title: "TypeScript" }}
import { step } from "inngest";
import { runSql } from "../sandbox/run-sql";

const result = await runSql("q1", { csvUrl, query: "region = 'EMEA'" });

const loose = await runSql("q2", input, { exitCodes: [0, 1] });
```

Input is validated before a Sandbox starts. A non-zero exit fails the step, per [Exit codes](/docs/sandboxes/features/exit-codes?ref=docs-sandboxes-sandbox-functions).

## Give it to an LLM

```typescript {{ title: "TypeScript" }}
import { generateText, stepCountIs } from "ai";
import { anthropic } from "@ai-sdk/anthropic";
import { toAiSdk } from "@inngest/sandbox-tools/ai-sdk";

const { text } = await generateText({
  model: anthropic("claude-sonnet-4-5"),
  tools: toAiSdk({ runSql, runPython }),
  stopWhen: stepCountIs(8),
  prompt: "Which region grew fastest in Q3?",
});
```

- `toAiSdk` lets the SDK run the tool. `toAnthropic` and `toOpenAI` give you `definitions` and `execute`. `toMcp` serves MCP.
- The model sees validation issues, or the exit code and stderr.

## The agent loop

```typescript {{ title: "inngest/functions/analyst.ts" }}
import { agentLoop, toAnthropic } from "@inngest/sandbox-tools";

export const analyst = inngest.createFunction(
  { id: "analyst", triggers: { event: "analyst/ask" } },
  async ({ event }) => {
    return agentLoop({
      adapter: toAnthropic,
      tools: [runSql, runPython],
      maxTurns: 8,
      model: (messages, defs) => {
        return anthropic.messages.create({ model: "claude-sonnet-4-5", max_tokens: 2048, tools: defs, messages });
      },
      messages: [{ role: "user", content: event.data.question }],
    });
  },
);
```

- A replay never calls the model again. A failed tool retries alone.

## Ready-made tools

`@inngest/sandbox-tools` ships `run_python`, `run_sql`, `fetch_and_parse`, `render_chart`, `run_tests`, and `read_output`.

## How it works

- Each call is a [SANDBOX group](/docs/sandboxes/features/traces?ref=docs-sandboxes-sandbox-functions) of durable steps.
- Keep the loop at function level, not inside a `step.run`.
