# Reusable sandbox functions

> Wrap a runner in a typed function, and call it like a step from any Inngest function.

A [runner](/docs/sandboxes/features/run-code) such as `step.sandbox.python()` is a durable step, and `step` is available as a global. So you can wrap a runner in an ordinary function with typed arguments and a typed result, export it, and call it from any function. There's no new API to learn.

## Define the function

<AnnotatedCode>

```typescript {{ title: "inngest/sandbox/stats.ts" }}
import { step } from "inngest";
import { z } from "zod";

const Stats = z.object({ mean: z.number(), stdev: z.number() });

export const stats = async (id: string, values: number[]) => {
  return step.sandbox.python(id, `import statistics
return {"mean": statistics.mean(values), "stdev": statistics.stdev(values)}`, {
    input: { values },
    schema: { output: Stats },
  });
};
```

<Annotation id="args" lines="6" tease="typed input" title="Arguments">
The function's signature types what callers pass. Take an `id`, so each call is a separately named step.
</Annotation>

<Annotation id="runner" lines="7-9" tease="a runner" title="The runner" href="/docs/sandboxes/features/run-code#return-a-value" linkText="Return a value">
Each `input` key becomes a variable in the code, and a top-level `return` sends the result back.
</Annotation>

<Annotation id="schema" lines="10" tease="typed output" title="Output schema" href="/docs/sandboxes/features/run-code#options" linkText="Runner options">
Types the result, and fails the step if the returned value doesn't match.
</Annotation>

</AnnotatedCode>

Set `runtime`, `from`, `tools`, and the other [runner options](/docs/sandboxes/features/run-code#options) on the runner call inside the function.

## Call it

```typescript {{ title: "TypeScript" }}
import { stats } from "../sandbox/stats";

const { mean } = await stats("stats", [1, 2, 3, 4]);
```

Each call is a durable step. A non-zero exit code fails the step, as described in [Exit codes and errors](/docs/sandboxes/features/exit-codes).
