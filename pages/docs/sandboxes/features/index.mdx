# Sandboxes features

> Run code in an isolated microVM and follow it in the same trace as your durable function.

- [Run code](/docs/sandboxes/features/run-code): Run Python, TypeScript, or shell in one statement.
- [Exit codes and errors](/docs/sandboxes/features/exit-codes): Fail loud, or allow the codes you expect.
- [Base images](/docs/sandboxes/features/base-images): Start from ready-made or custom images.
- [Custom images](/docs/sandboxes/features/custom-images): Build an image with Docker, upload it, and start Sandboxes from it.
- [Pause and resume](/docs/sandboxes/features/pause-and-resume): Pause work, then continue the same Sandbox.
- [Snapshots and restore](/docs/sandboxes/features/snapshots-and-restore): Save a prepared Sandbox to clone from.
- [Cloning](/docs/sandboxes/features/cloning): Start many jobs from one snapshot.
- [Durable filesystems](/docs/sandboxes/features/durable-filesystems): Keep files across pause, snapshot, and clone.
- [SSH](/docs/sandboxes/features/ssh): Planned: connect to a running Sandbox.
- [Secrets](/docs/sandboxes/features/secrets): Use workspace secrets without putting them in code.
- [Managed lifecycle](/docs/sandboxes/features/managed-lifecycle): Create a Sandbox and let Inngest clean up.
- [Run-owned Sandboxes](/docs/sandboxes/features/run-owned): Sandboxes end when their run ends.
- [Tools and code mode](/docs/sandboxes/features/tools): Let Sandbox code call your functions.
- [Reusable sandbox functions](/docs/sandboxes/features/sandbox-functions): Wrap a runner in a typed function.
- [Isolation and security](/docs/sandboxes/features/isolation-and-security): Run untrusted code in a separate microVM.
- [Traces](/docs/sandboxes/features/traces): Follow Sandbox work in your run trace.
