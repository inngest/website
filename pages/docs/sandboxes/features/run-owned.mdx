# Run-owned Sandboxes and snapshots

> Sandboxes and snapshots your run creates are cleaned up when the run ends, however it ends.

A Sandbox belongs to the run that created it. When the run ends, whether it completes, fails, is cancelled, or crashes, Inngest destroys the Sandboxes and snapshots the run still owns. You don't need `onFailure` handlers or stored Sandbox IDs to avoid leaks.

## Choose the owner

Set `owner` when you create a Sandbox to change which run it belongs to.

<AnnotatedCode>

```typescript {{ title: "TypeScript" }}
const sb = await step.sandbox.create("scratch");
await sb.python("work", code);

const shared = await step.sandbox.create("shared", {
  owner: { runId: event.data.coordinatorRunId },
});

const base = await step.sandbox.create("long-lived", { owner: "persistent" });
```

<Annotation id="default" lines="1-2" tease="this run owns it" title="Owned by this run">
The default. The Sandbox is destroyed when this run ends, so the code never destroys it.
</Annotation>

<Annotation id="other" lines="4-6" tease="another run owns it" title="Owned by another run">
The Sandbox lasts until that run ends. The owning run must still be active, or the call fails with `sandbox_owner_run_not_active`.
</Annotation>

<Annotation id="persistent" lines="8" tease="you destroy it" title="Persistent">
The Sandbox is kept until you destroy it.
</Annotation>

</AnnotatedCode>

`owner` works with `step.sandbox.create()`, `group.sandbox()`, the [runners](/docs/sandboxes/features/run-code), and `snapshot()`.

## Snapshots

Snapshots follow the same rule. A snapshot belongs to the run that took it, and is deleted after its clones when the run ends.

```typescript {{ title: "TypeScript" }}
const snapshot = await sb.snapshot("prepared");

const clones = await Promise.all(
  tasks.map((task) => snapshot.clone(`clone-${task.id}`)),
);
```

A clone doesn't inherit its snapshot's owner. Each clone belongs to the run that created it, unless you set `owner`.
