# Base images

> Start isolated work with Node.js, Python, Ruby, and common command-line tools already installed.

- **Ready on create.** No image to build first. [What's included →](#what-the-base-image-includes)
- **Pinned runtimes.** Node, Deno, Bun, and Python at exact versions. [Runtime images →](#runtime-images)
- **Bring your own.** Use an image from your workspace. [Choose an image →](#choose-an-image)
- **Image or snapshot.** Reuse a toolchain, or fan out. [Compare →](#image-or-snapshot)

## What the base image includes

- Node.js (`node`, `node-lts`), Python 3.14, Ruby 4.0.
- Git, curl, OpenSSH, BusyBox, `ripgrep`, `jq`, `tar`.
- No Go, Rust, Java, Bun, or Deno. Bun and Deno have [runtime images](#runtime-images).
- Check versions with `await sb.sh("versions", "node --version && python3 --version")`.

## Choose an image

- `image.inngest(name)` is `base` or a [runtime image](#runtime-images).
- `image.custom(ref)` is a workspace image. Build and publish one with [Custom images](/docs/sandboxes/features/custom-images?ref=docs-sandboxes-base-images).
- Images resolve once at create. A repeated name returns the original.

### Runtime images

```typescript {{ title: "TypeScript" }}
await step.sandbox.python("ml", code, { runtime: "python@3.12" });
await step.sandbox.typescript("edge", code, { from: image.inngest("deno") });
await step.sandbox.typescript("n22", code, { runtime: "node@22" });
```

- `node@20`, `22`, `24` and `python@3.11` to `3.13` map to `node-20`, `python-3.11`, and so on.
- `deno` and `bun` map to `image.inngest("deno")`.
- [Run code →](/docs/sandboxes/features/run-code?ref=docs-sandboxes-base-images#choose-a-runtime)

### Image or snapshot?

- **Image.** Starts fresh and lasts until you delete it.
- **[Snapshot](/docs/sandboxes/features/snapshots-and-restore?ref=docs-sandboxes-base-images).** Starts where the source left off, processes included. Ends with its [owner run](/docs/sandboxes/features/run-owned?ref=docs-sandboxes-base-images).

## Add dependencies

```typescript {{ title: "TypeScript" }}
await sandbox.commands.run(
  "mkdir -p /tmp/project && cd /tmp/project && npm init -y && npm install lodash",
  { timeout: "5m" },
);
```

Snapshots capture the files.

## Choose a size

```typescript {{ title: "TypeScript" }}
await inngest.sandboxes.create({ name: "a", vcpu: 1, memoryMb: 1024 });
await inngest.sandboxes.create({ name: "b", vcpu: 2, memoryMb: 8192 });
```

| `vcpu` | `memoryMb` |
| --- | --- |
| 1 | 1024, 2048, 4096 |
| 2 | 2048, 4096, 8192 |
| 4 | 4096, 8192, 16384 |

- 1, 2 or 4 vCPU with 1, 2 or 4 GiB per vCPU. Other sizes are refused.
- Clones inherit the snapshot's size.

## How it works

- New Sandboxes start from `base` unless you choose another.
- Inngest CI uses the same [images](/docs/labs/ci/base-images?ref=docs-sandboxes-base-images).
