# Exit codes and errors

> A failed command stops your function and shows red in the trace. Allow the codes that are information.

- **Fail loud by default.** A bad `npm ci` stops the run. [How it works →](#how-it-works)
- **Allow the codes you expect.** `grep` exiting `1` is an answer, not an error. [Allow exit codes →](#allow-exit-codes)
- **Read why it failed.** Command, exit code, and output tails. [Read the failure →](#read-the-failure)
- **Same rule in CI.** `$` throws, `$({ exitCodes: "any" })` returns. [Inngest CI →](/docs/labs/ci/commands?ref=docs-sandboxes-exit-codes)

<AnnotatedCode>

```typescript {{ title: "inngest/functions/review.ts" }}
import { getCommandError } from "inngest/experimental";

await using sb = await step.sandbox.create("review");

await sb.sh("install", "npm ci");

const hit = await sb.sh("find", `grep -q ${needle} /work/log`, {
  exitCodes: [0, 1],
});

const probe = await sb.sh("probe", "./flaky-tool", { exitCodes: "any" });

try {
  await sb.sh("lint", "npx eslint .");
} catch (err) {
  const failure = getCommandError(err);
  await step.run("report", () => postComment(failure?.stderrTail));
  throw err;
}
```

## Allow exit codes

```typescript {{ title: "TypeScript" }}
const result = await sb.sh("diff", "diff -q a.txt b.txt", { exitCodes: [0, 1] });

const hit = await sb.$({ exitCodes: [0, 1] })`grep ${needle} log`;
```

Works on `sh`, `python`, `ts`, `run`, `commands.run`, and [`$`](/docs/sandboxes/features/run-code?ref=docs-sandboxes-exit-codes#the-template).

## Read the failure

```typescript {{ title: "TypeScript" }}
const fn = inngest.createFunction(
  {
    id: "ci-lint",
    triggers: { event: "repo/pushed" },
    onFailure: async ({ error, step }) => {
      const failure = getCommandError(error);
      // { command, exitCode, stdoutTail, stderrTail, truncated } | undefined
      await step.run("comment", () => postComment(failure?.stderrTail));
    },
  },
  async ({ step }) => {
    await step.sandbox.sh("lint", "npx eslint .");
  },
);
```

`getSandboxError(err)` covers timeouts and capacity: `code`, `retryable`, `ambiguous`.

## How it works

- A non-zero exit fails the step without retries, so `npm publish` never repeats.
- The row and its group go red, and replays throw the same error.
- Timeouts are `sandbox_exec_timed_out`. An unknown outcome is `operation_ambiguous`.
