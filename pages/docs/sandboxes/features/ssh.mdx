# SSH

> Planned: connect to a running Sandbox to inspect and debug it.

SSH is planned for launch. There is no supported public connection path yet.

- **Inspect live files.** See the Sandbox's own filesystem and processes. [Pause and resume →](/docs/sandboxes/features/pause-and-resume?ref=docs-sandboxes-ssh)
- **Debug a process.** Connect with the key you uploaded.
- **Keep it scoped.** The microVM isolates the session from other Sandboxes. [Isolation →](/docs/sandboxes/features/isolation-and-security?ref=docs-sandboxes-ssh)

```bash {{ title: "Expected shape" }}
ssh <workload-id>@ssh.inngest.com
```

## How it works

- Upload a public key, create a Sandbox, wait for `RUNNING`, then connect.
- Closing the session leaves the Sandbox running until it is paused or destroyed.
- Reconnect after a resume. Pause can interrupt network sessions.
- Only give access to people who should be able to change the Sandbox.
