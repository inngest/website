# Traces

> See every Sandbox statement as one row in the run trace, and expand it to find what failed or ran slowly.

- **One statement, one row.** Size, exit code, and duration on the row. [Collapsed and expanded →](#collapsed-and-expanded)
- **Red means failed.** The exit code and stderr tail are on the row. [Exit codes →](/docs/sandboxes/features/exit-codes?ref=docs-sandboxes-traces)
- **One group per scope.** [One Sandbox →](#several-statements-in-one-sandbox)
- **Tools and snapshots.** Each shows as its own row. [Tools and snapshots →](#tools-and-snapshots)

## Collapsed and expanded

```text {{ title: "Collapsed" }}
sum      SANDBOX · python · exit 0 · 2 vCPU / 2 GB · 4.1s
ls       SANDBOX · sh · exit 0 · 3.2s
parse    SANDBOX · ts · exit 1 · red · 5.6s
```

```text {{ title: "Expanded: a command that exits 1" }}
SANDBOX  parse · node@22 · 2 vCPU / 2 GB · 5.6s
  create     ok
  run        exit 1 not in exitCodes: step failed, no retries
  destroy    ran because the failure was final
```

Retries show as attempts. Select a row for input, output, and error.

## Several statements in one Sandbox

```text {{ title: "Trace" }}
SANDBOX  build-check · node-22 · 4 vCPU / 2 GB · 38s
  create
  git clone ...     exit 0
  npm ci            exit 0
  npm test          exit 1 · allowed by exitCodes · green
  destroy
```

## Tools and snapshots

```text {{ title: "Trace" }}
SANDBOX  churn-report
  create
  exec                    exit 0 · 2 waits, folded in
  tool listCustomers      #1
  tool sendSlack          #2
  tool sendSlack          #3
  destroy
```

- [Tool](/docs/sandboxes/features/tools?ref=docs-sandboxes-traces) calls are rows. Waits fold into `exec`.
- A [snapshot](/docs/sandboxes/features/snapshots-and-restore?ref=docs-sandboxes-traces) is a **SNAPSHOT** group.

## How it works

- `step.sandbox` adds durable steps. `inngest.sandboxes` adds no rows.
- Protect trace data: it shows `input`, output, and errors unredacted. Use [`secrets`](/docs/sandboxes/features/secrets?ref=docs-sandboxes-traces).
- A [code mode](/docs/sandboxes/features/tools?ref=docs-sandboxes-traces#code-mode) call is a group between model calls.
