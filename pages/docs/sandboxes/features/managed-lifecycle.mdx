# Managed lifecycle

> Create a Sandbox, run several statements in it, and have it cleaned up without writing cleanup code.

- **End it where you want.** `await using` destroys it at scope end. [End it →](#end-it-where-you-want)
- **Or wrap a callback.** `group.sandbox()` works in every runtime. [Group a callback →](#group-a-callback)
- **Leftovers are cleaned up.** [Cleanup →](#what-cleanup-does-for-you)

<AnnotatedCode>

```typescript {{ title: "inngest/functions/build-check.ts" }}
import { image } from "inngest";

export const buildCheck = inngest.createFunction(
  { id: "build-check", triggers: { event: "repo/pushed" } },
  async ({ event, step }) => {
    await using sb = await step.sandbox.create("check", {
      from: image.inngest("node-22"),
      vcpu: 4,
      secrets: ["NPM_TOKEN"],
    });

    await sb.$`git clone --depth 1 ${event.data.url} /work/repo`;
    await sb.$.sh`cd /work/repo && npm ci`.timeout("5m");

    const tests = await sb.$.sh`cd /work/repo && npm test`.exitCodes("any");

    return { passed: tests.ok, tail: tests.stdout.slice(-2000) };
  },
);
```

## Create options

```typescript {{ title: "TypeScript" }}
type CreateOptions = {
  name?: string;
  from?: SandboxImage;
  vcpu?: number;
  memoryMb?: number;
  timeout?: SandboxDuration;
  runningTimeout?: SandboxDuration | false;
  env?: Record<string, string>;
  secrets?: string[];
  owner?: "persistent" | { runId: string };
  tools?: SandboxTools;
  toolOptions?: SandboxToolOptions;
};
```

- Defaults: `vcpu` 2, `memoryMb` 2048 ([limits](/docs/sandboxes/limits?ref=docs-sandboxes-managed-lifecycle)), `timeout` `"30s"`.
- See [images](/docs/sandboxes/features/base-images?ref=docs-sandboxes-managed-lifecycle), [secrets](/docs/sandboxes/features/secrets?ref=docs-sandboxes-managed-lifecycle), and [owners](/docs/sandboxes/features/run-owned?ref=docs-sandboxes-managed-lifecycle).

## End it where you want

```typescript {{ title: "TypeScript" }}
async ({ step, event }) => {
  const repo = await step.run("resolve", () => resolveRepo(event.data.repoId));
  let files: string[];

  {
    await using sb = await step.sandbox.create("review", { from: image.inngest("node-22") });
    await sb.$`git clone --depth 1 ${repo.url} /work/r`;
    await sb.$.sh`cd /work/r && npx eslint .`.exitCodes("any");
    files = (await sb.$.sh`cd /work/r && git diff --name-only`.text()).split("\n");
  }

  await step.run("notify", () => notify(repo.id, files));
  return { files };
}
```

Without `await using`, it lasts until the run ends, or until `await sb.destroy("done")`.

<Info>
  `await using` needs `lib: ["esnext.disposable"]` and Node.js 20.5 or newer. Otherwise use `group.sandbox()`.
</Info>

## Group a callback

```typescript {{ title: "TypeScript" }}
import { $ } from "inngest/experimental";

const out = await group.sandbox("run", (sb) => sb.python("main", "return 6 * 7"));

const report = await group.sandbox(
  { id: "build-check", from: image.inngest("node-22"), vcpu: 4, secrets: ["NPM_TOKEN"] },
  async (sb) => {
    await $`git clone --depth 1 ${url} /work/repo`;
    const tests = await $.sh`cd /work/repo && npm test`.exitCodes("any");
    return { passed: tests.ok, tail: tests.stdout.slice(-2000) };
  },
);
```

A bare `$` inside the callback runs on the group's Sandbox. Outside a group it throws.

Destroyed when the callback returns or throws. One `SANDBOX` group in the [trace](/docs/sandboxes/features/traces?ref=docs-sandboxes-managed-lifecycle).

## What cleanup does for you

- **Success or final failure.** Destroyed at once.
- **A failure that will retry.** Kept, so the retry finds its files.
- **Cancel, timeout, or crash.** Destroyed when the run ends. See [Run-owned](/docs/sandboxes/features/run-owned?ref=docs-sandboxes-managed-lifecycle).


## How it works

- A retry repeats only the failed step, in the same Sandbox.
- `operation_ambiguous` means inspect before repeating.
- [Pause](/docs/sandboxes/features/pause-and-resume?ref=docs-sandboxes-managed-lifecycle) resumes the same ID. A [clone](/docs/sandboxes/features/snapshots-and-restore?ref=docs-sandboxes-managed-lifecycle) is new.
- Outside a function, destroy in `finally`.
