# Sandboxes guides

> Run isolated code, keep your work, and inspect failures in one durable run.

## Start and run

- [Run your first Sandbox](/docs/sandboxes/quick-start). Python in a durable function.
- [Run code](/docs/sandboxes/features/run-code). `python`, `typescript`, and `sh` with `input` and a schema.
- [Keep one Sandbox](/docs/sandboxes/features/managed-lifecycle). `await using` or `group.sandbox()`.
- [Call your functions](/docs/sandboxes/features/tools). Tools run as durable steps.
- [Reuse sandbox code](/docs/sandboxes/features/sandbox-functions). A plain function over a runner.
- [Give an agent a Sandbox](/docs/sandboxes/features/tools#code-mode). One LLM tool that writes code against your tools.
- [Move files and run processes](/docs/sandboxes/reference#commands-processes-and-files). Direct client.

## Keep or branch your work

- [Pause and resume](/docs/sandboxes/features/pause-and-resume). Same Sandbox, same ID.
- [Snapshots](/docs/sandboxes/features/snapshots-and-restore) and [cloning](/docs/sandboxes/features/cloning). New Sandboxes from saved state.
- [Durable filesystems](/docs/sandboxes/features/durable-filesystems). Share files across Sandboxes.

## Access and inspect

- [SSH](/docs/sandboxes/features/ssh). Planned for launch.
- [Secrets](/docs/sandboxes/features/secrets). Select workspace secrets by name.
- [Traces](/docs/sandboxes/features/traces). Find the operation, result, and retry.

## Recover and clean up

- [Exit codes and errors](/docs/sandboxes/features/exit-codes). Fail loud, allow what is expected.
- [Managed lifecycle](/docs/sandboxes/features/managed-lifecycle). Safe retries and `operation_ambiguous`.
- [Run-owned Sandboxes](/docs/sandboxes/features/run-owned). Direct calls need `try/finally`.
