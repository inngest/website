# Sandboxes

> Run generated code in an isolated microVM and follow it in the same trace as your function.

- **Run code in one statement.** Python, TypeScript, or shell, with a typed value back. [Run code →](/docs/sandboxes/features/run-code?ref=docs-sandboxes-index)
- **Boot in under a second.** Each Sandbox is its own VM, isolated from the host. [Isolation →](/docs/sandboxes/features/isolation-and-security?ref=docs-sandboxes-index)
- **Keep your work.** Pause and resume, or snapshot and clone. [Pause and resume →](/docs/sandboxes/features/pause-and-resume?ref=docs-sandboxes-index)
- **Call your functions from the Sandbox.** Tools run as durable steps, so credentials stay out. [Tools →](/docs/sandboxes/features/tools?ref=docs-sandboxes-index)
- **Never leak one.** Whatever your run creates is cleaned up when it ends. [Run-owned →](/docs/sandboxes/features/run-owned?ref=docs-sandboxes-index)
- **Follow the whole job.** Every statement is a group in the run trace. [Traces →](/docs/sandboxes/features/traces?ref=docs-sandboxes-index)

```typescript {{ title: "TypeScript" }}
const total = await step.sandbox.python<number>("sum", "return sum(xs)", { input: { xs } });
```
