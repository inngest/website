# SDKs & APIs

> Find the SDK for your language and start building durable functions in your existing app.

Choose an SDK for your language to build durable functions, send events, and connect your app. Inngest also connects Sandboxes, Online Evals, and Realtime to those runs. Use the [versioned reference](/docs/sdk/overview/reference) for exact methods and options.

You can serve functions over HTTP from your existing app or use Connect to run a worker that connects to Inngest. Choose the deployment model that fits your host.

## Install an SDK

<LanguageSelector>

<LanguageSection show="typescript">

### Installation

Install `inngest` with your package manager:

<CodeGroup>
```shell {{ title: "npm" }}
npm install inngest
```
```shell {{ title: "yarn" }}
yarn add inngest
```
```shell {{ title: "pnpm" }}
pnpm add inngest
```
```shell {{ title: "bun" }}
bun add inngest
```
</CodeGroup>

### Setup

Create an Inngest client to define functions and send events:

```typescript
import { Inngest } from "inngest";

export const inngest = new Inngest({
  id: "my-app",
});
```


</LanguageSection>

<LanguageSection show="go">


Add the Go SDK to your project:

```shell
go get github.com/inngest/inngestgo
```

</LanguageSection>

<LanguageSection show="python">

### Installation

Install the Python SDK:

```shell
pip install inngest
```

### Setup

Create an Inngest client to define functions and send events:

```python
import inngest
import logging

inngest_client = inngest.Inngest(
    app_id="app_example",
    logger=logging.getLogger("uvicorn"),
)
```
