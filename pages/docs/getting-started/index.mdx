# Get started

> Run your first durable workflow, Sandbox, online eval, or live update.

Start with the area you need first: durable functions coordinate work, sandboxes run code in isolation, online evals connect outcomes to runs, and realtime sends progress to your users.

## Start the Dev Server

Every quick start runs locally against the Inngest Dev Server. It records your events and runs, and shows each run's trace at [http://localhost:8288](http://localhost:8288).

<DocsCallout>

Start the Dev Server with one of the commands below:

<CodeGroup>
```bash {{ title: "Bash installer" }}
curl -sSfL https://cli.inngest.com/install.sh | sh
inngest dev -u http://localhost:3000/api/inngest
```
```bash {{ title: "Brew" }}
brew install inngest/tap/inngest
inngest dev -u http://localhost:3000/api/inngest
```
```bash {{ title: "NPX" }}
npx --ignore-scripts=false inngest-cli@latest dev

# -u supplies the app URL when discovery does not find it.
npx --ignore-scripts=false inngest-cli@latest dev -u http://localhost:3000/api/inngest
```
```bash {{ title: "Docker" }}
docker run -p 8288:8288 -p 8289:8289 inngest/inngest \
  inngest dev -u http://host.docker.internal:3000/api/inngest
```
</CodeGroup>

</DocsCallout>
