# Events and triggers

> Start durable workflows from app events, provider webhooks, or schedules.

Start a durable workflow when your app records an action, a provider sends a webhook, or a schedule fires. Inngest starts one run for each matching function, so the sender does not need to call each function.
## Learn the model
- [Event and trigger concepts](/docs/durable-execution/guides-and-advanced/events-and-triggers/event-and-trigger-concepts) explains how an event starts runs, how trigger `if` conditions filter events, and when a wildcard matches an event family.
- [Durable Workflows](/docs/durable-execution/durable-workflows) shows one durable workflow with multiple event and schedule triggers.
