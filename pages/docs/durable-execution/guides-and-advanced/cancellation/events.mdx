# Events

> Use events to automatically cancel running functions without any extra work.

Stop a scheduled or sleeping run when a change makes its remaining work unnecessary. Define `cancelOn` on the TypeScript v4 function, then send a matching cancellation event.

## Cancel a reminder when it is deleted
This reminder function sleeps until the requested time. A deletion event with the same `reminderId` cancels the run before it sends the reminder.
```typescript
import { inngest } from "./client";
import { sendReminder } from "./notifications";

export const scheduleReminder = inngest.createFunction(
  {
    id: "schedule-reminder",
    triggers: { event: "reminders/created" },
    cancelOn: [
      {
        event: "reminders/deleted",
        if: "async.data.reminderId == event.data.reminderId",
      },
    ],
  },
  async ({ event, step }) => {
    await step.sleepUntil("wait-until-due", event.data.remindAt);
    await step.run("send-reminder", () => sendReminder(event.data));
  }
);
```
In the expression, `event` is the original `reminders/created` trigger and `async` is the later `reminders/deleted` event. Compare a stable identifier so one customer's event does not cancel another customer's run. Send the deletion event to Inngest when the reminder is removed.
For a direct equality on one field, use `match: "data.reminderId"` instead of `if`. You cannot combine `match` and `if` in the same cancellation rule.
## Bound the cancellation window
Add `timeout: "1h"` to a `cancelOn` rule if the event should only cancel runs during the first hour after the trigger. Without a matching event in that window, the function continues. A function can listen for up to five cancellation events.
Cancellation takes effect between steps. It can stop the reminder while the run sleeps, but it cannot interrupt a `step.run` that has already begun sending it. The canceled run emits `inngest/function.cancelled`.
Use [Timeouts](/docs/durable-execution/guides-and-advanced/cancellation/timeouts) for elapsed-time limits and [Bulk cancellation](/docs/durable-execution/guides-and-advanced/cancellation/bulk-cancellation) to stop a selected set of existing runs.
