# Error handling

> Recover from failed work and handle errors that retries cannot resolve.

When an API or database call fails, Inngest retries the failed step and keeps results from steps that already succeeded. If the error persists, run a fallback, compensate for earlier work, or report the final failure.

- [Retries](/docs/durable-execution/guides-and-advanced/error-handling/retries) shows retry scope, defaults, and timing.

- [Failure handlers](/docs/durable-execution/guides-and-advanced/error-handling/failure-handlers) responds after a function exhausts its retries.
