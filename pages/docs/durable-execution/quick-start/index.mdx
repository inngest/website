# Durable Execution quick start
> Build and inspect a durable workflow locally in your preferred language.

Choose TypeScript, Go, or Python to send a task event, run a saved step, and inspect the result in the local Dev Server. These guides need no Inngest account.

## Choose a language

- [TypeScript quick start](/docs/durable-execution/quick-start/typescript-quick-start) uses the TypeScript SDK v4 and Next.js App Router.
- [Go quick start](/docs/durable-execution/quick-start/go-quick-start) uses the Go SDK and the standard HTTP server.
- [Python quick start](/docs/durable-execution/quick-start/python-quick-start) uses the Python SDK and FastAPI.

All three guides use the same `app/task.created` event and `process-task` function, so you can compare the language-specific setup while following the same workflow.

## After your first run

- [Durable Workflows](/docs/durable-execution/durable-workflows) explains why completed steps survive retries and pauses.
- [Primitives](/docs/durable-execution/primitives) covers more step primitives.
- [Deploying functions](/docs/durable-execution/deploying-functions) helps you deploy the same function on your chosen host.

For framework setup and exact SDK signatures, use [SDKs & APIs](/docs/sdk/overview) in the platform and language navigation.
