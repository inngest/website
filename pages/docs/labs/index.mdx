# Inngest Labs

> New projects built on Inngest that you can use today, while they are still taking shape.

Labs is where Inngest ships what it is building next. Each lab is a real project on the platform you already use, released early so you can try it, build with it, and see where it goes. Labs projects use [Sandboxes](/docs/sandboxes), [traces](/docs/platform-and-operations/traces), and [flow control](/docs/durable-execution/flow-control), so what you already know about Inngest carries over.

## Why try a lab

- **Get new capabilities first.** Labs projects solve problems that the platform does not cover yet, such as running CI pipelines as durable functions.
- **Build on what you know.** Labs use the same runs, traces, and controls as the rest of Inngest.
- **Your usage matters.** The way people use a lab decides what it becomes.

## What to expect

- **Fast movement.** Labs change quickly. APIs may change between 0.x releases, so pin the version you use.
- **A path forward.** A lab can become part of the platform, and then it moves into the main docs. A lab can also be retired. In that case you get notice and a migration path.
- **Open source.** Lab code stays open source, whatever happens next.
