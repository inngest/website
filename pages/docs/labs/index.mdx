# Inngest Labs

> New projects built on Inngest that you can use today, while they are still taking shape.

Labs is where we ship what is next for Inngest. Each lab is a real project you can install and use today, released early so you can build with it while it takes shape.

## Why try a lab

- **Use new capabilities first.** Labs cover ground the platform does not yet, such as running CI pipelines as durable functions.
- **Nothing new underneath.** Labs run on the same runs, [traces](/docs/platform-and-operations/traces?ref=docs-labs), and [flow control](/docs/durable-execution/flow-control?ref=docs-labs) you already use.
- **Help decide what is next.** How people use a lab shapes where it goes.

## What to expect

- **Fast movement.** Labs change quickly. APIs may change between 0.x releases, so pin the version you use.
- **A path forward.** A lab can become part of the platform, and then it moves into the main docs. A lab can also be retired. In that case you get notice and a migration path.
- **Open source.** Lab code stays open source, whatever happens next.
