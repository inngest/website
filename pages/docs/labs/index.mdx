# Inngest Labs

> Projects we build on the Inngest platform, in the open, to find out whether they are worth keeping.

Labs is the home for ideas built on top of Inngest. Each lab starts with one person who believes an idea is valuable and sprints on it. We ship it early so you can use it, tell us what works, and help us decide what happens next.

## Why Labs exists

Labs lets us ship fast without whole-company planning. A lab uses the platform you already use, including [Sandboxes](/docs/sandboxes), [traces](/docs/platform-and-operations/traces), and [flow control](/docs/durable-execution/flow-control), so a new idea can reach you quickly. In return, you see it while the design is still open.

## What to expect

- **Early design.** Labs projects are young. APIs may change between 0.x releases.
- **Fast movement.** The person building a lab reads the feedback and changes the project in response.
- **A decision.** A lab either **graduates** into the platform or is **retired**.

If a lab graduates, it moves into the main docs as part of the platform. If a lab is retired, we give notice and a migration note, and the code stays open source.
