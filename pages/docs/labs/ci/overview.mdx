# Inngest CI overview

> Write your CI in TypeScript, run it on Inngest, and debug every run as one trace.

<Info>
  Inngest CI is an Inngest Labs project: early, moving fast, and shaped by your feedback. [What's Labs?](/docs/labs?ref=docs-labs-ci-overview)
</Info>

## What you can do

- **Write plain TypeScript.** `if`, loops, and `Promise.all`. [Pipelines →](/docs/labs/ci/pipelines?ref=docs-labs-ci-overview)
- **Debug one trace per run.** Every job, command, and retry. [See a run →](#see-the-result)
- **Retry only what failed.** Passed work never reruns. [Retries →](/docs/labs/ci/commands?ref=docs-labs-ci-overview#retries)
- **Build once, reuse it.** Start jobs from another job's machine. [Base images →](/docs/labs/ci/base-images?ref=docs-labs-ci-overview#another-job)
- **Run it locally.** Real Sandboxes, your uncommitted changes. [Run locally →](/docs/labs/ci/local?ref=docs-labs-ci-overview)

<AnnotatedCode>

```typescript {{ title: "ci/pipelines.ts" }}
import { github, checkout, $ } from "@inngest/ci";
import { ci } from "./client";

export const pr = ci.pipeline(
  {
    id: "pr",
    on: github.pullRequest(),
    singleton: { key: "event.data.pull_request.number", mode: "cancel" },
  },
  async () => {
    await Promise.all([
      lint(),
      test(),
    ]);
  },
);

const base = ci.job("base", async () => {
  await checkout();
  await $`pnpm install`;
});

const lint = ci.job({ id: "lint", from: base }, async () => {
  await $`pnpm lint`;
});

const test = ci.job({ id: "test", from: base }, async () => {
  await $({ retries: 1 })`pnpm test`;
});
```

## How it works

- A **pipeline** runs on a **trigger** and calls **jobs**. Each job runs **commands** on its own **machine**.
- A failed command retries on the same machine. Inngest never retries a run for it.
- Other failures replay saved results. Finished jobs do not rerun.
