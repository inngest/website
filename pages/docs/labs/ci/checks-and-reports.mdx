# Checks and reports

> See each pipeline and job as a GitHub check, and read every run as one trace.

- **A check per job.** Plus one for the pipeline. [Checks →](#checks)
- **Summaries and annotations.** Add them from code. [Add a summary →](#add-a-summary-or-annotations)
- **One trace per run.** Every job, command, and retry. [Read the trace →](#read-the-trace)
- **Terminal checks locally.** The same states print in dev mode. [Run on GitHub →](/docs/labs/ci/reference?ref=docs-labs-ci-checks-and-reports#run-on-github)

## Checks

```
✕ pr             test: `pnpm test` exited with 1
✓ pr / base      Passed in 41s
✓ pr / lint      Passed in 22s
✕ pr / test      `pnpm test` exited with 1
```

```typescript {{ title: "TypeScript" }}
ci.pipeline({ id: "pr", on, check: false }, fn);
ci.pipeline({ id: "pr", on, check: { jobs: false } }, fn);
ci.pipeline({ id: "pr", on, check: { name: "CI" } }, fn);
ci.job({ id: "notify", check: false }, fn);
```

## Read the trace

```typescript {{ title: "TypeScript" }}
const test = ci.job({ id: "test", name: "Unit tests", from: base }, async () => {
  await $({ id: "unit tests", retries: 1 })`pnpm test`;
});
```

- **Job row.** Tagged `JOB` with its `name`, or `id`. An `S1`, `S2` badge marks each [Sandbox](/docs/labs/ci/machines?ref=docs-labs-ci-checks-and-reports#use-a-second-machine).
- **Expanded job.** Start sandbox, your commands, your `step.run` steps, Save sandbox.
- **Expanded command.** Each retry is an attempt. A failure ends in "Exited with code N".
- **Cached work.** Shows the image and whether it was found or built just in time.
- **Dimmed rows.** Work CI does for you. Failures are never dimmed.

## How it works

- A job called twice shows as `test (2)` with its own check.
- While a run will be retried, checks stay in progress.
- A GitHub "Re-run" sends a new event. Passed jobs are reused only with a [cache](/docs/labs/ci/base-images?ref=docs-labs-ci-checks-and-reports#add-a-cache-key).
- `ci.skip()` completes as success with the reason. [Pipelines →](/docs/labs/ci/pipelines?ref=docs-labs-ci-checks-and-reports#skip-a-run)
