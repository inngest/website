# Machines

> Run each job on its own Sandbox, sized for its work.

- **Right-sized.** 1, 2, or 4 vCPU per job, pipeline, or app. [Reference →](/docs/labs/ci/reference?ref=docs-labs-ci-machines#machines)
- **Start set up.** Boot from a job or image. [Base images & caching →](/docs/labs/ci/base-images?ref=docs-labs-ci-machines)
- **A second machine.** Test a clean install. [Second machine →](#use-a-second-machine)

<AnnotatedCode>

```typescript {{ title: "ci/jobs/verify.ts" }}
const verify = ci.job({ id: "verify", machine: { vcpu: 4 } }, async () => {
  await checkout();

  const clean = await sandbox("clean", { vcpu: 1 });

  await Promise.all([
    $`pnpm test`,
    clean.$.sh`npm install -g my-cli@next && my-cli --version`,
  ]);
});
```

## Choose a size

```typescript {{ title: "ci/jobs/build.ts" }}
machine: { vcpu: 1 } // 1 GiB
machine: { vcpu: 2 } // 2 GiB, default
machine: { vcpu: 4 } // 4 GiB
```

Set it on a job, a pipeline, or `createCi`. The first one set wins, in that order.

## Use a second machine

<Warning>
  Machines cannot reach each other yet. Run servers on the job's machine and use `127.0.0.1`.
</Warning>

```typescript {{ title: "ci/jobs/e2e.ts" }}
await $`pnpm start`.background();
await waitForPort(3000);
await $`pnpm exec playwright test`;
```


## How it works

- A machine is a [Sandbox](/docs/sandboxes/overview?ref=docs-labs-ci-machines): an ephemeral microVM.
- It starts on the first command. Only commands run on it.
- `machine` on a job beats the pipeline, which beats `createCi`.
- Machines are destroyed when the pipeline ends.
- Locally, `checkout()` uploads your working tree.
