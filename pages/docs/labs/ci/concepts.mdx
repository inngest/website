# Inngest CI concepts

> A trigger starts a pipeline, which calls jobs, which run commands and report checks.

## Pipeline

One Inngest function that calls jobs. [Pipelines →](/docs/labs/ci/pipelines?ref=docs-labs-ci-concepts)

```typescript {{ title: "ci/pipelines/pr.ts" }}
export const pr = ci.pipeline({ id: "pr", on: github.pullRequest() }, async () => {
  await test();
});
```

## Trigger

Starts a pipeline and types its `event`. [Triggers →](/docs/labs/ci/pipelines?ref=docs-labs-ci-concepts#triggers)

```typescript {{ title: "ci/pipelines/pr.ts" }}
on: [github.pullRequest(), github.push({ branches: ["main"] })]
```

## Job

A unit of work with its own machine and check. [Jobs →](/docs/labs/ci/jobs?ref=docs-labs-ci-concepts)

```typescript {{ title: "ci/jobs/test.ts" }}
const test = ci.job("test", async () => {
  await checkout();
  await $`pnpm test`;
});
```

## Command

A shell command on the job's machine. [Commands →](/docs/labs/ci/commands?ref=docs-labs-ci-concepts)

```typescript {{ title: "ci/jobs/test.ts" }}
await $({ retries: 1 })`pnpm test`;
```

## Machine

A [Sandbox](/docs/sandboxes/overview?ref=docs-labs-ci-concepts) microVM. [Machines →](/docs/labs/ci/machines?ref=docs-labs-ci-concepts)

```typescript {{ title: "ci/jobs/build.ts" }}
const build = ci.job({ id: "build", machine: { vcpu: 4 } }, async () => {
  await $`pnpm build`;
});
```

## Starting from another job

Starts a job on a copy of another's machine. [Base images →](/docs/labs/ci/base-images?ref=docs-labs-ci-concepts#start-from-a-job)

```typescript {{ title: "ci/jobs/lint.ts" }}
const lint = ci.job({ id: "lint", from: base }, async () => {
  await $`pnpm lint`;
});
```

## Cache

Skips a job when its key is unchanged. [Caching →](/docs/labs/ci/base-images?ref=docs-labs-ci-concepts#add-a-cache-key)

```typescript {{ title: "ci/jobs/base.ts" }}
const base = ci.job({ id: "base", cache: { key: files("pnpm-lock.yaml") } }, fn);
```

## Check

Reports each pipeline and job on GitHub. [Checks →](/docs/labs/ci/checks-and-reports?ref=docs-labs-ci-concepts)

```typescript {{ title: "ci/jobs/test.ts" }}
await report.summary("Coverage: **91%**");
```
