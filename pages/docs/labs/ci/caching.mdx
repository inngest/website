# Caching

> Skip a job when nothing it depends on has changed.

- **Install once per lockfile.** The machine is published as an image. [Choose the key →](#choose-the-key)
- **Ready before the PR.** Build ahead on push or cron. [Refresh →](#refresh-the-cache-ahead-of-time)
- **Shared by everyone.** CI, teammates, and local runs. [How it works →](#how-it-works)
- **Rebuild on demand.** Send one event. [Rebuild →](#rebuild-on-demand)

<AnnotatedCode>

```typescript {{ title: "ci/jobs.ts" }}
const base = ci.job(
  {
    id: "base",
    cache: {
      key: files("pnpm-lock.yaml", ".nvmrc"),
      refresh: [{ cron: "0 3 * * *" }],
      maxAge: "7d",
    },
  },
  async () => {
    await checkout();
    await $`pnpm install`;
  },
);

const test = ci.job({ id: "test", from: base }, async () => {
  await checkout();
  await $`pnpm test`;
});
```

## Choose the key

```typescript {{ title: "TypeScript" }}
key: files("migrations/**", "seeds/**")
key: [files("go.mod", "go.sum"), "go1.25"]
key: files("schema.graphql", { repo: "acme/api", ref: "main" })
key: [files("pnpm-lock.yaml"), files("ci/**")]
```

A key is `files()`, a string, an array of them, or an async function returning a string. Locally, `files()` hashes your working tree.

## Refresh the cache ahead of time

```typescript {{ title: "TypeScript" }}
cache: {
  key: files("pnpm-lock.yaml"),
  refresh: [github.push({ branches: ["main"] }), { cron: "0 3 * * *" }],
},
```

<CiBuilds scenario="just-in-time" />

Set `repo` on the pipeline for a cron. The trace warns when a run built just in time:

```text
built just in time: `base` (add `cache.refresh` to build it ahead of time)
```

## Set a maximum age

```typescript {{ title: "TypeScript" }}
cache: { key: files("Dockerfile.ci"), maxAge: "1d" },
```

Durations: `"30m"`, `"1h30m"`, `"7d"`, milliseconds, or a `Temporal.Duration`.

## Rebuild on demand

```typescript {{ title: "TypeScript" }}
import { invalidateEvent } from "@inngest/ci";

await inngest.send(invalidateEvent("base"));
await inngest.send(invalidateEvent(base, { scope: "main" }));
```

`scope` takes a branch, `pr:<number>`, `global`, or `local`. Without it, every scope is cleared.

## Share across branches

```typescript {{ title: "TypeScript" }}
cache: { key: files("pnpm-lock.yaml"), scope: "global" }
```

The default is `"branch"`.

## How it works

- Images are found by name: key, input, and parent image. Parents with no `cache` rebuild every run.
- A pull request reads its own and its base branch's images, and writes only its own.
- A local run reads shared images and writes its own.
- Runs missing the same image share one build. [See it →](/docs/labs/ci/base-images?ref=docs-labs-ci-caching#built-once-then-reused)
- A key with no changes never expires unless `maxAge` says so.
