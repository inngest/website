# Recipes

## Services and waiting

| Task | Code | Learn more |
| --- | --- | --- |
| Start a server | `` const server = await $`pnpm start`.background() `` | [Reference](/docs/labs/ci/reference#commands) |
| Wait for a port | `await probe.waitForPort(3000)` | [Machines](/docs/labs/ci/machines#use-a-second-machine) |
| Wait for a health check | `await probe.waitForHttp("http://127.0.0.1:3000/health")` | [Machines](/docs/labs/ci/machines#use-a-second-machine) |
| Read server logs | `await server.output()` | [Reference](/docs/labs/ci/reference#commands) |
| Stop a server | `await server.kill()` | [Reference](/docs/labs/ci/reference#commands) |
| Wait for other checks | `await github.waitForChecks({ names: ["vercel"] })` | [Reference](/docs/labs/ci/reference#github-api-and-helpers) |
| Wait for an Actions workflow | `await github.waitForWorkflow({ workflow: "npm_test.yml" })` | [Reference](/docs/labs/ci/reference#github-api-and-helpers) |
| Run another pipeline | `await step.invoke("contracts", { function: contracts, data: { sha } })` | [Jobs](/docs/labs/ci/jobs#use-inngest-steps-in-a-job) |

## Tests

| Task | Code | Learn more |
| --- | --- | --- |
| Build once, test many | `await from(build)` | [Machines](/docs/labs/ci/machines#start-a-job-from-another-job) |
| Skip unchanged tests | `cache: { key: files("src/**", "test/**") }` | [Caching](/docs/labs/ci/caching) |
| Retry a flaky command | `` await $`pnpm test`.retries(2) `` | [Commands](/docs/labs/ci/commands#retries) |
| Test every Node version | `ci.matrix` over `axes: { node: ["20", "22"] }` | [Jobs](/docs/labs/ci/jobs#run-a-job-for-every-combination) |
| Dump state when a command hangs | `` await $`pnpm test`.timeout("10m").onTimeout(async () => { return $`ps auxf`; }) `` | [Reference](/docs/labs/ci/reference#commands) |

## Changes and triggers

| Task | Code | Learn more |
| --- | --- | --- |
| Run on changed files | `if (await changed("docs/**")) { await docsSite(); }` | [Pipelines](/docs/labs/ci/pipelines#skip-a-run) |
| Skip a whole run | `return ci.skip("nothing changed")` | [Pipelines](/docs/labs/ci/pipelines#skip-a-run) |
| Watch another repository | `on: github.push({ repo: "inngest/inngestgo", branches: ["main"] })` | [Pipelines](/docs/labs/ci/pipelines#triggers) |

| Cancel superseded runs | `singleton: { key: "event.data.pull_request.number", mode: "cancel" }` | [Pipelines](/docs/labs/ci/pipelines#flow-control) |
