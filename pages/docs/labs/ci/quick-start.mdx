# Inngest CI quick start

> Write a pipeline, run it with your uncommitted changes, and read one trace.

- **Needs.** Node.js 20+, `inngest` 4.22.0+, a git repo with `lint` and `test` scripts, and [Sandboxes](/docs/sandboxes/overview?ref=docs-labs-ci-quick-start) access.
- **Sign in once.** The Dev Server runs commands on your account's Sandboxes.

```bash
npx inngest-cli@latest login
```

## 1. Install the packages

```bash
npm install @inngest/ci inngest
npm install --save-dev inngest-cli tsx
```

## 2. Create the client

```typescript {{ title: "ci/client.ts" }}
import { Inngest } from "inngest";
import { createCi } from "@inngest/ci";

export const inngest = new Inngest({ id: "my-app" });
export const ci = createCi(inngest);
```

Checks print to the terminal by default. [Run on GitHub →](/docs/labs/ci/reference?ref=docs-labs-ci-quick-start#run-on-github)

## 3. Write the jobs

```typescript {{ title: "ci/jobs/base.ts" }}
import { $, checkout } from "@inngest/ci";
import { ci } from "../client";

export const base = ci.job("base", async () => {
  await checkout();
  await $`pnpm install`;
});
```

```typescript {{ title: "ci/jobs/lint.ts" }}
import { $ } from "@inngest/ci";
import { ci } from "../client";
import { base } from "./base";

export const lint = ci.job({ id: "lint", from: base }, async () => {
  await $`pnpm lint`;
});
```

```typescript {{ title: "ci/jobs/test.ts" }}
import { $ } from "@inngest/ci";
import { ci } from "../client";
import { base } from "./base";

export const test = ci.job({ id: "test", from: base }, async () => {
  await $({ retries: 1 })`pnpm test`;
});
```

## 4. Write a pipeline

```typescript {{ title: "ci/pipelines/pr.ts" }}
import { github } from "@inngest/ci";
import { ci } from "../client";
import { lint } from "../jobs/lint";
import { test } from "../jobs/test";

export const pr = ci.pipeline(
  {
    id: "pr",
    on: github.pullRequest(),
    singleton: { key: "event.data.pull_request.number", mode: "cancel" },
  },
  async () => {
    await Promise.all([lint(), test()]);
  },
);
```

## 5. Serve the pipelines

```typescript {{ title: "ci/server.ts" }}
import { createServer } from "inngest/node";
import { inngest, ci } from "./client";
import "./pipelines/pr";

const server = createServer({ client: inngest, functions: ci.functions() });

server.listen(Number(process.env.PORT ?? 3000));
```

[Project structure →](/docs/labs/ci/structure?ref=docs-labs-ci-quick-start)

## 6. Run locally

```bash
npx inngest-ci pr
```

[Run CI locally →](/docs/labs/ci/local?ref=docs-labs-ci-quick-start)

## 7. Inspect the result

```
  inngest-ci pr  pull_request.opened · my-branch @ 70f798f + uncommitted
  Dev Server  http://127.0.0.1:24288

  ✕ pr                                                       58s
  └─ ✓ base     $ pnpm install                               31s
     ├─ ✓ lint  $ pnpm lint                                  12s
     └─ ✕ test  $ pnpm test · attempt 2                      27s
          `pnpm test` exited with 1
```

Press `enter` to open the run in the Dev Server. [Read the trace →](/docs/labs/ci/checks-and-reports?ref=docs-labs-ci-quick-start#read-the-trace)

## How it works

- `inngest-cli` 1.45.1+ is the Dev Server. Your server must listen on `PORT`.
- `inngest-ci` starts a Dev Server and `ci/server.ts`, then sends a pull request event for your branch.
- `ci.functions()` adds the cache, GitHub re-run, and single-job functions.
- `checkout()` uploads your working tree, uncommitted changes included.
- Machines are destroyed when the run ends, or by a cleanup function.
- Command output arrives when the command ends.
