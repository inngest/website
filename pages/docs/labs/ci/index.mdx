`@inngest/ci` runs each pipeline as a durable function and each job on its own [Sandbox](/docs/sandboxes/overview?ref=docs-labs-ci).

## What you can do

- **Write plain TypeScript.** `if`, loops, and `Promise.all`. [Pipelines →](/docs/labs/ci/pipelines?ref=docs-labs-ci)
- **Keep finished work.** Retries skip what passed. [Commands →](/docs/labs/ci/commands?ref=docs-labs-ci#retries)
- **Start from another job.** Copy its machine, or [cache](/docs/labs/ci/base-images?ref=docs-labs-ci#add-a-cache-key) it. [Base images →](/docs/labs/ci/base-images?ref=docs-labs-ci#start-from-a-job)
- **Run it locally.** Real Sandboxes, uncommitted changes. [Run locally →](/docs/labs/ci/local?ref=docs-labs-ci)
- **Get GitHub checks.** One per pipeline and job. [Checks →](/docs/labs/ci/checks-and-reports?ref=docs-labs-ci)
- **Control flow.** Cancel, cap, debounce. [Flow control →](/docs/labs/ci/pipelines?ref=docs-labs-ci#flow-control)
