> Write CI pipelines in TypeScript and run every job on its own Inngest Sandbox.

`@inngest/ci` turns TypeScript functions into CI pipelines. Inngest runs each pipeline as a durable function and each job on its own [Sandbox](/docs/sandboxes/overview), an ephemeral microVM. One run produces one trace that covers the pipeline, its jobs, and every command.

## What you can do

- **Write plain TypeScript, not YAML.** Use `if`, loops, `Promise.all`, types, and your own SDKs.
- **Keep finished work.** Inngest saves finished commands and steps, so a retry does not rerun work that already passed.
- **Start a job from another job.** `from()` starts a job on a copy of another job's machine, like a Docker layer.
- **Run the same code locally.** Run a pipeline against the Dev Server with your uncommitted changes.
- **Get GitHub checks.** Each pipeline gets one check, and each job gets one.
- **Control how pipelines run.** Cancel superseded runs, cap concurrency, debounce, throttle, and rate limit pipelines with Inngest [flow control](/docs/durable-execution/flow-control).
