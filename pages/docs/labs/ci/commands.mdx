# Commands

> Run shell commands on a job's machine. Retries skip passed work.

- **Plain template tag.** `` $`pnpm test` `` runs on the job's machine. [Reference →](/docs/labs/ci/reference?ref=docs-labs-ci-commands#commands)
- **Retry one command.** Nothing that passed runs again. [Retries →](#retries)
- **Pass options.** Env, timeout, names, parsed output. [Options →](#options)

<AnnotatedCode>

```typescript {{ title: "ci/jobs/test.ts" }}
const test = ci.job("test", async () => {
  await checkout();
  await $`pnpm install`;
  await $({ retries: 2 })`pnpm --filter ${pkg} test`;
  await $({ exitCodes: "any" })`pnpm lint`;
});
```

## Retries

```typescript {{ title: "ci/jobs/test.ts" }}
await $({ retries: 2 })`pnpm test`;
```

## Options

```typescript {{ title: "ci/jobs/test.ts" }}
await $({ env: { CI: "true" }, timeout: "10m" })`pnpm test`;
await $({ id: "e2e" })`pnpm exec playwright test`;
await $.sh`pnpm build && pnpm pack`;

const sha = await $`git rev-parse HEAD`.text();
```

## Share commands between jobs

```typescript {{ title: "ci/helpers.ts" }}
import { $, checkout } from "@inngest/ci";

export const install = async () => {
  await checkout();
  await $`pnpm install --frozen-lockfile`;
};
```

```typescript {{ title: "ci/jobs/test.ts" }}
import { $ } from "@inngest/ci";
import { ci } from "../client";
import { install } from "../helpers";

export const test = ci.job("test", async () => {
  await install();
  await $`pnpm test`;
});
```

## How it works

- Each command is a step. A resumed run replays saved results.
- Each retry is an attempt in the [trace](/docs/labs/ci/checks-and-reports?ref=docs-labs-ci-commands#read-the-trace).
- `$` outside a job throws `CiUsageError`.
