# Base images

> Start a job on a machine that's already set up.

- **Install once.** Every job starts from a copy of `base`. [Another job →](#another-job)
- **Share across runs.** A cached parent becomes an image. [Caching →](/docs/labs/ci/caching?ref=docs-labs-ci-base-images)
- **Bring your own.** Start from an Inngest or custom image. [Images →](#an-inngest-image)
- **Reuse another app's job.** One build, many apps. [Another app →](#another-app-s-job)

<AnnotatedCode>

```typescript {{ title: "ci/jobs.ts" }}
import { checkout, files, image, $ } from "@inngest/ci";
import { ci } from "./client";

const base = ci.job(
  { id: "base", cache: { key: files("pnpm-lock.yaml") } },
  async () => {
    await checkout();
    await $`pnpm install`;
  },
);

const test = ci.job({ id: "test", from: base }, async () => {
  await checkout();
  await $`pnpm test`;
});

const e2e = ci.job(
  { id: "e2e", from: image.custom("playwright") },
  async () => {
    await checkout();
    await $`npx playwright test`;
  },
);
```

</Annotation>

<Annotation id="from" lines="12" tease="copy of base" title="Start from another job" href="#another-job" linkText="Another job">

</Annotation>

<Annotation id="checkout" lines="13" tease="only the changes" title="Catch up to this commit" href="/docs/labs/ci/machines?ref=docs-labs-ci-base-images" linkText="Machines">

</Annotation>

## Another job

```typescript {{ title: "TypeScript" }}
const test = ci.job({ id: "test", from: base }, fn);
const web = ci.job({ id: "web", from: build.with("web") }, fn);
const app = ci.job({ id: "app", from: ({ input }) => build.with(input) }, fn);
const matrix = ci.matrix({ id: "m", axes, from: base }, fn);
```

Add a [`cache`](/docs/labs/ci/caching?ref=docs-labs-ci-base-images) to share the parent across runs. Without one, the parent is a [run-owned snapshot](/docs/sandboxes/features/run-owned?ref=docs-labs-ci-base-images) cleaned up when the run ends.

## An Inngest image

```typescript {{ title: "TypeScript" }}
const lint = ci.job({ id: "lint", from: image.inngest("base") }, fn);
const old = ci.job({ id: "old", from: image.inngest("node-22") }, fn);
```

Jobs without `from` start on `base`. [Runtime images →](/docs/sandboxes/features/base-images?ref=docs-labs-ci-base-images#runtime-images)

## Your own image

```typescript {{ title: "TypeScript" }}
const e2e = ci.job({ id: "e2e", from: image.custom("playwright") }, fn);
```

## Another app's job

```typescript {{ title: "TypeScript" }}
const test = ci.job({ id: "test", from: image.job("platform/node-base") }, fn);
```

Both apps share one Inngest environment.

## Every job

```typescript {{ title: "TypeScript" }}
const ci = createCi(inngest, { from: image.custom("agent-deps") });
```

## How it works

- A cached job's image is named by its [key](/docs/labs/ci/caching?ref=docs-labs-ci-base-images#choose-the-key), input, and parent image.
- A missing image makes the job run its parent's commands itself: same result, slower.
- A bad parent or cycle (`a → b → a`) fails at app start.
