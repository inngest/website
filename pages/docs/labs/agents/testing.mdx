# Testing

> Test a whole agent with no model key, no Slack and no real sandbox.

- **Script the model.** `script()` answers from a list of steps. [Script →](#script-the-model)
- **Fake Slack and GitHub.** `startFakes()` records every post. [Fakes →](#test-the-whole-agent)
- **Fake the sandbox.** `fakeSandbox()` serves the Sandboxes API from memory. [Sandbox →](#fake-the-sandbox)
- **Test a push.** `startGitRemote()` and `fakeGitDataApi()` ask for a token. [Git →](#test-a-push)
- **Read thread state.** `withKeys()` returns the keys the agent set. [State →](#test-the-whole-agent)
- **Test a channel.** `testReporter()` runs `report` steps on the spot. [Channel →](#test-a-channel)

Everything here runs in Node and is for tests only. Import it from `inngest/experimental/agents/testing`.

## Test the whole agent

Build the app from a function, so a test can pass the model and the Slack URL.

```typescript {{ title: "inngest/tools/lookup.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";

export const lookup = tool.step({
  description: "Find an order by ID",
  input: z.object({ id: z.string() }),
  run: async ({ id }) => {
    return { id, status: "shipped" };
  },
});
```

```typescript {{ title: "inngest/app.ts" }}
import { Inngest } from "inngest";
import {
  agent,
  type AgentModel,
  createAgents,
  kv,
  memoryKvAdapter,
  slack,
} from "inngest/experimental/agents";
import { lookup } from "./tools/lookup";

export interface AppOptions {
  model: AgentModel;
  slackApi?: string;
}

export function createApp(options: AppOptions) {
  const inngest = new Inngest({ id: "support", isDev: true });

  const agents = createAgents(inngest, { store: memoryKvAdapter() });

  const support = agents.agent(
    {
      id: "support",
      on: slack.thread({ in: ["C0123ABC"] }),
      channels: ({ event }) => {
        return {
          main: slack.channel(event, {
            in: ["C0123ABC"],
            apiUrl: options.slackApi,
            token: "xoxb-test",
          }),
        };
      },
      report: "main",
    },
    async ({ inbox, control, report }) => {
      for await (const message of inbox) {
        const result = await agent.loop({
          model: options.model,
          prompt: message.content ?? "",
          tools: { lookup },
          ...control,
        });

        await kv.thread.set("answer", result.text);

        await report(result.text);
      }
    },
  );

  return { inngest, agents, support };
}
```

A small helper serves the app and registers it with the Dev Server.

```typescript {{ title: "test/serveApp.ts" }}
import { createServer } from "node:http";
import type { Inngest, InngestFunction } from "inngest";
import { serve } from "inngest/node";

export async function serveApp(
  client: Inngest.Any,
  functions: InngestFunction.Any[],
  port = 3939,
) {
  const server = createServer(serve({ client, functions }));

  await new Promise<void>((resolve) => {
    server.listen(port, resolve);
  });

  await fetch(`http://localhost:${port}/api/inngest`, { method: "PUT" });

  return {
    close: async () => {
      server.close();
    },
    [Symbol.asyncDispose]: async () => {
      server.close();
    },
  };
}
```

Start the Dev Server, then run the test.

```bash
npx inngest-cli@latest dev --no-discovery
npx vitest run
```

## Script the model

A step answers by turn. A step with `when` answers the first request it matches.

```typescript {{ title: "test/models.ts" }}
import { script } from "inngest/experimental/agents/testing";

export const model = script([
  { call: { name: "lookup", input: { id: "42" } } },
  {
    say: "Sorry, I cannot help with that.",
    when: (request) => {
      return request.messages.length > 20;
    },
  },
  { say: "You asked: {{last}}" },
]);
```

After the script the model echoes the last user message. `{{last}}` in a `say` is replaced by that message.

## Fake the sandbox

`fakeSandbox` is the Sandboxes API served from memory. Give its `fetch` to the client.

```typescript {{ title: "inngest/checks.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";
import { agent } from "inngest/experimental/agents";
import type { DurableSandbox } from "inngest/experimental";
import { script } from "inngest/experimental/agents/testing";

export function createChecks(fetchImpl: typeof fetch) {
  const inngest = new Inngest({
    id: "checks",
    isDev: true,
    middleware: [sandboxMiddleware()],
    fetch: fetchImpl,
  });

  const check = inngest.createFunction(
    { id: "check", triggers: [{ event: "checks/run" }] },
    async ({ group }) => {
      return group.sandbox("box", async (sandbox: DurableSandbox) => {
        const result = await agent.loop({
          model: script([
            { call: { name: "run", input: { command: "npm test" } } },
            { say: "tests pass" },
          ]),
          prompt: "run the tests",
          tools: sandbox.tools.code({ only: ["run"] }),
        });

        return result.text;
      });
    },
  );

  return { inngest, check };
}
```

## Test a push

`startGitRemote` serves real repositories over HTTP, behind a token. `fakeGitDataApi` is GitHub's Git Data API in memory, for pushes without git.

```typescript {{ title: "test/git.test.ts" }}
import {
  fakeGitDataApi,
  startGitRemote,
} from "inngest/experimental/agents/testing";
import { expect, test } from "vitest";

test("a push needs the token", async () => {
  await using remote = await startGitRemote({
    token: "t0k",
    repos: {
      website: { "index.html": "<h1>hi</h1>\n" },
      source: { main: { "a.ts": "export {};\n" }, pr: { "b.ts": "1\n" } },
    },
    anonymousReads: true,
  });

  const options = {
    remote: remote.repos.website?.url ?? remote.url,
    token: () => {
      return "t0k";
    },
    transport: "git" as const,
  };

  expect(options.remote).toContain("website.git");

  expect(remote.pushAuth).toEqual([]);

  expect(Object.keys(remote.repos.source?.heads ?? {})).toEqual([
    "main",
    "pr",
  ]);
});

test("a push without git", () => {
  const github = fakeGitDataApi({ repo: "acme/app" });

  github.seed("/tmp/clone", "HEAD", "refs/heads/main");

  expect(github.ref("refs/heads/agent-fix")).toBeUndefined();

  expect(github.requests).toEqual([]);

  expect(typeof github.fetch).toBe("function");
});
```

Pass `options` to `gitPushTool` or `pushBranch`, and for the API form give `github.fetch` as `fetch` with `transport: "api"`. Read `remote.pushAuth` and `github.ref(...)` after the agent pushes.

The remote needs `git` with `git-http-backend`.

## Test a channel

`testReporter()` gives a `report` that runs its steps on the spot, so a test sees what the channel was sent.

```typescript {{ title: "inngest/channels/ticket.ts" }}
import { defineChannel } from "inngest/experimental/agents";

export const posted: string[] = [];

export const ticket = defineChannel({
  post: async (message) => {
    posted.push(message.text ?? "");

    return `ticket-${posted.length}`;
  },
});
```

```typescript {{ title: "test/reporter.test.ts" }}
import { testReporter } from "inngest/experimental/agents/testing";
import { expect, test } from "vitest";
import { posted, ticket } from "../inngest/channels/ticket";

test("finish returns the reference and a replay writes nothing", async () => {
  const first = testReporter({ main: ticket });

  const ref = await first.report.finish({ text: "Done." });

  expect(ref).toBe("ticket-1");

  expect(first.ran).toEqual(["report:finish:1"]);

  const replay = testReporter({ main: ticket }, { saved: first.results });

  expect(await replay.report.finish({ text: "Done." })).toBe("ticket-1");

  expect(replay.ran).toEqual([]);

  expect(posted).toEqual(["Done."]);
});
```

`report.finish()` returns the reference `post` gave back (Slack: the message `ts`). `ran` lists the steps that ran, and `results` replays them.

## How it works

- `startFakes`, `fakeSandbox` and `startGitRemote` have `close()` and work with `await using`.
- `fakeSandbox({ fakes })` records in this process. `recordUrl` posts to a fakes server in another process.
- The fake Slack follows the Web API, including streamed progress and its 50-card limit.
- `fakeSandbox` serves pause and resume, so a thread whose sandbox pauses when idle can be tested.
- Nothing looks for `git` until you call `startGitRemote` or `fakeGitDataApi`.
