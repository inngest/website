# Channels

> Let people talk to an agent where they already work, and watch it work.

- **Start from Slack or GitHub.** `slack.thread` and `github.thread` turn messages into threads. [Triggers →](#start-from-a-message)
- **Report progress.** `report()` posts text, cards and status to every channel. [Report →](#report-to-several-places)
- **Reach your own surface.** `defineChannel` wraps a ticket tool, a board or a log. [Your channel →](#write-your-own-channel)
- **Ask a person.** `askThrough` renders a question with options. [Asks →](#ask-a-person)
- **Test it offline.** Fake Slack and GitHub servers keep every call. [Testing →](/docs/labs/agents/testing?ref=docs-labs-agents-channels)

## Start from a message

A Slack thread or a GitHub issue is one agent thread. Replies reach the live run.

<AnnotatedCode>

```typescript {{ title: "inngest/agents/triage.ts" }}
import { agent, slack } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const triage = agents.agent(
  {
    id: "triage",
    on: slack.thread({ in: ["C0123ABC"] }),
    channels: ({ event }) => {
      return { main: slack.channel(event, { in: ["C0123ABC"] }) };
    },
    report: "main",
  },
  async ({ inbox, control, report }) => {
    for await (const message of inbox) {
      await report.status("working");

      await report.card({ id: "read", title: "Reading the thread" });

      const result = await agent.loop({
        model: claude,
        prompt: message.content ?? "",
        tools: {},
        ...control,
      });

      await report.card({ id: "read", title: "Read", status: "done" });

      await report.finish({ text: result.text });

      await report.status("idle");
    }
  },
);
```

Your route sends the events. It must verify Slack's or GitHub's signature first, because any sender of the event can steer the agent.

```typescript {{ title: "inngest/events.ts" }}
import {
  githubCommentEvent,
  slackMessageEvent,
} from "inngest/experimental/agents";
import { inngest } from "./client";

export async function relay(text: string) {
  await inngest.send({
    name: slackMessageEvent,
    data: { channel: "C0123ABC", ts: "1700000000.000100", text, user: "U1" },
  });

  await inngest.send({
    name: githubCommentEvent,
    data: { owner: "acme", repo: "app", number: 7, body: text, author: "jo" },
  });
}
```

Tokens come from `SLACK_BOT_TOKEN` and `GITHUB_TOKEN`, or from a `token` option that is a string or a function.

## Report to several places

`report` takes a channel name, a channel, or a list. Each call can override it with `to`.

```typescript {{ title: "inngest/agents/review.ts" }}
import { agent, github } from "inngest/experimental/agents";
import { agents } from "../client";
import { ticketChannel } from "../channels/ticket";
import { claude } from "../models/claude";

export const review = agents.agent(
  {
    id: "review",
    on: github.thread({
      repos: ["acme/app"],
      ignoreAuthors: ["review-bot[bot]"],
    }),
    channels: ({ event }) => {
      return {
        main: github.channel(event, {
          repos: ["acme/app"],
          token: () => {
            return process.env.GITHUB_TOKEN ?? "";
          },
        }),
        tickets: ticketChannel("T-1"),
      };
    },
    report: ["main", "tickets"],
  },
  async ({ inbox, control, report }) => {
    for await (const message of inbox) {
      const result = await agent.loop({
        model: claude,
        prompt: message.content ?? "",
        tools: {},
        ...control,
      });

      await report({
        text: result.text,
        kind: "result",
        data: { turns: result.turns },
      });

      await report("Heads up for the team", { to: "tickets" });
    }
  },
);
```

`kind` is `"progress"`, `"result"` or `"error"`, and `data` is plain JSON up to 32 KB. The GitHub channel makes `@mentions` inert.

## Write your own channel

A channel needs only `post`.

```typescript {{ title: "inngest/channels/ticket.ts" }}
import { defineChannel } from "inngest/experimental/agents";
import { tickets } from "../tickets";

export function ticketChannel(id: string) {
  return defineChannel({
    post: async (message) => {
      await tickets.comment(id, message.text);
    },
  });
}
```

Add `status`, `ask` and `stream` for a richer surface.

<AnnotatedCode>

```typescript {{ title: "inngest/channels/board.ts" }}
import { ChannelStreamEnded, defineChannel } from "inngest/experimental/agents";
import { board } from "../board";

export const boardChannel = defineChannel({
  post: async (message) => {
    await board.write("main", [message.text]);
  },
  status: async (status) => {
    await board.write("status", [status]);
  },
  ask: async (ask) => {
    await board.write("asks", [ask.question, ...(ask.options ?? [])]);
  },
  stream: {
    limits: { maxCards: 50, rollAt: 40, maxAgeMs: 9 * 60_000 },
    start: async ({ title, cards = [] }) => {
      const id = await board.open(title);

      await board.write(
        id,
        cards.map((card) => {
          return card.title;
        }),
      );

      return id;
    },
    append: async (stream, cards) => {
      const written = await board.write(
        stream,
        cards.map((card) => {
          return card.title;
        }),
      );

      if (!written) {
        throw new ChannelStreamEnded();
      }
    },
    stop: async (stream, final) => {
      await board.write(stream, [final?.text ?? ""]);
    },
  },
});
```

<Annotation id="post" lines="5" tease="at least once" title="post" href="/docs/labs/agents/reference?ref=docs-labs-agents-channels#channels" linkText="Reference">
Runs in a step. A post whose answer is lost is posted again.
</Annotation>

<Annotation id="status-fn" lines="8" tease="best effort" title="status" href="/docs/labs/agents/reference?ref=docs-labs-agents-channels#channels" linkText="Reference">
A failure here never fails the run.
</Annotation>

<Annotation id="ask-fn" lines="11" tease="renders only" title="ask" href="/docs/labs/agents/reference?ref=docs-labs-agents-channels#channels" linkText="Reference">
Shows the question. The answer arrives later as a signal.
</Annotation>

<Annotation id="limits" lines="15" tease="the reporter rolls over" title="limits" href="/docs/labs/agents/reference?ref=docs-labs-agents-channels#channels" linkText="Reference">
When a stream is full or old, the reporter starts a new one with a summary card.
</Annotation>

<Annotation id="ended" lines="37" tease="start a new stream" title="ChannelStreamEnded" href="/docs/labs/agents/threads?ref=docs-labs-agents-channels" linkText="Threads">

</Annotation>

A stream is a string your adapter hands out, such as a message timestamp. Add `continued(restarts)` to say a stream goes on after a restart.

## Ask a person

`askThrough` renders a question through a channel. A channel without `ask` is an error that says so.

```typescript {{ title: "inngest/agents/approve.ts" }}
import { step } from "inngest";
import { askThrough } from "inngest/experimental/agents";
import { agents } from "../client";
import { boardChannel } from "../channels/board";

export const approve = agents.agent(
  { id: "approve", channels: { main: boardChannel } },
  async ({ inbox, channels }) => {
    for await (const message of inbox) {
      await step.run("ask", async () => {
        await askThrough(channels.main ?? boardChannel, {
          signal: `approve-${message.seq}`,
          question: "Ship it?",
          options: ["yes", "no"],
          recommended: "no",
          approvers: ["jack"],
          timeout: "1d",
        });
      });
    }
  },
);
```

The Slack channel shows options as buttons, or a menu past 25. Your route sends the answer as the `signal`, and checks `approvers`: the SDK enforces nothing.

## How it works

- Every `report` call is a step, so a replay posts nothing twice. Delivery is at least once.
- Called inside your own `step.run`, a write goes on your step and adds none.
- Slack text is escaped and never parsed, so a `<!channel>` in model output arrives as plain text.
- `slack.channel` and `github.channel` refuse targets outside `in` and `repos`.
- With `scores` on, the first post gets `agent.first_output_ms` and later ones `agent.output_gap_ms`.
