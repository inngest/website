# Quick start

> A few small files, then a conversation that survives restarts.

## Install

You need Node.js 20+, a recent `inngest`, Zod 4, a Redis URL in `INNGEST_EXPERIMENTAL_KV_URL`, and an `ANTHROPIC_API_KEY`.

```bash
npm install inngest zod @anthropic-ai/sdk
```

```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({ id: "support" });
export const agents = createAgents(inngest);
```

## Make a model

```typescript {{ title: "inngest/models/claude.ts" }}
import { agent } from "inngest/experimental/agents";

export const claude = agent.anthropic({ model: "claude-sonnet-5-5" });
```

It reads `ANTHROPIC_API_KEY`. For another provider, [`agent.model()`](/docs/labs/agents/models-and-the-loop?ref=docs-labs-agents-quick-start#choose-a-model) wraps its SDK.

## Write the agent

A tool the model can call, then the agent that uses it.

```typescript {{ title: "inngest/tools/lookupOrder.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";

export const lookupOrder = tool.step({
  description: "Find an order by ID",
  input: z.object({ id: z.string() }),
  run: async ({ id }) => {
    return { id, status: "shipped" };
  },
});
```

```typescript {{ title: "inngest/agents/support.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { lookupOrder } from "../tools/lookupOrder";

export const support = agents.agent(
  { id: "support" },
  async ({ inbox, control }) => {
    for await (const message of inbox) {
      await agent.loop({
        model: claude,
        prompt: message.content ?? "",
        tools: { lookupOrder },
        ...control,
      });
    }
  },
);
```

## Serve it

```typescript {{ title: "inngest/serve.ts" }}
import { createServer } from "inngest/node";
import { agents, inngest } from "./client";
import "./agents/support";

createServer({
  client: inngest,
  functions: agents.functions(),
}).listen(3000);
```

`agents.functions()` returns every agent defined so far, so import agent files before calling it. Agents that use [sandboxes](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-quick-start) need `sandboxMiddleware()` on the client.

## Send a message

```typescript {{ title: "send.ts" }}
import { support } from "./inngest/agents/support";

await support.thread("customer-42").send("Where is order 7?");
```

The first message starts a run. Later messages to `customer-42` reach the same thread, and its [memory](/docs/labs/agents/threads-and-memory?ref=docs-labs-agents-quick-start) lives in Redis.

## See the run

Open the run in the Dev Server to see each model call and tool call as a step. Agents use `step.subscribe`, which the published Inngest CLI does not have yet, so build a Dev Server from the `jack/step-subscribe-clean` branch of [inngest/inngest](https://github.com/inngest/inngest). You need `git` and Go.

```bash
(
  set -e
  git clone --depth 1 --branch jack/step-subscribe-clean https://github.com/inngest/inngest inngest-dev-src
  cd inngest-dev-src
  mkdir -p pkg/devserver/static internal/embeddocs/website/pages/docs
  [ -f pkg/devserver/static/index.html ] || echo "<!doctype html><title>Inngest Dev Server</title>" > pkg/devserver/static/index.html
  [ -f internal/embeddocs/website/pages/docs/index.md ] || echo "# Inngest docs" > internal/embeddocs/website/pages/docs/index.md
  CGO_ENABLED=0 go build -trimpath -o ../inngest-dev ./cmd
)
```

`$DEV_SERVER` is that `inngest-dev` binary. This build has no Dev Server UI, so follow runs through your app's output. With your app serving on port 3000:

```bash
DEV_SERVER=$PWD/inngest-dev
$DEV_SERVER dev --no-discovery -u http://localhost:3000/api/inngest
```
