# Calling home

> Let a script in the sandbox call your tools, each call a step in your app.

The model can write one script instead of taking many turns, and your tools' credentials stay out of the machine. This page adds that to the PR helper, built up through [Threads](/docs/labs/agents/threads?ref=docs-labs-agents-calling-home), [Inboxes](/docs/labs/agents/inboxes?ref=docs-labs-agents-calling-home), [Models](/docs/labs/agents/models?ref=docs-labs-agents-calling-home), [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-calling-home), [Skills](/docs/labs/agents/skills?ref=docs-labs-agents-calling-home) and [Sandboxes](/docs/labs/agents/sandboxes?ref=docs-labs-agents-calling-home).

## The model writes code

You want the model to read the CI log of every open pull request without a turn for each. Give the sandbox's code tools your `readLog` tool.

<AnnotatedCode>

{/* not type-checked: sandbox.tools.code({ tools }), which gives the model work_run_code */}
```typescript {{ title: "inngest/sandboxes/work.ts" }}
import { secret } from "inngest/experimental";
import { sandbox } from "inngest/experimental/agents";
import { readLog } from "../tools/readLog";

export const work = sandbox({
  id: "work",
  repo: {
    url: "https://github.com/acme/web",
    auth: {
      read: secret("GITHUB_READ_TOKEN"),
      write: secret("GITHUB_WRITE_TOKEN"),
    },
    policy: (push) => {
      if (push.branch === "main") {
        return { refuse: "Never push to main" };
      }
    },
  },
  tools: sandbox.tools.code({ tools: { readLog } }),
});
```

<Annotation id="tools" lines="19" tease="adds work_run_code" title="Tools for scripts" href="/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-calling-home#code-tools" linkText="Reference: code tools">
Passing `tools` to the code tools adds `work_run_code`. A script calls each by its key in the record, as `tools.readLog(...)`.
</Annotation>

</AnnotatedCode>

The model writes one script and runs it with `work_run_code`:

```python {{ title: "A script the model writes" }}
failing = []

for pr in [41, 42, 43, 44, 45]:
    log = await tools.readLog(pr=pr)

    if "FAIL" in log:
        failing.append(pr)

print(failing)
```

Each `readLog` is a step in your trace. The tool and the CI helper are as [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-calling-home) left them:

```typescript {{ title: "inngest/lib/ci.ts" }}
export const fetchLog = async (pr: number) => {
  const response = await fetch(`https://ci.acme.test/prs/${pr}/log`);

  if (!response.ok) {
    throw new Error(`CI log for #${pr}: ${response.status}`);
  }

  return await response.text();
};
```

```typescript {{ title: "inngest/tools/readLog.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { fetchLog } from "../lib/ci";

export const readLog = tool.step({
  description: "Reads the CI log of a pull request",
  input: z.object({ pr: z.number() }),
  run: async ({ pr }) => {
    return await fetchLog(pr);
  },
});
```

## Your scope, from its code

You want the script to do what only your run can, such as saving thread state and commenting on the PR. Make the tool inside the handler.

<AnnotatedCode>

{/* not type-checked: a tool made in the handler and passed with loop(batch, { tools }) */}
```typescript {{ title: "inngest/agents/prHelper.ts" }}
import { tool } from "inngest/experimental";
import { kv, skills } from "inngest/experimental/agents";
import { z } from "zod";
import { agents } from "../client";
import { ciFailed, ciPassed, deployed, prOpened } from "../events";
import { gh } from "../lib/github";
import { claude } from "../models/claude";
import { work } from "../sandboxes/work";
import { comment } from "../tools/comment";
import { readLog } from "../tools/readLog";

const triggers = [
  prOpened,
  ciFailed,
  { event: deployed, thread: "event.data.pull" },
];

export const prHelper = agents.agent(
  {
    id: "pr-helper",
    triggers,
    thread: "event.data.pr",
    inbox: [ciPassed],
    idle: "1h",
    model: claude,
    system: "You help with pull requests on acme/web.",
    budget: { usd: 0.5 },
    tools: { readLog, comment },
    sandboxes: { work },
    listen: [ciPassed, ciFailed],
    skills: [skills.folder("./skills")],
  },
  async ({ inbox, loop, me, step }) => {
    const note = tool.step({
      description: "Leaves a note on this PR",
      input: z.object({ text: z.string() }),
      run: async ({ text }) => {
        await kv.thread.set("note", text);

        await gh.comment(Number(me.key), text);

        return "noted";
      },
    });

    for await (const batch of inbox.batches({ max: 20 })) {
      const result = await loop(batch, { tools: { note } });

      if (result.end === "budget") {
        await step.run("comment", async () => {
          return await gh.comment(Number(me.key), "This PR is out of budget.");
        });

        return;
      }

      await step.run("comment", async () => {
        return await gh.comment(Number(me.key), result.text);
      });
    }
  },
);
```

<Annotation id="note" lines="34-44" tease="closes over me" title="A tool made in the handler" href="/docs/labs/agents/tools?ref=docs-labs-agents-calling-home" linkText="Tools">
Its body can use `me`, `kv` and your variables. It runs as a durable step, so its comment happens once.
</Annotation>

<Annotation id="tools" lines="47" tease="for this call" title="Per-call tools" href="/docs/labs/agents/reference?ref=docs-labs-agents-calling-home#tools-passed-to-a-loop" linkText="Reference: tools passed to a loop">
Added to the agent's tools for this call. A script in the sandbox calls it by the same name.
</Annotation>

</AnnotatedCode>

The script can also write thread state and comment on the PR:

```python {{ title: "A script that calls note" }}
log = await tools.readLog(pr=42)

if "FAIL" in log:
    await tools.note(text="The checkout test is failing.")
```

The events, the client with its `sandboxMiddleware()`, and the GitHub client with its `comment` tool are as [Threads](/docs/labs/agents/threads?ref=docs-labs-agents-calling-home), [Sandboxes](/docs/labs/agents/sandboxes?ref=docs-labs-agents-calling-home#a-sandbox) and [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-calling-home#your-own-git-hub-tools) left them:

```typescript {{ title: "inngest/events.ts" }}
import { eventType } from "inngest";
import { z } from "zod";

const ciRun = z.object({ pr: z.number() });

export const prOpened = eventType("pr/opened", {
  schema: z.object({ pr: z.number(), author: z.string() }),
});

export const ciFailed = eventType("ci/run.failed", { schema: ciRun });

export const ciPassed = eventType("ci/run.passed", { schema: ciRun });

export const deployed = eventType("deploy/finished", {
  schema: z.object({ env: z.string(), pull: z.number() }),
});
```

{/* not type-checked: sandboxMiddleware() on the client */}
```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({
  id: "acme-web",
  middleware: [sandboxMiddleware()],
});

export const agents = createAgents(inngest);
```

```typescript {{ title: "inngest/lib/github.ts" }}
const api = "https://api.github.com/repos/acme/web";

export const gh = {
  comment: async (pr: number, body: string) => {
    const response = await fetch(`${api}/issues/${pr}/comments`, {
      method: "POST",
      headers: {
        accept: "application/vnd.github+json",
        authorization: `Bearer ${process.env.GITHUB_TOKEN}`,
      },
      body: JSON.stringify({ body }),
    });

    if (!response.ok) {
      throw new Error(`Comment on #${pr}: ${response.status}`);
    }

    return await response.json();
  },
};
```

```typescript {{ title: "inngest/tools/comment.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { gh } from "../lib/github";

export const comment = tool.step({
  description: "Comments on a pull request",
  input: z.object({ pr: z.number(), body: z.string() }),
  run: async ({ pr, body }) => {
    return await gh.comment(pr, body);
  },
});
```

## The keys stay home

You want a script to use a credential without being handed it. `note` comments with your app's GitHub token and `readLog` reads CI with yours, so the script sees only what they return.

Only the checkout's read token and any `sandbox({ secrets })` values enter the sandbox; the write token stays on your host. [Reference: secrets →](/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-calling-home#secrets)

## Your own scripts

You want to call the same tools from a script you wrote. Run it from [your handler's sandbox](/docs/labs/agents/sandboxes?ref=docs-labs-agents-calling-home#a-sandbox-for-your-code) and pass the tools to the command.

{/* not type-checked: sandboxes.work.commands.run with tools */}
```typescript
await sandboxes.work.commands.run("triage", "node triage.cjs", {
  tools: { readLog, note },
});
```

```js {{ title: "triage.cjs" }}
const { tools } = require("inngest_tools");

const main = async () => {
  const log = await tools.readLog({ pr: 42 });

  if (log.includes("FAIL")) {
    await tools.note({ text: "The checkout test is failing." });
  }
};

main();
```

The script finds the tools in `inngest_tools` by the names in the record. In Python, import them with `from inngest_tools import tools`. [Tools and code mode →](/docs/sandboxes/features/tools?ref=docs-labs-agents-calling-home)
