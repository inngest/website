# Teams of agents

> Hand work to another agent and use what it finds, with limits on how far it goes.

One agent can call another, wait for its result and carry on. Each callee gets a thread of its own and is traced as part of the caller's run.

<AnnotatedCode>

```typescript {{ title: "inngest/agents/lead.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { researcher } from "./researcher";

export const lead = agents.agent({ id: "lead" }, async () => {
  const found = await agent.invoke(
    researcher,
    { question: "What changed in v3?" },
    { thread: "research-1", timeout: "10m" },
  );

  return found.answer;
});
```

## Hand work to another agent

The callee uses `on: invoke(schema)` to type its input and returns its result.

```typescript {{ title: "inngest/agents/researcher.ts" }}
import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";

export const researcher = agents.agent(
  {
    id: "researcher",
    on: invoke(z.object({ question: z.string() })),
    limits: { price: { "*": { input: 3, output: 15 } } },
  },
  async ({ trigger, depth }) => {
    return { answer: `Looked into: ${trigger?.data.question}`, depth };
  },
);
```

`depth` is 1 when a function that is not an agent invoked it, 2 for the next, and `0` when anything else started the run. For an agent without a handle, pass `"appId/functionId"`; the result is then untyped.

## Call an agent from a tool

Let the model decide when to delegate. A group tool calls the agent and returns its answer.

```typescript {{ title: "inngest/tools/research.ts" }}
import { tool } from "inngest/experimental";
import { agent } from "inngest/experimental/agents";
import { z } from "zod";
import { researcher } from "../agents/researcher";

export const research = tool.group({
  description: "Ask the researcher a question",
  input: z.object({ question: z.string() }),
  run: async ({ question }) => {
    return agent.invoke(researcher, { question });
  },
});
```

## Give a sandbox to one agent

A sandbox belongs to the thread that uses it. Declare `sandboxes` on the agent that needs a machine; callers and other agents need none.

```typescript {{ title: "inngest/agents/builder.ts" }}
import { invoke } from "inngest";
import { agent } from "inngest/experimental/agents";
import { z } from "zod";
import { agents } from "../client";
import { claude } from "../models/claude";
import { workbench } from "../sandboxes/workbench";

export const builder = agents.agent(
  {
    id: "builder",
    on: invoke(z.object({ task: z.string() })),
    sandboxes: { work: workbench },
  },
  async ({ trigger, sandboxTools, control }) => {
    const result = await agent.loop({
      model: claude,
      prompt: trigger?.data.task ?? "",
      tools: sandboxTools,
      ...control,
    });

    return { summary: result.text };
  },
);
```

```typescript {{ title: "inngest/sandboxes/workbench.ts" }}
import { sandbox } from "inngest/experimental/agents";

export const workbench = sandbox({
  id: "workbench",
  tools: sandbox.tools.code(),
});
```

## Limit sub-agents

`limits` apply to `agent.invoke()`. A refused call throws `AgentLimitError`, whose `limit` is `depth`, `spawn`, `mayCall` or `budget`.

```typescript {{ title: "inngest/agents/careful.ts" }}
import { agent, AgentLimitError } from "inngest/experimental/agents";
import { agents } from "../client";
import { researcher } from "./researcher";

export const careful = agents.agent(
  {
    id: "careful",
    limits: {
      depth: 1,
      spawn: 3,
      mayCall: ["support/researcher"],
      budget: { usd: 5 },
      price: { "*": { input: 3, output: 15 } },
    },
  },
  async () => {
    try {
      const found = await agent.invoke(researcher, { question: "Why?" });

      return found.answer;
    } catch (error) {
      if (error instanceof AgentLimitError) {
        return `refused by ${error.limit}`;
      }

      throw error;
    }
  },
);
```

Sub-agents inherit the limits, narrowed, and `depth` defaults to 1. A dollar budget needs the sub-agent's own `limits.price`, since a price does not travel.

## Cancel with the caller

Cancelling the caller cancels the callee only if the callee lists `agentInvokeCancelOn`. A cancelled callee makes `agent.invoke()` throw `AgentCancelledError`.

```typescript {{ title: "inngest/agents/worker.ts" }}
import { invoke } from "inngest";
import { agentInvokeCancelOn } from "inngest/experimental/agents";
import { z } from "zod";
import { agents } from "../client";

export const worker = agents.agent(
  {
    id: "worker",
    on: invoke(z.object({ task: z.string() })),
    cancelOn: [agentInvokeCancelOn],
  },
  async ({ trigger }) => {
    return { done: trigger?.data.task };
  },
);
```

```typescript {{ title: "inngest/agents/boss.ts" }}
import { agent, AgentCancelledError } from "inngest/experimental/agents";
import { agents } from "../client";
import { worker } from "./worker";

export const boss = agents.agent({ id: "boss" }, async () => {
  try {
    return await agent.invoke(worker, { task: "audit" });
  } catch (error) {
    if (error instanceof AgentCancelledError) {
      return { done: null, cancelledRun: error.runId };
    }

    throw error;
  }
});
```

## When to use what

- Use another agent's result: `agent.invoke(agent, input)`.
- Let the model choose to delegate: a tool that calls `agent.invoke()`.
- Cap depth, fan-out or which agents may be called: `limits.depth`, `spawn`, `mayCall`.
- Cap spend across callees: `limits.budget` with a `limits.price` on each.
- End children with their parent: `cancelOn: [agentInvokeCancelOn]`.

## Options

`agent.invoke(target, input, options)` takes `id` (default `agent:invoke:<target>`), `thread` (default `<functionId>:<runId>.<n>`), `meta` and `timeout` (default none). The callee keeps the caller's session.

## Gotchas

- Use `agentInvokeCancelOn` only on an agent that `agent.invoke()` starts. `agents.agent()` throws if `on` has any other trigger.
- A raw `step.invoke` or `sendEvent` is not checked by `limits`.
- A callee's `trigger.data` is already the caller's input. A plain function uses `agentInvokeInput(event)` and `agentInvokeDepth(event)`.

## How it works

- `agent.invoke()` is a step. The caller sleeps until the callee returns.
- Limits are checked before the call starts and narrowed for the callee.
- The callee's run is a child of the caller's trace.
