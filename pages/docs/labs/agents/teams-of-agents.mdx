# Teams of agents

> Find another agent and hand it work, without wiring them together.

Agents never import each other. Each one publishes a card that says what it does. Callers find it at runtime and call it by its address.

<AnnotatedCode>

```typescript {{ title: "inngest/agents/lead.ts" }}
import { callAgent } from "inngest/experimental/agents";
import { agents } from "../client";

export const lead = agents.agent({ id: "lead" }, async () => {
  const found = await callAgent("support/researcher", {
    question: "What changed in v3?",
  });

  return found;
});
```

## Publish a card

The callee's config becomes its card. `on: invoke(schema)` types its input, and it returns its result.

```typescript {{ title: "inngest/agents/researcher.ts" }}
import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";

export const researcher = agents.agent(
  {
    id: "researcher",
    description: "Looks into a question",
    share: "team",
    on: invoke(z.object({ question: z.string() })),
    limits: { price: { "*": { input: 3, output: 15 } } },
  },
  async ({ trigger, depth }) => {
    return { answer: `Looked into: ${trigger?.data.question}`, depth };
  },
);
```

Agents in the same app find each other by default; `share: "team"` lets agents in other apps find it too. `depth` counts calls: the first callee gets 1 and its callees 2. A run no call started gets `0`.

`agents.announce()` publishes the app's cards once it is up.

```typescript {{ title: "inngest/serve.ts" }}
import { createServer } from "inngest/node";
import { agents, inngest } from "./client";
import "./agents/lead";
import "./agents/researcher";

createServer({
  client: inngest,
  functions: agents.functions(),
}).listen(3000);

await agents.announce();
```

## Let the model choose

`discoveryTools()` lets the model list agents, read their cards, and call or message the one it needs.

```typescript {{ title: "inngest/agents/delegator.ts" }}
import { agent, discoveryTools } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const delegator = agents.agent(
  { id: "delegator" },
  async ({ inbox, control }) => {
    const message = await inbox.next();

    const result = await agent.loop({
      model: claude,
      prompt: message ?? "",
      tools: discoveryTools(),
      ...control,
    });

    return result.text;
  },
);
```

The model gets `list_agents`, `describe_agent`, `call_agent` and `message_agent`. It picks by `description` and `skills`, so write those for a model to read.

## Give a sandbox to one agent

A sandbox belongs to the thread that uses it. Declare `sandboxes` on the agent that needs a machine; callers and other agents need none.

```typescript {{ title: "inngest/agents/builder.ts" }}
import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";
import { workbench } from "../sandboxes/workbench";

export const builder = agents.agent(
  {
    id: "builder",
    on: invoke(z.object({ task: z.string() })),
    sandboxes: { work: workbench },
  },
  async ({ trigger, sandboxTools }) => {
    return { task: trigger?.data.task, tools: Object.keys(sandboxTools) };
  },
);
```

```typescript {{ title: "inngest/sandboxes/workbench.ts" }}
import { sandbox } from "inngest/experimental/agents";

export const workbench = sandbox({
  id: "workbench",
  tools: sandbox.tools.code(),
});
```

## Limit sub-agents

`limits` apply to every `callAgent()`, and to every `call_agent` the model makes. A refused call throws `AgentLimitError`, whose `limit` is `depth`, `spawn`, `mayCall` or `budget`.

```typescript {{ title: "inngest/agents/careful.ts" }}
import { AgentLimitError, callAgent } from "inngest/experimental/agents";
import { agents } from "../client";

export const careful = agents.agent(
  {
    id: "careful",
    limits: { depth: 1, spawn: 3, mayCall: ["support/researcher"] },
  },
  async () => {
    try {
      return await callAgent("support/researcher", { question: "Why?" });
    } catch (error) {
      return error instanceof AgentLimitError
        ? `refused by ${error.limit}`
        : "failed";
    }
  },
);
```

Sub-agents inherit the limits, narrowed, and `depth` defaults to 1. Add `budget: { usd: 5 }` and a `price` table to cap spend; a dollar budget needs the sub-agent's own `limits.price`, since a price does not travel.

## Cancel with the caller

Cancelling the caller cancels the callee only if the callee lists `agentInvokeCancelOn`. A cancelled callee makes `callAgent()` throw `AgentCancelledError`.

```typescript {{ title: "inngest/agents/worker.ts" }}
import { invoke } from "inngest";
import { agentInvokeCancelOn } from "inngest/experimental/agents";
import { z } from "zod";
import { agents } from "../client";

export const worker = agents.agent(
  {
    id: "worker",
    on: invoke(z.object({ task: z.string() })),
    cancelOn: [agentInvokeCancelOn],
  },
  async ({ trigger }) => {
    return { done: trigger?.data.task };
  },
);
```

```typescript {{ title: "inngest/agents/boss.ts" }}
import { AgentCancelledError, callAgent } from "inngest/experimental/agents";
import { agents } from "../client";

export const boss = agents.agent({ id: "boss" }, async () => {
  try {
    return await callAgent("support/worker", { task: "audit" });
  } catch (error) {
    if (error instanceof AgentCancelledError) {
      return { done: null, cancelledRun: error.runId };
    }

    throw error;
  }
});
```

## When to use what

- Use another agent's result: `callAgent("app/agent", input)`.
- Let the model choose who to ask: `tools: discoveryTools()`.
- Look up agents in code: `findAgents(query)`.
- Let agents in other apps find yours: `share: "team"`.
- Cap depth, fan-out or which agents may be called: `limits.depth`, `spawn`, `mayCall`.
- Cap spend of callees: `limits.budget` with a `limits.price` on each, and `spawn`. A callee gets at most what is left, but the callees' total is not capped.
- End children with their parent: `cancelOn: [agentInvokeCancelOn]`.

## Options

`callAgent()` takes a step `id`. The callee keeps the caller's session and gets a thread of its own.

```typescript {{ title: "inngest/agents/patient.ts" }}
import { callAgent } from "inngest/experimental/agents";
import { agents } from "../client";

export const patient = agents.agent({ id: "patient" }, async () => {
  return callAgent(
    "support/researcher",
    { question: "Why?" },
    { id: "ask-researcher" },
  );
});
```

Defaults: `id` is `agent:invoke:<address>`, the callee's thread is `<functionId>:<runId>.<n>`, and there is no timeout. For the options of `discoveryTools()`, see the [reference](/docs/labs/agents/reference?ref=docs-labs-agents-teams-of-agents#calling-agents).

## Gotchas

- An agent can be found only after its app announced its card. A daily heartbeat announces again.
- `callAgent()` returns `unknown`. Check the shape before you use it.
- Use `agentInvokeCancelOn` only on an agent that is called. `agents.agent()` throws if `on` has any other trigger.
- A raw `step.invoke` or `sendEvent` is not checked by `limits`.

## How it works

- `callAgent()` reads the cards in a step and checks sharing.
- The call is a step. The caller sleeps until the callee returns.
- The tools check sharing on every call, so a made-up address gets nowhere.
- Limits are checked before the call starts and narrowed for the callee.
- The callee's run is a child of the caller's trace.
