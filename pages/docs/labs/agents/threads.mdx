# Threads

> Give a conversation an address, then talk to it from anywhere.

- **Send from anywhere.** `send`, `steer` and `stop` on a handle. [Handles →](#talk-to-a-thread)
- **Steer a running turn.** New messages join the next model call. [Steer →](#steer-a-running-turn)
- **Ask another thread.** `request` waits for a typed reply. [Request →](#ask-another-thread)
- **Read the inbox.** Messages in order, with timeouts. [Inbox →](#read-the-inbox)
- **Know what happened.** State, usage and how the last run ended. [State →](#read-state)
- **List threads.** Handles for every thread of an agent. [List →](#list-threads)

```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({ id: "support" });
export const agents = createAgents(inngest);
```

## Talk to a thread

A thread is a string key. `agent.thread(key)` gives its handle.

```typescript {{ title: "app/tickets.ts" }}
import { support } from "../inngest/agents/support";

const ticket = support.thread("ticket-42", "acct-9");

await ticket.send("My invoice shows the wrong amount");
await ticket.steer("Check the refund policy first");

await ticket.stop({ when: "nextTurn" });

const { stopped } = await ticket.stop({ when: "now" });
```

The second argument is the session the thread belongs to. It defaults to the key.

Without the agent's module, use its address.

```typescript {{ title: "app/script.ts" }}
import { getThread } from "inngest/experimental/agents";
import { inngest } from "../inngest/client";

const ticket = getThread(inngest, "support/support", "ticket-42");

await ticket.send("Any update?");
```

## Message kinds

Every message has a `kind`. `stop` never reaches the inbox.

```typescript {{ title: "inngest/agents/kinds.ts" }}
import { agents } from "../client";

export const kinds = agents.agent({ id: "kinds" }, async ({ inbox }) => {
  for await (const message of inbox) {
    if (message.kind === "user") {
      console.log("next turn", message.content);
    }

    if (message.kind === "steer") {
      console.log("redirect", message.content);
    }

    if (message.kind === "request") {
      await message.reply({ seen: message.payload });
    }
  }
});
```

## Steer a running turn

Spread `control` into `agent.loop()`. A `steer` message that arrives during a turn joins the next model call.

```typescript {{ title: "inngest/agents/fold.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const fold = agents.agent(
  { id: "fold", foldMessages: "all" },
  async ({ inbox, control }) => {
    for await (const message of inbox) {
      await agent.loop({
        model: claude,
        prompt: message.content ?? "",
        tools: {},
        ...control,
      });
    }
  },
);
```

`foldMessages: "all"` folds user messages in too. The default, `"steer"`, leaves them for their own turn.

## Ask another thread

Give the agent `requests` schemas. The asker gets a typed reply, or `null` after the timeout.

```typescript {{ title: "inngest/agents/billing.ts" }}
import { z } from "zod";
import { agents } from "../client";

export const billing = agents.agent(
  {
    id: "billing",
    requests: {
      request: z.object({ orderId: z.string() }),
      reply: z.object({ refundable: z.boolean() }),
    },
  },
  async ({ inbox }) => {
    for await (const message of inbox) {
      if (message.kind === "request") {
        await message.reply({ refundable: message.payload.orderId !== "" });
      }
    }
  },
);
```

```typescript {{ title: "inngest/agents/refunds.ts" }}
import { agents } from "../client";
import { billing } from "./billing";

export const refunds = agents.agent({ id: "refunds" }, async ({ inbox }) => {
  const message = await inbox.next();
  const answer = await billing
    .thread("acct-9")
    .request({ orderId: message?.content ?? "" }, { timeout: "5m" });

  if (answer === null) {
    return "billing did not answer";
  }

  return answer.refundable ? "refund" : "no refund";
});
```

`request` works inside a function and wakes an idle thread.

## Read the inbox

`next()` waits for a message. With a `timeout` it gives up with `undefined`; it returns `null` once the inbox is closed.

```typescript {{ title: "inngest/agents/poll.ts" }}
import { agents } from "../client";

export const poll = agents.agent({ id: "poll" }, async ({ inbox }) => {
  while (true) {
    const message = await inbox.next({ timeout: "10m" });

    if (message === null) {
      return "closed";
    }

    if (message === undefined) {
      console.log("quiet for ten minutes");

      continue;
    }

    const waiting = await inbox.unread();
    inbox.putBack(waiting);

    console.log(message.content, (await inbox.current()).length);
  }
});
```

`current()` lists saved messages, `unread()` takes the rest, `putBack()` returns them. `of(type)` and `listen()` are in [Events and triggers](/docs/labs/agents/events-and-triggers?ref=docs-labs-agents-threads#inbox-sources).

## Acknowledge arrivals

`onArrival` runs for each message that reaches a busy thread. It runs in its own function, so it never waits for the turn.

```typescript {{ title: "inngest/agents/ack.ts" }}
import { agents } from "../client";

export const ack = agents.agent(
  {
    id: "ack",
    onArrival: async ({ thread, message, step }) => {
      await step.sendEvent("ack", {
        name: "support/ack",
        data: { thread, kind: message.kind },
      });
    },
  },
  async ({ inbox }) => {
    for await (const message of inbox) {
      console.log(message.content);
    }
  },
);
```

## Read state

`state()` reads the thread's KV, so it works with no run live.

```typescript {{ title: "app/state.ts" }}
import { support } from "../inngest/agents/support";

const ticket = support.thread("ticket-42");

const { status, turn, summary, usage, keys, lastRun } = await ticket.state();
```

`status` is `running`, `waiting`, `stopped` or `idle`. `usage` sums every model call, with `usd` when the agent has a [`limits.price`](/docs/labs/agents/loop?ref=docs-labs-agents-threads#price-and-budget).

Inside the body, `previousRun` says how the run before this one ended, and `restarts` counts the times this run continued in another process.

```typescript {{ title: "inngest/agents/resume.ts" }}
import { agents } from "../client";

export const resume = agents.agent(
  { id: "resume", recovery: true },
  async ({ inbox, previousRun, restarts, thread }) => {
    if (previousRun?.status === "failed") {
      console.log("last run failed:", previousRun.error);
    }

    console.log(thread.key, thread.session, restarts);

    for await (const message of inbox) {
      console.log(message.content);
    }
  },
);
```

## List threads

`threads.list()` returns handles, most recently messaged first.

```typescript {{ title: "app/list.ts" }}
import { support } from "../inngest/agents/support";

const recent = await support.threads.list({ session: "acct-9", limit: 20 });

for (const thread of recent) {
  console.log(thread.key, (await thread.state()).status);
}
```

Listing uses Insights, which the Dev Server does not serve. Pass `query` to read the messages another way.

## How it works

- A message is an `agent/message` event. It starts a run when none is live.
- One run is live per thread. A message sent during a run joins its inbox.
- The inbox closes when the body returns. A later message is dropped.
- Thread state lives in the KV store you give `createAgents`.
