# Reliability

> Leave an agent running: it retries what fails, caps its own spend and picks up after a crash or a deploy.

Every model call and tool call is a [durable step](/docs/labs/agents/agents?ref=docs-labs-agents-reliability#steps), so a retry never repeats finished work.

- **Cap spend and turns.** No runaway loops. [Caps →](#cap-spend)
- **Recover.** Rate limits wait; a failed run picks up. [Recovery →](#recover-from-failures)
- **Run long.** Deploys, `idle` and the step limit. [Long runs →](#deploys-and-long-runs)

<AnnotatedCode>

{/* not type-checked: budget, limits and recovery on an agent definition, result.end and result.reason */}
```typescript {{ title: "inngest/agents/support.ts" }}
import { slack } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const support = agents.agent(
  {
    id: "support",
    triggers: [slack.thread()],
    model: claude,
    system: "You answer support questions.",
    budget: { usd: 2, tokens: 500_000 },
    limits: { depth: 2, mayCall: ["support/researcher"] },
    recovery: true,
  },
  async ({ inbox, me, loop }) => {
    for await (const batch of inbox.batches()) {
      const result = await loop(batch);

      if (result.end === "budget") {
        await me.post(result.reason);

        return;
      }

      await me.post(result.text);
    }
  },
);
```

## Cap spend

`budget` caps what one thread spends across all its runs, kept in thread state. The model prices its own calls; `price` overrides its rates.

<AnnotatedCode>

{/* not type-checked: price as a per-million-token table */}
```typescript {{ title: "inngest/agents/summarizer.ts" }}
import { slack } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const summarizer = agents.agent({
  id: "summarizer",
  triggers: [slack.thread()],
  model: claude,
  system: "Summarize the thread in three lines.",
  budget: { usd: 1 },
  price: {
    "*": { input: 2.5, output: 12.5 },
  },
});
```

<Annotation id="price" lines="11-13" tease="dollars per million tokens" title="Price" href="/docs/labs/agents/reference?ref=docs-labs-agents-reliability#budget-and-price" linkText="Reference: budget and price">
`"*"` is the rate for any model not named.
</Annotation>

</AnnotatedCode>

## Cap turns

A loop that keeps calling tools stops after `maxTurns` (40 by default). An agent with no handler sets it as `loop: { maxTurns: 10 }` on its definition.

<AnnotatedCode>

{/* not type-checked: maxTurns as a per-call loop option and end: "maxTurns" */}
```typescript {{ title: "inngest/agents/lookup.ts" }}
import { slack } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const lookup = agents.agent(
  {
    id: "lookup",
    triggers: [slack.thread()],
    model: claude,
    system: "Answer from the docs.",
  },
  async ({ inbox, me, loop }) => {
    for await (const batch of inbox.batches()) {
      const result = await loop(batch, { maxTurns: 10 });

      if (result.end === "maxTurns") {
        await me.post("I ran out of turns before I finished.");

        continue;
      }

      await me.post(result.text);
    }
  },
);
```

<Annotation id="turns" lines="14" tease="for this call" title="maxTurns" href="/docs/labs/agents/reference?ref=docs-labs-agents-reliability#the-loop" linkText="Reference: the loop">
A loop option, so each call can have its own.
</Annotation>

</AnnotatedCode>

## Recover from failures

A rate limit waits for the provider's `retry-after`, for any model. A final error such as a rejected request isn't retried.

A run that fails for good posts one line where the thread lives. With `recovery`, the message it was handling goes to a fresh run.

<AnnotatedCode>

{/* not type-checked: recovery with a message function */}
```typescript {{ title: "inngest/agents/releaser.ts" }}
import { slack } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const releaser = agents.agent({
  id: "releaser",
  triggers: [slack.thread()],
  model: claude,
  system: "You run releases.",
  recovery: {
    message: (failure) => {
      return `That run failed: ${failure.error}`;
    },
  },
});
```

<Annotation id="message" lines="10-14" tease="the line it posts" title="Message" href="/docs/labs/agents/reference?ref=docs-labs-agents-reliability#recovery" linkText="Reference: recovery">
`message` writes the line; `{ resume: false }` keeps it but skips the fresh run.
</Annotation>

</AnnotatedCode>

The same error is never resent, and neither is a `NonRetriableError`. A handler's [`previousRun`](/docs/labs/agents/reference?ref=docs-labs-agents-reliability#the-handler) says how the last run ended.

## Deploys and long runs

After a deploy, a live run replays on your latest code. Every model call, tool call, awaited post and inbox message is a step toward the 1,000-step limit. So is a KV call made outside a step. [Limits →](/docs/durable-execution/limits?ref=docs-labs-agents-reliability#platform-limits)

Keep the default `idle` of ten minutes unless the agent waits on something slow, such as a pull request. A longer `idle` keeps the run live across deploys and spends steps.

<AnnotatedCode>

{/* not type-checked: idle as a duration string on an agent that waits for GitHub events */}
```typescript {{ title: "inngest/agents/babysitter.ts" }}
import { github } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const babysitter = agents.agent({
  id: "babysitter",
  triggers: [github.thread()],
  model: claude,
  system: "Watch the pull request until it merges.",
  idle: "7d",
});
```

<Annotation id="idle" lines="10" tease="a week-long run" title="A long idle" href="/docs/labs/agents/inboxes?ref=docs-labs-agents-reliability#going-quiet" linkText="Going quiet">
Live across every deploy.
</Annotation>

</AnnotatedCode>

## Gotchas

- **A spent budget stays spent.** Later messages end at once.
- **A cancelled run isn't recovered.**
