# Reliability

> Leave an agent running: it retries what fails, caps its own spend and picks up after a crash or a deploy.

Every model call and tool call is a [durable step](/docs/labs/agents/agents?ref=docs-labs-agents-reliability#steps), so a retry never repeats finished work.

- **Cap spend and turns.** No runaway loops. [Caps →](#cap-spend)
- **Recover.** Rate limits wait; a failed run picks up. [Recovery →](#recover-from-failures)
- **Run long.** Deploys, `idle` and the step limit. [Long runs →](#deploys-and-long-runs)

```typescript {{ title: "inngest/agents/support.ts" }}
import { agents } from "../client";
import { ticketOpened, ticketReplied } from "../events";
import { claude } from "../models/claude";

export const support = agents.agent(
  {
    id: "support",
    triggers: [ticketOpened],
    thread: "event.data.ticket",
    inbox: [ticketReplied],
    model: claude,
    system: "You answer support questions.",
    budget: { usd: 2, tokens: 500_000 },
    limits: { depth: 2, mayCall: ["support/researcher"] },
    recovery: true,
  },
  async ({ inbox, loop }) => {
    let answer = "";

    for await (const batch of inbox.batches()) {
      const result = await loop(batch);

      if (result.end === "budget") {
        return result.reason;
      }

      answer = result.text;
    }

    return answer;
  },
);
```

## Cap spend

`budget` caps what one thread spends across all its runs, kept in thread state. The model prices its own calls; `price` overrides its rates. With no handler, a spent budget ends the loop: the run's output is the model's last text, and the trace shows `end` as `"budget"`.

```typescript {{ title: "inngest/agents/summarizer.ts" }}
  triggers: [ticketOpened],
  thread: "event.data.ticket",
  model: claude,
  system: "Summarize the ticket in three lines.",
```

## Cap turns

A loop that keeps calling tools stops after `maxTurns` (40 by default). An agent with no handler sets it as `loop: { maxTurns: 10 }` on its definition.

<AnnotatedCode>

{/* not type-checked: maxTurns as a per-call loop option and end: "maxTurns" */}
```typescript {{ title: "inngest/agents/lookup.ts" }}
import { agents } from "../client";
import { ticketOpened } from "../events";
import { claude } from "../models/claude";

export const lookup = agents.agent(
  {
    id: "lookup",
    triggers: [ticketOpened],
    thread: "event.data.ticket",
    model: claude,
    system: "Answer from the docs.",
  },
  async ({ inbox, loop }) => {
    let answer = "";

    for await (const batch of inbox.batches()) {
      const result = await loop(batch, { maxTurns: 10 });

      if (result.end === "maxTurns") {
        return "I ran out of turns before I finished.";
      }

      answer = result.text;
    }

    return answer;
  },
);
```

## Recover from failures

A rate limit waits for the provider's `retry-after`, for any model. A final error such as a rejected request isn't retried.

A run that fails for good shows its error in the trace. With `recovery: true`, the message it was handling goes to a fresh run. The same error is never resent, nor is a `NonRetriableError`, and a message is resent for at most three kinds of error.

Every next run gets [`previousRun`](/docs/labs/agents/reference?ref=docs-labs-agents-reliability#the-handler), with or without `recovery`. It is `{ runId, status, at, error? }` and says how the last run ended: `status` is `"completed"`, `"failed"` or `"cancelled"`, and `at` is milliseconds since the epoch.

## Deploys and long runs

After a deploy, a live run replays on your latest code. Every model call, tool call, `step.run` of your own and inbox message is a step toward the 1,000-step limit. So is a KV call made outside a step. [Limits →](/docs/durable-execution/limits?ref=docs-labs-agents-reliability#platform-limits)

Keep the default `idle` of ten minutes unless the agent waits on something slow, such as a customer's reply. A longer `idle` keeps the run live across deploys, spends steps and keeps the thread's sandbox running.

## Gotchas

- **A spent budget stays spent.** Later messages end at once.
- **A cancelled run isn't recovered.**
- **Work you don't await is stopped** when the handler returns. An un-awaited `score()` is still written.
