# Which API?

> Find the call for what you want. Each row links to the page that teaches it.

## Read messages

| When you want | Use | Learn |
| --- | --- | --- |
| Handle every message in order | `for await (const message of inbox)` | [Read the inbox](/docs/labs/agents/threads?ref=docs-labs-agents-which-api#read-the-inbox) |
| The newest request to win | `inbox.of(type).current()` or `.unread()`, then take the last | [Inbox sources](/docs/labs/agents/events-and-triggers?ref=docs-labs-agents-which-api#inbox-sources) |
| Never wait for a message | `inbox.next({ timeout: 0 })` | [Wait and catch up](/docs/labs/agents/subscribe?ref=docs-labs-agents-which-api#wait-and-catch-up) |
| Give up after a while | `inbox.next({ timeout: "10m" })` returns `undefined` | [Read the inbox](/docs/labs/agents/threads?ref=docs-labs-agents-which-api#read-the-inbox) |
| Take what arrived while you worked | `inbox.unread()` | [Wait and catch up](/docs/labs/agents/subscribe?ref=docs-labs-agents-which-api#wait-and-catch-up) |
| List every message so far without moving | `inbox.current()` | [Wait and catch up](/docs/labs/agents/subscribe?ref=docs-labs-agents-which-api#wait-and-catch-up) |
| Hand messages back for later | `inbox.putBack(messages)` | [Read the inbox](/docs/labs/agents/threads?ref=docs-labs-agents-which-api#read-the-inbox) |
| Listen to another event mid-run | `inbox.listen(type, { thread })` | [Inbox sources](/docs/labs/agents/events-and-triggers?ref=docs-labs-agents-which-api#inbox-sources) |
| Let the model listen too | `inboxTools` | [Let a model listen](/docs/labs/agents/subscribe?ref=docs-labs-agents-which-api#let-a-model-listen) |
| Acknowledge a message that reaches a busy thread | `onArrival` | [Acknowledge arrivals](/docs/labs/agents/threads?ref=docs-labs-agents-which-api#acknowledge-arrivals) |
