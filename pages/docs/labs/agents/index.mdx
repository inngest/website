# Inngest Agents

> Build agents that keep a thread going for days, take new messages mid-task, and never repeat finished work.

<Info>
  Inngest Agents is experimental and moves fast. Import it from `inngest/experimental/agents`; the API may change between releases. [What's Labs?](/docs/labs?ref=docs-labs-agents)
</Info>

An agent is an Inngest function that holds conversations. Every model call and tool call is a durable step, so a crash or a deploy never repeats one.

- **No loop to write.** A model, a prompt and tools make a whole agent. [Agents and triggers →](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents)
- **Threads that remember.** A Slack thread, a pull request or a customer is one thread, with its history and state. [Threads and memory →](/docs/labs/agents/threads-and-memory?ref=docs-labs-agents)
- **New messages reach the model mid-task.** Everything that arrives lands in the next model call. [Inboxes →](/docs/labs/agents/inboxes?ref=docs-labs-agents)
- **A machine per thread.** The model works in a shell that's still there next week. [Sandboxes and code →](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents)
- **Agents that find each other.** The model looks up other agents and hands them work. [Discovery →](/docs/labs/agents/discovery?ref=docs-labs-agents)

{/* not type-checked: an agent with no handler in Slack */}
```typescript {{ title: "inngest/agents/support.ts" }}
import { slack } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { lookupOrder } from "../tools/lookupOrder";

export const support = agents.agent({
  id: "support",
  triggers: [slack.thread()],
  model: claude,
  system: "You answer questions about orders.",
  tools: { lookupOrder },
});
```

```typescript {{ title: "inngest/tools/lookupOrder.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";

export const lookupOrder = tool.step({
  description: "Find an order by ID",
  input: z.object({ id: z.string() }),
  run: async ({ id }) => {
    return { id, status: "shipped", eta: "Friday" };
  },
});
```

Mention it in Slack and it answers in the thread, with a status line while it works. A reply days later picks up the same thread.

## Concepts

Read them in order, or jump to the one you need.

1. [Agents and triggers](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents): define an agent and what starts it.
2. [Handlers](/docs/labs/agents/handlers?ref=docs-labs-agents): your code around the model.
3. [Threads and memory](/docs/labs/agents/threads-and-memory?ref=docs-labs-agents): one key per thread, and state that lasts.
4. [Models and the loop](/docs/labs/agents/models-and-the-loop?ref=docs-labs-agents): turns, tools, history and cost.
5. [Inboxes](/docs/labs/agents/inboxes?ref=docs-labs-agents): messages in order, and events the agent watches.
6. [Tools](/docs/labs/agents/tools?ref=docs-labs-agents): functions in your app that the model and scripts call.
7. [Slack and GitHub](/docs/labs/agents/slack-and-github?ref=docs-labs-agents): start from a thread, answer in it.
8. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents): a machine per thread, and repos the app pushes.
9. [Skills](/docs/labs/agents/skills?ref=docs-labs-agents): know-how the model reads when it needs it.
10. [Teams of agents](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents): start an agent, talk to it, wait for its result.
11. [Discovery](/docs/labs/agents/discovery?ref=docs-labs-agents): cards, and how agents find each other.
12. [Reliability](/docs/labs/agents/reliability?ref=docs-labs-agents): retries, budgets and recovery.
13. [Observability](/docs/labs/agents/observability?ref=docs-labs-agents): traces, usage and scores.

## Recipes

- [Slack assistant](/docs/labs/agents/recipes/slack-assistant?ref=docs-labs-agents): answers in a thread and remembers what the team tells it.
- [Issue triage](/docs/labs/agents/recipes/issue-triage?ref=docs-labs-agents): labels new issues and links duplicates.
- [PR reviewer](/docs/labs/agents/recipes/pr-reviewer?ref=docs-labs-agents): checks out a pull request, runs its tests and reviews it.
- [Coding agent](/docs/labs/agents/recipes/coding-agent?ref=docs-labs-agents): changes a repository on a branch without holding the write token.
- [Scheduled watcher](/docs/labs/agents/recipes/scheduled-watcher?ref=docs-labs-agents): a weekday digest, as a plain function.
- [Agent teams](/docs/labs/agents/recipes/agent-teams?ref=docs-labs-agents): a lead that finds specialists and combines their answers.
- [MCP assistant](/docs/labs/agents/recipes/mcp-assistant?ref=docs-labs-agents): works in each person's own account on a remote MCP server.
- [Sandbox tools](/docs/labs/agents/recipes/sandbox-tools?ref=docs-labs-agents): answers by writing a script that calls your tools.
