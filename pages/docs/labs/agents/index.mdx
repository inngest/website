# Inngest Agents

> Build AI agents as durable functions that keep a conversation for days, take new messages while they work, and never repeat finished work.

Inngest Agents lets you define an agent with a model, a system prompt, and tools, and run it on Inngest. Each conversation is a thread that keeps its history between runs. Messages that arrive while the agent works reach the model on its next call. Every model call and tool call is a durable step, so a crash or a deploy never repeats work that already finished.

```typescript {{ title: "inngest/agents/support.ts" }}
export const support = agents.agent({
  id: "support",
  triggers: [ticketOpened, ticketReplied],
  thread: "event.data.ticket",
  model: claude,
  system: "You answer customer questions about orders.",
  tools: { lookupOrder, sendReply },
});
```

## What you can do

- **Define an agent without writing a loop.** A model, a system prompt, and tools make a complete agent. Write a handler when you want control over each turn. See [Models and the loop](/docs/labs/agents/models?ref=docs-labs-agents).
- **Keep conversations across runs.** Name a thread from your events, such as a ticket or a pull request, and every run on it shares the model's history and your own state. See [Threads](/docs/labs/agents/threads?ref=docs-labs-agents).
- **Take new messages mid-task.** Messages that arrive while the agent works wait in its inbox and reach the model on its next call. See [Inboxes](/docs/labs/agents/inboxes?ref=docs-labs-agents).
- **Act through your own code.** Tools run in your app as durable steps, with your credentials. Connect MCP servers and share tools between apps. See [Tools](/docs/labs/agents/tools?ref=docs-labs-agents).
- **Give each thread a machine.** A sandbox gives the model a shell, files, and a checked-out repository that are still there on the next message. See [Sandboxes](/docs/labs/agents/sandboxes?ref=docs-labs-agents).
- **Build teams of agents.** Agents start other agents, talk to them while they work, and find each other at run time. See [Agent teams](/docs/labs/agents/agent-teams?ref=docs-labs-agents).
- **See and score every run.** Each model call, tool call, and message is a row in the run's trace, with usage, cost, and scores. See [Observability](/docs/labs/agents/observability?ref=docs-labs-agents).
