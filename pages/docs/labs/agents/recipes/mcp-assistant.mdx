# MCP assistant

> An agent that works in each person's own account on a remote MCP server.

Each person signs in once, and the model never sees the link or a token.

```text
Maya        What's in my Notion roadmap page?
Assistant   I sent you a link to connect Notion. Ask again once connected.
Maya        (signs in with Notion in the browser)
Maya        What's in my roadmap page?
Assistant   Your roadmap has three items: ...
```

Screenshot needed: the sign-in link in Slack, then the answer.

export const notion = tool.mcp({

## What it shows off

- [Per-person sign-in](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-mcp-assistant#sign-in-each-person) lets each person work as themselves.
- [A one-line callback](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-mcp-assistant#sign-in-each-person) finishes the sign-in.
- [A Slack agent with no handler](/docs/labs/agents/slack-and-github?ref=docs-labs-agents-recipes-mcp-assistant) needs only a signed Slack route.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-mcp-assistant#install), in a Next.js app.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export MCP_OAUTH_ENCRYPTION_KEY=$(openssl rand -base64 32)
export SLACK_BOT_TOKEN=xoxb-...
export SLACK_SIGNING_SECRET=...
npm run dev
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

Set up the Slack app as on [Slack and GitHub](/docs/labs/agents/slack-and-github?ref=docs-labs-agents-recipes-mcp-assistant#add-the-route), and set `redirectUri` to your app's public address. Mention the agent, ask about Notion and open the run at [localhost:8288](http://localhost:8288).

## Variations

- [A shared token](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-mcp-assistant#connect-an-mcp-server) serves a server that has one: `auth: { bearer: secret("TOKEN") }`.
- [Disconnecting](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-mcp-assistant#sign-in-each-person) revokes one person's connection with `notion.disconnect(user)`.
