# MCP assistant

> An agent that works in each person's own account on a remote MCP server.

```text
Maya   What's in my Notion roadmap page?
Bot    Connect Notion first: https://mcp.notion.com/authorize?...
Maya   (approves)
Bot    Your roadmap has three items: ...
```

## The code

<AnnotatedCode>

```typescript {{ title: "inngest/agents/assistant.ts" }}
import { tool, kvOAuthStore } from "inngest/experimental";
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const store = kvOAuthStore();

export const assistant = agents.agent({ id: "assistant" }, async ({ event, inbox, control }) => {
  const asker = event.data.user as string;
  const notion = tool.mcp({
    url: "https://mcp.notion.com/mcp",
    auth: { oauth: { user: asker, redirectUri: "https://app.acme.test/oauth/mcp", store } },
  });

  for await (const message of inbox) {
    await agent.loop({ model: claude, prompt: message, tools: { notion }, ...control });
  }
});
```

```typescript {{ title: "inngest/routes/mcpCallback.ts" }}
import { completeMcpAuthorization } from "inngest/experimental";
import { inngest } from "../client";
import { store } from "../agents/assistant";

export async function mcpCallback(query: { code: string; state: string; error?: string }, signedInUser: string) {
  await completeMcpAuthorization({
    store,
    code: query.code,
    state: query.state,
    error: query.error,
    expectUser: signedInUser,
    send: (event) => {
      return inngest.send(event);
    },
  });
}
```

`inngest/client.ts`, `inngest/models/claude.ts` and `inngest/serve.ts` follow the [Slack assistant](/docs/labs/agents/recipes/slack-assistant?ref=docs-labs-agents-recipes-mcp-assistant).

## What it shows off

- A remote server's tools, with no token in the model, a trace or a step output. [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-mcp-assistant#use-a-remote-mcp-server)
- Each person signs in once and works as themselves. [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-mcp-assistant#connect-each-persons-account)
- Pause until they connect with `waitForMcpAuthorization()`. [Reference](/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-mcp-assistant#per-user-oauth)

## Run it

```bash
export ANTHROPIC_API_KEY=sk-ant-... MCP_OAUTH_ENCRYPTION_KEY=$(openssl rand -base64 32) INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
node --import tsx inngest/serve.ts
```

Your callback route must know who is signed in: pass that user as `expectUser`.

## Variations

- A server with a fixed token: `auth: { bearer: secret("TOKEN") }`. [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-mcp-assistant#use-a-remote-mcp-server)
- A server with no dynamic registration: set `clientId` and `clientSecret`. [Reference](/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-mcp-assistant#per-user-oauth)
