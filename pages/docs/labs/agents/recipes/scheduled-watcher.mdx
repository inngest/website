# Scheduled watcher

> A weekday digest that speaks up only when there is news.

It has no thread, inbox or card, so it is a plain function and not an agent. [Agent or plain function →](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-scheduled-watcher#not-everything-is-an-agent)

```text
Mon 09:00   Watcher
            Stale pull requests in acme/app:
            #301 Add retries to webhooks, maya, idle 5 days
            #288 Bump vitest, dan, idle 4 days

Tue 09:00   (nothing posted: no pull request went stale)
```

```typescript {{ title: "inngest/functions/watcher.ts" }}
import { kv } from "inngest/experimental/agents";
import { z } from "zod";
import { inngest } from "../client";
import { claude } from "../models/claude";
import { findStalePulls } from "./findStalePulls";
import { postToSlack } from "./postToSlack";

const reported = kv.key("reported", z.array(z.number()));

export const watcher = inngest.createFunction(
  { id: "watcher", triggers: [{ cron: "TZ=UTC 0 9 * * 1-5" }] },
  async ({ step }) => {
    const seen = (await kv.app.get(reported)) ?? [];

    const stale = await step.run("find-stale", async () => {
      return await findStalePulls(seen);
    });

    if (stale.length === 0) {
      return;
    }

    const digest = await step.run("digest", async () => {
      const { text } = await claude({
        system: "One line per pull request, oldest first, for the team.",
        prompt: JSON.stringify(stale),
      });

      return text;
    });

    await step.run("post", async () => {
      await postToSlack(digest);
    });

    const numbers = stale.map((pull) => {
      return pull.number;
    });

    await kv.app.update(reported, (current) => {
      return [...(current ?? []), ...numbers];
    });
  },
);
```

```typescript {{ title: "inngest/functions/findStalePulls.ts" }}
export const findStalePulls = async (seen: number[]) => {
  const token = process.env.GITHUB_TOKEN;

  if (!token) {
    throw new Error("Set GITHUB_TOKEN");
  }

  const query = "state=open&sort=updated&direction=asc";

  const response = await fetch(
    `https://api.github.com/repos/acme/app/pulls?${query}`,
    { headers: { authorization: `Bearer ${token}` } },
  );

  if (!response.ok) {
    throw new Error(`GitHub ${response.status}: ${await response.text()}`);
  }

  const pulls = (await response.json()) as {
    number: number;
    title: string;
    updated_at: string;
    user: { login: string };
  }[];

  const cutoff = Date.now() - 3 * 86_400_000;

  return pulls
    .filter((pull) => {
      const idle = Date.parse(pull.updated_at) < cutoff;

      return idle && !seen.includes(pull.number);
    })
    .map((pull) => {
      return {
        number: pull.number,
        title: pull.title,
        author: pull.user.login,
        updated: pull.updated_at,
      };
    });
};
```

```typescript {{ title: "inngest/functions/postToSlack.ts" }}
export const postToSlack = async (text: string) => {
  const webhook = process.env.SLACK_WEBHOOK_URL;

  if (!webhook) {
    throw new Error("Set SLACK_WEBHOOK_URL");
  }

  const response = await fetch(webhook, {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({ text }),
  });

  if (!response.ok) {
    throw new Error(`Slack answered ${response.status}`);
  }
};
```

## What it shows off

- [A plain function](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-scheduled-watcher#not-everything-is-an-agent) runs a schedule with steps and no agent.
- [One model call](/docs/labs/agents/models?ref=docs-labs-agents-recipes-scheduled-watcher#ask-a-model) writes the digest inside a step.
- [App-wide memory](/docs/labs/agents/memory?ref=docs-labs-agents-recipes-scheduled-watcher#thread-state) with a typed key remembers what was reported.
- [Retried steps](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-scheduled-watcher) keep a failed post from being marked reported.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-scheduled-watcher#install), plus a GitHub token and a Slack incoming webhook.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_TOKEN=ghp_...
export SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

Invoke `watcher` from the Functions page at [localhost:8288](http://localhost:8288) to run it before 09:00. A second invoke posts nothing.
