# Scheduled watcher

> An agent that checks every weekday morning and speaks up only when there is news.

```text
Mon 09:00   Watcher
            Stale pull requests in acme/app:
            #301 Add retries to webhooks, maya, idle 5 days
            #288 Bump vitest, dan, idle 4 days

Tue 09:00   (nothing posted: no new stale pull requests)
```

## The code

<AnnotatedCode>

```typescript {{ title: "inngest/agents/watcher.ts" }}
import { agent, kv } from "inngest/experimental/agents";
import { agents } from "../client";
import { team } from "../channels/team";
import { reported } from "../keys";
import { claude } from "../models/claude";
import { listStalePullRequests } from "../tools/listStalePullRequests";

export const watcher = agents.agent(
  {
    id: "watcher",
    on: { cron: "0 9 * * 1-5", jitter: "30s" },
    channels: { main: team },
    report: "main",
  },
  async ({ report }) => {
    const found: number[] = [];

    const result = await agent.loop({
      model: claude,
      system:
        "Write a short digest for the team: one line per pull request, oldest first. If nothing is stale, answer with exactly OK.",
      prompt: "Check acme/app for pull requests idle for 3 days or more.",
      tools: { listStalePullRequests },
      onToolResult: (run) => {
        if (!run.isError && run.name === "listStalePullRequests") {
          found.push(
            ...run.output.map((pull) => {
              return pull.number;
            }),
          );
        }
      },
    });

    if (result.text.trim() !== "OK") {
      await report(result.text);

      await kv.app.update(reported, (current) => {
        return [...(current ?? []), ...found];
      });
    }
  },
);
```

```typescript {{ title: "inngest/tools/listStalePullRequests.ts" }}
import { tool } from "inngest/experimental";
import { kv } from "inngest/experimental/agents";
import { z } from "zod";
import { reported } from "../keys";

export const listStalePullRequests = tool.step({
  description: "List open pull requests with no activity for days, not yet reported",
  input: z.object({ repo: z.string(), days: z.number() }),
  output: z.array(z.object({ number: z.number() }).passthrough()),
  run: async ({ repo, days }) => {
    const response = await fetch(
      `https://api.github.com/repos/${repo}/pulls?state=open&sort=updated&direction=asc&per_page=30`,
      { headers: { authorization: `Bearer ${process.env.GITHUB_TOKEN}` } },
    );

    const pulls = (await response.json()) as {
      number: number;
      title: string;
      updated_at: string;
      user: { login: string };
    }[];

    const cutoff = Date.now() - days * 86_400_000;
    const seen = (await kv.app.get(reported)) ?? [];

    return pulls
      .filter((pull) => {
        return (
          Date.parse(pull.updated_at) < cutoff && !seen.includes(pull.number)
        );
      })
      .map((pull) => {
        return {
          number: pull.number,
          title: pull.title,
          author: pull.user.login,
          updated: pull.updated_at,
        };
      });
  },
});
```

import { defineChannel } from "inngest/experimental/agents";

export const team = defineChannel({
  post: async (message) => {
    await fetch(process.env.SLACK_WEBHOOK_URL ?? "", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ text: message.text }),
    });
  },
});

## What it shows off

- A schedule is a trigger like any other. [Agents and triggers](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-scheduled-watcher)
- A channel you define in ten lines. [Reporting](/docs/labs/agents/reporting?ref=docs-labs-agents-recipes-scheduled-watcher)
- Memory shared by every run. [Threads and memory](/docs/labs/agents/threads-and-memory?ref=docs-labs-agents-recipes-scheduled-watcher)

## Run it

`$DEV_SERVER` is the Dev Server that `pnpm tour:devserver` builds; the published Inngest CLI does not have `step.subscribe` yet. See the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-scheduled-watcher).

```bash
$DEV_SERVER dev --no-discovery -u http://localhost:3000/api/inngest
export GITHUB_TOKEN=ghp_... SLACK_WEBHOOK_URL=https://hooks.slack.com/services/... ANTHROPIC_API_KEY=sk-ant-... INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
node --import tsx inngest/serve.ts
```

Invoke `watcher` from the Dev Server's Functions page to run it now. This recipe was type-checked against the SDK and not run.
