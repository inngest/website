# Scheduled watcher

> A weekday digest that speaks up only when there is news.

```text
Mon 09:00   Watcher
            Stale pull requests in acme/app:
            #301 Add retries to webhooks, maya, idle 5 days
            #288 Bump vitest, dan, idle 4 days

Tue 09:00   (nothing posted: no pull request went stale)
```

Screenshot needed: the digest in the team channel.

It has no thread to reply in, no inbox to read and no card to publish, so it is a plain function and not an agent. [Agent or plain function →](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-scheduled-watcher#agent-or-plain-function)

```typescript {{ title: "inngest/functions/watcher.ts" }}
import { kv } from "inngest/experimental/agents";
import { z } from "zod";
import { inngest } from "../client";
import { claude } from "../models/claude";

const reported = kv.key("reported", z.array(z.number()));

export const watcher = inngest.createFunction(
  { id: "watcher", triggers: [{ cron: "TZ=UTC 0 9 * * 1-5" }] },
  async ({ step }) => {
    const seen = (await kv.app.get(reported)) ?? [];

    const stale = await step.run("find-stale", async () => {
      const query = "state=open&sort=updated&direction=asc";
      const response = await fetch(
        `https://api.github.com/repos/acme/app/pulls?${query}`,
        { headers: { authorization: `Bearer ${process.env.GITHUB_TOKEN}` } },
      );

      const pulls = (await response.json()) as {
        number: number;
        title: string;
        updated_at: string;
        user: { login: string };
      }[];

      const cutoff = Date.now() - 3 * 86_400_000;

      return pulls
        .filter((pull) => {
          const idle = Date.parse(pull.updated_at) < cutoff;

          return idle && !seen.includes(pull.number);
        })
        .map((pull) => {
          return {
            number: pull.number,
            title: pull.title,
            author: pull.user.login,
            updated: pull.updated_at,
          };
        });
    });

    if (stale.length === 0) {
      return;
    }

    const digest = await step.run("digest", async () => {
      const { text } = await claude({
        system: "One line per pull request, oldest first, for the team.",
        prompt: JSON.stringify(stale),
      });

      return text;
    });

    await step.run("post", async () => {
      const response = await fetch(process.env.SLACK_WEBHOOK_URL ?? "", {
        method: "POST",
        headers: { "content-type": "application/json" },
        body: JSON.stringify({ text: digest }),
      });

      if (!response.ok) {
        throw new Error(`Slack answered ${response.status}`);
      }
    });

    const numbers = stale.map((pull) => {
      return pull.number;
    });

    await kv.app.update(reported, (current) => {
      return [...(current ?? []), ...numbers];
    });
  },
);
```

## What it shows off

- A schedule with steps and no agent. [Agent or plain function](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-scheduled-watcher#agent-or-plain-function)
- One model call inside a step. [Models and the loop](/docs/labs/agents/models-and-the-loop?ref=docs-labs-agents-recipes-scheduled-watcher)
- Memory shared by every run, with a typed key. [Threads and memory](/docs/labs/agents/threads-and-memory?ref=docs-labs-agents-recipes-scheduled-watcher)
- A failed post is retried and never marked reported. [Reliability](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-scheduled-watcher)

## Run it

You need the setup from the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-scheduled-watcher#install), plus a GitHub token and a Slack incoming webhook.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_TOKEN=ghp_...
export SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

Invoke `watcher` from the Dev Server's Functions page to run it before 09:00. The run shows each step, and a second invoke posts nothing.

## Variations

- Run hourly with `{ cron: "TZ=UTC 0 * * * *" }`. [Agents and triggers](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-scheduled-watcher#start-a-run)
- Remind weekly by writing the key with `kv.app.set(reported, value, { ttl: 604800 })`. [Threads and memory](/docs/labs/agents/threads-and-memory?ref=docs-labs-agents-recipes-scheduled-watcher)
- Start an agent from the function with `start()` when a digest needs a conversation. [Teams of agents](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-scheduled-watcher)
