# PR reviewer

> An agent that checks out a pull request, runs its tests and reviews it in a comment.

Opening a pull request starts the review, and nothing the agent runs can push.

```text
pr/opened   #42   maya

reviewer    comment on #42
  The tests pass (42 passed). Two problems:
  1. src/pagination.ts:31 skips the last page when `total` % `limit` is 0.
  2. src/pagination.test.ts has no case for an empty list.
```

Screenshot needed: the review comment on a pull request.

## The code

Your own webhook route sends `pr/opened` with `inngest.send` when a pull request opens.

```typescript {{ title: "inngest/events.ts" }}
import { eventType } from "inngest";
import { z } from "zod";

export const prOpened = eventType("pr/opened", {
  schema: z.object({ pr: z.number(), author: z.string() }),
});
```

  thread: "event.data.pr",
  model: claude,
  system:

  sandboxes: { review },
  tools: { comment },

{/* not type-checked: repo as a function of the event, repo auth as one secret(), push: false */}
```typescript {{ title: "inngest/sandboxes/review.ts" }}
import { secret } from "inngest/experimental";
import { sandbox } from "inngest/experimental/agents";

export const review = sandbox({
  id: "review",
  repo: ({ event }) => {
    return {
      url: "https://github.com/acme/web",
      ref: `refs/pull/${event.data.pr}/head`,
      auth: secret("GITHUB_READ_TOKEN"),
      push: false,
    };
  },
  tools: sandbox.tools.code({ only: ["run", "read", "search"] }),
});
```

<Annotation id="repo" lines="6-9" tease="the pull request's head" title="Check out the pull request" href="/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-pr-reviewer#repos" linkText="Reference: repos">
The head of the pull request that opened.
</Annotation>

<Annotation id="readonly" lines="10-11" tease="nothing can push" title="Read only" href="/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-pr-reviewer#repos" linkText="Reference: repos">
One read-only secret serves the checkout, and `push: false` leaves out the push tool. A changed tracked file would block the next checkout, so the prompt forbids it.
</Annotation>

<Annotation id="tools" lines="14" tease="three tools only" title="Only these tools" href="/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-pr-reviewer#code-tools" linkText="Reference: code tools">
The model gets `review_run`, `review_read` and `review_search`: no `edit`, no push.
</Annotation>

```typescript {{ title: "inngest/tools/comment.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { gh } from "../lib/github";

export const comment = tool.step({
  description: "Comments on a pull request",
  input: z.object({ pr: z.number(), body: z.string() }),
  run: async ({ pr, body }) => {
    return await gh.comment(pr, body);
  },
});
```

```typescript {{ title: "inngest/lib/github.ts" }}
const api = "https://api.github.com/repos/acme/web";

export const gh = {
  comment: async (pr: number, body: string) => {
    const response = await fetch(`${api}/issues/${pr}/comments`, {
      method: "POST",
      headers: {
        accept: "application/vnd.github+json",
        authorization: `Bearer ${process.env.GITHUB_TOKEN}`,
      },
      body: JSON.stringify({ body }),
    });

    if (!response.ok) {
      throw new Error(`Comment on #${pr}: ${response.status}`);
    }

    return await response.json();
  },
};
```

The client adds `sandboxMiddleware()`.

{/* not type-checked: createAgents with the store from the environment, sandboxMiddleware() */}
```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({
  id: "pr-reviewer",
  middleware: [sandboxMiddleware()],
});

export const agents = createAgents(inngest);
```

The [model](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-pr-reviewer#pick-a-model) is the quick start's. The serve route is the [Support assistant's](/docs/labs/agents/recipes/support-assistant?ref=docs-labs-agents-recipes-pr-reviewer), importing `inngest/agents/reviewer`.

## What it shows off

- [Your own event](/docs/labs/agents/threads?ref=docs-labs-agents-recipes-pr-reviewer#which-conversation-is-this) starts the agent on the pull request's thread.
- [A repository in the sandbox](/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-pr-reviewer#repos) is checked out at the event's ref.
- [Code tools](/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-pr-reviewer#code-tools) limit the model to a shell, `read` and `search`.
- [A comment tool](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-pr-reviewer#your-own-git-hub-tools) posts the review, so the write token stays in your app.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-pr-reviewer#install), in a Next.js app with Sandboxes.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_READ_TOKEN=ghp_...
export GITHUB_TOKEN=ghp_...
npm run dev
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

`GITHUB_READ_TOKEN` only reads `acme/web`, and `GITHUB_TOKEN` posts the review. Send a pull request from the Dev Server's **Send event** button at [localhost:8288](http://localhost:8288), or from code, with the number of an open pull request:

```typescript {{ title: "scripts/openPr.ts" }}
import { inngest } from "../inngest/client";

await inngest.send({
  name: "pr/opened",
  data: { pr: 42, author: "maya" },
});
```
