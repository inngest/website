# PR reviewer

> An agent that checks out a pull request, runs its tests and reviews it in a comment.

```text
maya     @review-bot please review

review-bot
  The tests pass (42 passed). Two problems:
  1. src/pagination.ts:31 skips the last page when `total` is a multiple of `limit`.
  2. src/pagination.test.ts has no case for an empty list.
```

## The code

<AnnotatedCode>

```typescript {{ title: "inngest/agents/reviewer.ts" }}
import { agent, github, repo } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { review } from "../sandboxes/review";

export const reviewer = agents.agent(
  {
    id: "reviewer",
    on: github.thread({
      repos: ["acme/app"],
      ignoreAuthors: ["review-bot[bot]"],
    }),
    channels: ({ event }) => {
      return { main: github.channel(event, { repos: ["acme/app"] }) };
    },
    report: "main",
    sandboxes: { work: review },
  },
  async ({ inbox, trigger, sandboxes, sandboxTools, control, report }) => {
    for await (const message of inbox) {
      const sandbox = await sandboxes.work.get();

      await repo(sandbox, {
        repo: `${trigger?.data.owner}/${trigger?.data.repo}`,
        ref: `refs/pull/${trigger?.data.number}/head`,
        path: "/work/app",
        sync: "reset",
        token: process.env.GITHUB_TOKEN,
      });

      const result = await agent.loop({
        model: claude,
        system:
          "Review the pull request checked out in /work/app. Run its tests and read the changed files. Report problems first, with file and line.",
        prompt: message,
        tools: sandboxTools,
        ...control,
      });

      await report.finish({ text: result.text });
    }
  },
);
```

```typescript {{ title: "inngest/sandboxes/review.ts" }}
import { sandbox } from "inngest/experimental/agents";

export const review = sandbox({
  id: "review",
  tools: sandbox.tools.code({
    cwd: "/work/app",
    only: ["read", "search", "run"],
  }),
});
```

```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({
  id: "pr-reviewer",
  middleware: [sandboxMiddleware()],
});

export const agents = createAgents(inngest);
```

`inngest/models/claude.ts` and `inngest/serve.ts` follow the [Slack assistant](/docs/labs/agents/recipes/slack-assistant?ref=docs-labs-agents-recipes-pr-reviewer), with `./agents/reviewer` imported.

## What it shows off

- A GitHub comment is a durable conversation. [Agents and triggers](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-pr-reviewer)
- A real machine to run the tests on. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-pr-reviewer)
- Tools limited to what a reviewer needs. [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-pr-reviewer)

## Run it

`$DEV_SERVER` is a Dev Server with `step.subscribe`; [build it once](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-pr-reviewer#see-the-run).

```bash
$DEV_SERVER dev --no-discovery -u http://localhost:3000/api/inngest
export GITHUB_TOKEN=ghp_... ANTHROPIC_API_KEY=sk-ant-... INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
node --import tsx inngest/serve.ts
```

Your GitHub route sends a `github/issue_comment` event, and decides which comments count: only those that mention the bot. It needs an environment with Sandboxes. This recipe was type-checked against the SDK and not run.
