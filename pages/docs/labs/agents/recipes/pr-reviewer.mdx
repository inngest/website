# PR reviewer

> An agent that checks out a pull request, runs its tests and reviews it in a comment.

A comment asks for the review, and nothing the agent runs can push.

```text
maya     @review-bot please review

review-bot
  The tests pass (42 passed). Two problems:
  1. src/pagination.ts:31 skips the last page when `total` % `limit` is 0.
  2. src/pagination.test.ts has no case for an empty list.
```

Screenshot needed: the review comment on a pull request.

## The code

<AnnotatedCode>

{/* not type-checked: github.thread with repos, events and if; idle as a duration */}
```typescript {{ title: "inngest/agents/reviewer.ts" }}
import { github } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { review } from "../sandboxes/review";

export const reviewer = agents.agent({
  id: "reviewer",
  triggers: [
    github.thread({
      repos: ["acme/app"],
      events: ["issue_comment"],
      if:
        'event.data.action == "created" && ' +
        "has(event.data.issue.pull_request) && " +
        'event.data.comment.body.contains("@review-bot please review")',
    }),
  ],
  idle: "1m",
  model: claude,
  system:
    "Run tests, list problems with file and line, change no tracked files.",
  sandboxes: { review },
});
```

<AnnotatedCode>

{/* not type-checked: repo as a function of the event, repo auth as a secret(), push: false */}
```typescript {{ title: "inngest/sandboxes/review.ts" }}
import { secret } from "inngest/experimental";
import { sandbox } from "inngest/experimental/agents";

export const review = sandbox({
  id: "review",
  repo: ({ event }) => {
    return {
      url: "https://github.com/acme/app",
      ref: `refs/pull/${event.data.issue.number}/head`,
      auth: secret("GITHUB_READ_TOKEN"),
      push: false,
    };
  },
  tools: sandbox.tools.code({ only: ["run", "read", "search"] }),
});
```

<Annotation id="repo" lines="6-9" tease="the pull request's head" title="Check out the pull request" href="/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-pr-reviewer#check-out-a-repo" linkText="Check out a repo">
The head of the pull request that asked.
</Annotation>

<Annotation id="readonly" lines="10-11" tease="nothing can push" title="Read only" href="/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-pr-reviewer#push-a-branch" linkText="Push a branch">
A read token and no push tool. A changed tracked file would block the next checkout, so the prompt forbids it.

GitHub calls a route in your app.

{/* not type-checked: github.bridge as a Web handler with the client and a secret */}
```typescript {{ title: "app/api/github/route.ts" }}
import { secret } from "inngest/experimental";
import { github } from "inngest/experimental/agents";
import { inngest } from "../../../inngest/client";

export const POST = github.bridge({
  client: inngest,
  secret: secret("GITHUB_WEBHOOK_SECRET"),
});
```

The client adds `sandboxMiddleware()`.

{/* not type-checked: createAgents with the store from the environment, sandboxMiddleware() */}
```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({
  id: "pr-reviewer",
  middleware: [sandboxMiddleware()],
});

export const agents = createAgents(inngest);
```

The [model](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-pr-reviewer#pick-a-model) is the quick start's. The serve route is the [Slack assistant's](/docs/labs/agents/recipes/slack-assistant?ref=docs-labs-agents-recipes-pr-reviewer), importing `inngest/agents/reviewer`.

## What it shows off

- [A GitHub comment](/docs/labs/agents/slack-and-github?ref=docs-labs-agents-recipes-pr-reviewer#work-on-git-hub) starts the agent on the pull request's thread.
- [A repository in the sandbox](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-pr-reviewer#check-out-a-repo) is checked out at the event's ref.
- [Code tools](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-pr-reviewer#work-in-a-shell) limit the model to a shell, `read` and `search`.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-pr-reviewer#install), in a Next.js app with Sandboxes.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_READ_TOKEN=ghp_...
export GITHUB_TOKEN=ghp_...
export GITHUB_WEBHOOK_SECRET=...
npm run dev
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

Add an **Issue comments** webhook pointing at `https://<your-host>/api/github`, then comment `@review-bot please review` on a pull request. `GITHUB_TOKEN` posts the review. Open the run at [localhost:8288](http://localhost:8288).
