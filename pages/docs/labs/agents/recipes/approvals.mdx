# Approvals

> An agent that asks in Slack before it merges, and waits as long as it takes.

```text
Maya   Merge acme/app#42
Bot    Merge acme/app#42?   [merge] [skip]
Maya   (clicks merge)
Bot    Merged acme/app#42.
```

## The code

```typescript {{ title: "inngest/tools/mergePullRequest.ts" }}
import { step } from "inngest";
import { tool } from "inngest/experimental";
import { askThrough, type Channel } from "inngest/experimental/agents";
import { z } from "zod";
import { github } from "../github";

export function mergePullRequest(channel: Channel) {
  return tool.group({
    description: "Merge a pull request once a person approves it",
    input: z.object({ repo: z.string(), number: z.number() }),
    waits: true,
    run: async ({ repo, number }) => {
      const signal = `merge:${repo.replace("/", ".")}:${number}`;

      await step.run("ask", async () => {
        await askThrough(channel, {
          signal,
          question: `Merge ${repo}#${number}?`,
          options: ["merge", "skip"],
          recommended: "skip",
          timeout: "1d",
        });
      });

      const answer = await step.waitForSignal("answer", {
        signal,
        timeout: "1d",
        onConflict: "replace",
      });

      if (answer?.data !== "merge") {
        return { merged: false, reason: answer ? "declined" : "no answer" };
      }

      await step.run("merge", async () => {
        await github(`/repos/${repo}/pulls/${number}/merge`, {
          method: "PUT",
        });
      });

      return { merged: true };
    },
  });
}
```

```typescript {{ title: "inngest/agents/merger.ts" }}
import { agent, slack } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { findPullRequest } from "../tools/findPullRequest";
import { mergePullRequest } from "../tools/mergePullRequest";

export const merger = agents.agent(
  {
    id: "merger",
    on: slack.thread({ in: ["C0123ABC"] }),
    channels: ({ event }) => {
      return { main: slack.channel(event, { in: ["C0123ABC"] }) };
    },
    report: "main",
  },
  async ({ inbox, channels, control, report }) => {
    const main = channels.main;

    if (!main) {
      throw new Error("The main channel is missing");
    }

    for await (const message of inbox) {
      const result = await agent.loop({
        model: claude,
        system:
          "Merge the pull request the user names, but only if it can merge.",
        prompt: message.content ?? "",
        tools: {
          findPullRequest,
          mergePullRequest: mergePullRequest(main),
        },
        ...control,
      });

      await report.finish({ text: result.text });
    }
  },
);
```

```typescript {{ title: "inngest/tools/findPullRequest.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { github } from "../github";

export const findPullRequest = tool.step({
  description: "Read a pull request: title, author and whether it can merge",
  input: z.object({ repo: z.string(), number: z.number() }),
  run: async ({ repo, number }) => {
    const pr = (await github(`/repos/${repo}/pulls/${number}`)) as {
      title: string;
      user: { login: string };
      mergeable: boolean | null;
    };

    return { title: pr.title, author: pr.user.login, mergeable: pr.mergeable };
  },
});
```

```typescript {{ title: "inngest/github.ts" }}
export async function github(path: string, init?: RequestInit) {
  const response = await fetch(`https://api.github.com${path}`, {
    ...init,
    headers: {
      accept: "application/vnd.github+json",
      authorization: `Bearer ${process.env.GITHUB_TOKEN}`,
    },
  });

  if (!response.ok) {
    throw new Error(`GitHub ${response.status}: ${await response.text()}`);
  }

  return response.json() as Promise<unknown>;
}
```

## What it shows off

- A person decides, the agent waits. [Reporting](/docs/labs/agents/reporting?ref=docs-labs-agents-recipes-approvals)
- A tool built for the run's channel. [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-approvals)
- A wait of days survives deploys and restarts. [Reliability](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-approvals)

## Run it

`$DEV_SERVER` is the Dev Server that `pnpm tour:devserver` builds; the published Inngest CLI does not have `step.subscribe` yet. See the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-approvals).

```bash
$DEV_SERVER dev --no-discovery -u http://localhost:3000/api/inngest
export SLACK_BOT_TOKEN=xoxb-... GITHUB_TOKEN=ghp_... ANTHROPIC_API_KEY=sk-ant-... INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
node --import tsx inngest/serve.ts
```

Your Slack interactivity route calls `onApprovalClick` with the button's `block_id` as the signal and its `value` as the answer. Check who clicked there: the SDK does not.

The transcript is from a run with a scripted model, a fake Slack, a stubbed GitHub and a local Dev Server. Clicking `skip` instead sent no merge request.

## Variations

- Name who may approve with `approvers`, and check it in your route. [Reporting](/docs/labs/agents/reporting?ref=docs-labs-agents-recipes-approvals)
- Approve a push instead of a merge. [Coding agent](/docs/labs/agents/recipes/coding-agent?ref=docs-labs-agents-recipes-approvals)
- Wait up to a week with `timeout: "7d"`. [Reliability](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-approvals)
- Ask in GitHub or your own tool with `defineChannel`. [Reporting](/docs/labs/agents/reporting?ref=docs-labs-agents-recipes-approvals)
