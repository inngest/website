# Support assistant

> An agent that answers every ticket and learns from what the team tells it.

It remembers each ticket across restarts, and a note saved on one ticket reaches the others.

```text
ticket/opened    T-1  Where is order 7?
Support          sendReply: Order 7 shipped with UPS and arrives Friday.

ticket/replied   T-1  maya (team): Remember: always give the carrier first.
Support          saveNote: always give the carrier first

(another ticket, an hour later)
ticket/opened    T-2  Where is order 9?
Support          sendReply: UPS (carrier first, as asked), arriving Friday.
```

Screenshot needed: the first run's trace in the Dev Server, with the `sendReply` step.

## The code

Your helpdesk's webhook route sends these two events with `inngest.send`. It sends `ticket/replied` for customer and team messages, not for the assistant's own replies.

```typescript {{ title: "inngest/events.ts" }}
import { eventType } from "inngest";
import { z } from "zod";

export const ticketOpened = eventType("ticket/opened", {
  schema: z.object({ ticket: z.string(), text: z.string() }),
});

export const ticketReplied = eventType("ticket/replied", {
  schema: z.object({
    ticket: z.string(),
    from: z.string(),
    team: z.boolean(),
    text: z.string(),
  }),
});
```

```typescript {{ title: "inngest/agents/support.ts" }}
import { kv } from "inngest/experimental/agents";
import { agents } from "../client";
import { ticketOpened, ticketReplied } from "../events";
import { claude } from "../models/claude";
import { lookupOrder } from "../tools/lookupOrder";
import { notes, saveNote } from "../tools/saveNote";
import { sendReply } from "../tools/sendReply";

export const support = agents.agent({
  id: "support",
  triggers: [ticketOpened, ticketReplied],
  thread: "event.data.ticket",
  model: claude,
  system: async () => {
    const known = (await kv.app.get(notes)) ?? [];

    return [
      "Answer each ticket and send the answer with sendReply.",
      "Call saveNote only when a message with team: true asks you to.",
      `Team notes: ${known.join("; ")}`,
    ].join("\n");
  },
  tools: { lookupOrder, saveNote, sendReply },
});
```

```typescript {{ title: "inngest/tools/sendReply.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { helpdesk } from "../lib/helpdesk";

export const sendReply = tool.step({
  description: "Sends a reply to the customer on their ticket",
  input: z.object({ ticket: z.string(), body: z.string() }),
  run: async ({ ticket, body }) => {
    return await helpdesk.reply(ticket, body);
  },
});
```

```typescript {{ title: "inngest/lib/helpdesk.ts" }}
const api = "https://helpdesk.acme.test/api";

export const helpdesk = {
  reply: async (ticket: string, body: string) => {
    const response = await fetch(`${api}/tickets/${ticket}/replies`, {
      method: "POST",
      headers: {
        authorization: `Bearer ${process.env.HELPDESK_TOKEN}`,
        "content-type": "application/json",
      },
      body: JSON.stringify({ body }),
    });

    if (!response.ok) {
      throw new Error(`Reply on ${ticket}: ${response.status}`);
    }

    return await response.json();
  },
};
```

```typescript {{ title: "inngest/tools/lookupOrder.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";

export const lookupOrder = tool.step({
  description: "Find an order by ID",
  input: z.object({ id: z.string() }),
  run: async ({ id }) => {
    return { id, status: "shipped", carrier: "UPS", eta: "Friday" };
  },
});
```

{/* not type-checked: kv.key with a schema, kv.app.update with a typed kv.key */}
```typescript {{ title: "inngest/tools/saveNote.ts" }}
import { tool } from "inngest/experimental";
import { kv } from "inngest/experimental/agents";
import { z } from "zod";

export const notes = kv.key("notes", z.array(z.string()));

export const saveNote = tool.step({
  description: "Save something the team asked you to remember",
  input: z.object({ fact: z.string() }),
  run: async ({ fact }) => {
    await kv.app.update(notes, (current) => {
      return [...(current ?? []), fact];
    });

    return { saved: fact };
  },
});
```

## What it shows off

- [Threads](/docs/labs/agents/threads?ref=docs-labs-agents-recipes-support-assistant#what-a-conversation-keeps) give each ticket its own history.
- [An agent with no handler](/docs/labs/agents/models?ref=docs-labs-agents-recipes-support-assistant#delete-the-handler) answers from a definition alone.
- [A tool you write](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-support-assistant#your-own-git-hub-tools) tells the customer, as a step that retries and never repeats.
- [App-wide memory](/docs/labs/agents/memory?ref=docs-labs-agents-recipes-support-assistant#shared-by-every-pr) is one store every ticket can read.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-support-assistant#install), in a Next.js app.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export HELPDESK_TOKEN=...
npm run dev
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

Send a ticket from the Dev Server's **Send event** button at [localhost:8288](http://localhost:8288), or from code:

```typescript {{ title: "scripts/openTicket.ts" }}
import { inngest } from "../inngest/client";

await inngest.send({
  name: "ticket/opened",
  data: { ticket: "T-1", text: "Where is order 7?" },
});
```

Then send `ticket/replied` for `T-1` with `from: "maya"`, `team: true` and `text: "Remember: always give the carrier first."`, and open `T-2`. With no helpdesk yet, swap the `fetch` in `helpdesk.reply` for a `console.log` and read the replies in the app's output.
