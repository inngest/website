# Coding agent

> An agent that changes a repository on a branch and never holds the write token.

A plain function takes the request and waits for the agent's summary. The sandbox clones with a read token; your app makes the push, after your policy has looked at it.

```text
request-change   acme/web   "Fix the off-by-one in pagination"

  coder  work_run   edit src/pagination.ts
  coder  work_run   npm test                  58 passed
  coder  work_push  agent/fix-pagination-offset

Returned: Pushed agent/fix-pagination-offset. The tests pass.
```

## The code

The sandbox holds the repository, the tokens and the push policy.

<AnnotatedCode>

{/* not type-checked: repo as a function of the event, repo auth by access, policy */}
```typescript {{ title: "inngest/sandboxes/work.ts" }}
import { sandbox } from "inngest/experimental/agents";

export const work = sandbox({
  id: "work",
  repo: ({ event }) => {
    return {
      url: `https://github.com/${event.data.repo}`,
      auth: ({ access }) => {
        if (access === "write") {
          return process.env.GITHUB_WRITE_TOKEN ?? "";
        }

        return process.env.GITHUB_READ_TOKEN ?? "";
      },
      policy: (push) => {
        if (!push.branch?.startsWith("agent/")) {
          return { refuse: "Branches for the agent start with agent/" };
        }

        const touched = push.paths.filter((path) => {
          return path.startsWith(".github/");
        });

        if (touched.length > 0) {
          return { refuse: `Not allowed to change ${touched.join(", ")}` };
        }
      },
    };
  },
});
```

The checkout asks for `read`, the push for `write`. Only your app uses the write token; it never enters the sandbox.

<Annotation id="policy" lines="15-27" tease="can refuse a push" title="Push policy" href="/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-coding-agent" linkText="Sandboxes and code">
Sees the branch and the changed files before anything is pushed, and can refuse. The model reads a refusal and can fix the branch.
</Annotation>

The agent takes a typed request and lists the sandbox. It needs no handler.

<AnnotatedCode>

{/* not type-checked: invoke() as an agent trigger, a listed sandbox with a repo */}
```typescript {{ title: "inngest/agents/coder.ts" }}
import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";
import { claude } from "../models/claude";
import { work } from "../sandboxes/work";

export const request = z.object({ repo: z.string(), task: z.string() });

export const coder = agents.agent({
  id: "coder",
  triggers: [invoke(request)],
  model: claude,
  system: [
    "Make the change on a branch named agent/<short-name>.",
    "Run the tests, push the branch and say which branch you pushed.",
  ].join(" "),
  sandboxes: { work },
});
```

<Annotation id="invoke" lines="11" tease="callers send checked input" title="A typed input" href="/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-coding-agent#take-a-typed-input" linkText="Take a typed input">
Callers send `{ repo, task }`, checked against this schema.
</Annotation>

<Annotation id="sandbox" lines="17" tease="a machine per thread" title="The sandbox" href="/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-coding-agent" linkText="Sandboxes and code">
The model gets `work_run` and `work_push`. The sandbox starts on first use, with the repository checked out.
</Annotation>

</AnnotatedCode>

The caller is a plain function. It starts the agent and waits for its answer.

<AnnotatedCode>

{/* not type-checked: start().result() from a plain function */}
```typescript {{ title: "inngest/functions/requestChange.ts" }}
import { invoke } from "inngest";
import { inngest } from "../client";
import { coder, request } from "../agents/coder";

export const requestChange = inngest.createFunction(
  { id: "request-change", triggers: [invoke(request)] },
  async ({ event }) => {
    return await coder.start(event.data).result();
  },
);
```

<Annotation id="result" lines="8" tease="start, then wait" title="Start and wait" href="/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-coding-agent" linkText="Teams of agents">
`start()` opens a thread for the agent. `result()` resolves with its answer as soon as it has given it.
</Annotation>

</AnnotatedCode>

{/* not type-checked: agents.functions() beside a plain function */}
```typescript {{ title: "inngest/serve.ts" }}
import { createServer } from "inngest/node";
import { agents, inngest } from "./client";
import { requestChange } from "./functions/requestChange";

createServer({
  client: inngest,
  functions: [...agents.functions(), requestChange],
}).listen(3000);
```

{/* not type-checked: createAgents with the store from the environment */}
```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({
  id: "coding-agent",
  middleware: [sandboxMiddleware()],
});

export const agents = createAgents(inngest);
```

`inngest/models/claude.ts` is the one from the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-coding-agent). Importing `requestChange` imports the agent, so `agents.functions()` includes it.

Another function calls `requestChange` and waits for the summary:

```typescript
const summary = await step.invoke("change", {
  function: requestChange,
  data: { repo: "acme/web", task: "Fix the off-by-one in pagination" },
});
```

## What it shows off

- [A repository in the sandbox](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-coding-agent) is cloned for you, and the request picks which one.
- [A push policy](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-coding-agent) is your code, and the write token stays in your app.
- [A typed input](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-coding-agent#take-a-typed-input) gives callers a checked request and a returned answer.
- [Start and wait](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-coding-agent) is one line in a plain function.

## Run it

Set the project up as in the quick start. It needs an environment with Sandboxes.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_READ_TOKEN=ghp_...
export GITHUB_WRITE_TOKEN=ghp_...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

In the Dev Server, open the `request-change` function, choose **Invoke** and send `{ "repo": "acme/web", "task": "Fix the off-by-one in pagination" }`. The run returns the summary.
