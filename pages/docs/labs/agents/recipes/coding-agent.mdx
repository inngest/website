# Coding agent

> An agent that changes a repository on a branch and never holds the write token.

<Info>
  Inngest Agents is an Inngest Labs project: early, moving fast, and shaped by your feedback. [What's Labs?](/docs/labs?ref=docs-labs-agents-recipes-coding-agent)
</Info>

Ask for a change in plain words and get a branch your policy allowed.

```text
request-change   acme/web   "Fix the off-by-one in pagination"

  coder  work_run   sed -i 's/offset + 1/offset/' src/pagination.ts
  coder  work_run   npm test                  58 passed
  coder  work_push  agent/fix-pagination-offset

Returned: Pushed agent/fix-pagination-offset. The tests pass.
```

## The code

<AnnotatedCode>

```typescript {{ title: "inngest/sandboxes/work.ts" }}
import { secret } from "inngest/experimental";
import { sandbox } from "inngest/experimental/agents";

export const work = sandbox({
  id: "work",
  repo: ({ event }) => {
    const { repo } = event.data as { repo: string };

    return {
      url: `https://github.com/${repo}`,
      auth: {
        read: secret("GITHUB_READ_TOKEN"),
        write: secret("GITHUB_WRITE_TOKEN"),
      },
      policy: (push) => {
        if (!push.branch?.startsWith("agent/")) {
          return { refuse: "Branches for the agent start with agent/" };
        }

        const touched = push.paths.filter((path) => {
          return path.startsWith(".github/");
        });

        if (touched.length > 0) {
          return { refuse: `Not allowed to change ${touched.join(", ")}` };
        }
      },
    };
  },
});
```

<Annotation id="repo" lines="6-10" tease="the request names it" title="The repository" href="/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-coding-agent#repos" linkText="Reference: repos">
A function of the event, so the sandbox clones the repository the request names. A sandbox is defined apart from any agent, so `event.data` is `unknown` until you state its shape.
</Annotation>

<Annotation id="auth" lines="11-14" tease="read to clone" title="Two tokens" href="/docs/labs/agents/sandboxes?ref=docs-labs-agents-recipes-coding-agent#check-out-a-repository" linkText="Check out a repo">
The read token clones the repository. The write token pushes, and stays in your app.
</Annotation>

<Annotation id="policy" lines="15-27" tease="can refuse a push" title="Push policy" href="/docs/labs/agents/sandboxes?ref=docs-labs-agents-recipes-coding-agent#check-out-a-repository" linkText="Push a branch">
Sees the branch and the changed files before anything is pushed, and can refuse. The model reads the refusal and can fix the branch.
</Annotation>

</AnnotatedCode>

<AnnotatedCode>

```typescript {{ title: "inngest/agents/coder.ts" }}
import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";
import { claude } from "../models/claude";
import { work } from "../sandboxes/work";

export const changeRequest = z.object({ repo: z.string(), task: z.string() });

export const coder = agents.agent({
  id: "coder",
  triggers: [invoke(changeRequest)],
  model: claude,
  system:
    "Work on a branch named agent/<name>, run tests, push, say which branch.",
  sandboxes: { work },
});
```

<Annotation id="invoke" lines="11" tease="callers send checked input" title="A typed input" href="/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-coding-agent#start-an-agent-from-code" linkText="Take a typed input">

<AnnotatedCode>

```typescript {{ title: "inngest/functions/requestChange.ts" }}
import { invoke } from "inngest";
import { inngest } from "../client";
import { changeRequest, coder } from "../agents/coder";

export const requestChange = inngest.createFunction(
  { id: "request-change", triggers: [invoke(changeRequest)] },
  async ({ event }) => {
    return await coder.start(event.data).result();
  },
);
```

<Annotation id="result" lines="8" tease="start, then wait" title="Start and wait" href="/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-coding-agent#start-an-agent-from-code" linkText="Wait for the result">
`result()` returns the agent's answer when its run finishes.

```typescript {{ title: "inngest/serve.ts" }}
import { createServer } from "inngest/node";
import { agents, inngest } from "./client";
import { requestChange } from "./functions/requestChange";

createServer({
  client: inngest,
  functions: [...agents.functions(), requestChange],
}).listen(3000);
```

The [model](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-coding-agent#3-choose-a-model) is the quick start's, and [the client](/docs/labs/agents/structure?ref=docs-labs-agents-recipes-coding-agent#the-client) adds `sandboxMiddleware()`. Importing `requestChange` also imports the agent, so `agents.functions()` includes it.

## How it works

- [A repository in the sandbox](/docs/labs/agents/reference-sandboxes?ref=docs-labs-agents-recipes-coding-agent#repos) is the one the request names.
- [A push policy](/docs/labs/agents/sandboxes?ref=docs-labs-agents-recipes-coding-agent#check-out-a-repository) lets your code decide what leaves the sandbox.
- [A typed input](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-coding-agent#start-an-agent-from-code) gives callers a checked request.
- [Start and wait](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-coding-agent#start-an-agent-from-code) from a plain function, in one line.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-coding-agent#1-install-the-packages), with Sandboxes.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export GITHUB_READ_TOKEN=ghp_...
export GITHUB_WRITE_TOKEN=ghp_...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

At [localhost:8288](http://localhost:8288), open `request-change`, choose **Invoke** and send `{ "repo": "acme/web", "task": "Fix the off-by-one in pagination" }`. The run returns the summary.
