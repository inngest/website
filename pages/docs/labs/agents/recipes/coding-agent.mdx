# Coding agent

> An agent that changes a repository on a branch and never holds the write token.

```text
coder/requested   acme/web   "Fix the off-by-one in pagination"

  clone  acme/web
  edit   src/pagination.ts
  run    npm test            58 passed
  push   agent/fix-pagination-offset

Returned: Pushed agent/fix-pagination-offset. The tests pass.
```

## The code

<AnnotatedCode>

```typescript {{ title: "inngest/agents/coder.ts" }}
import { eventType } from "inngest";
import { agent, repo } from "inngest/experimental/agents";
import { z } from "zod";
import { agents } from "../client";
import { claude } from "../models/claude";
import { policy } from "../policy";
import { workbench } from "../sandboxes/workbench";

export const codingRequested = eventType("coder/requested", {
  schema: z.object({ repo: z.string(), task: z.string() }),
});

export const coder = agents.agent(
  {
    id: "coder",
    on: {
      event: codingRequested,
      thread: '"coder:" + event.data.repo + ":" + event.data.task',
    },
    sandboxes: { work: workbench },
  },
  async ({ inbox, trigger, sandboxes, control }) => {
    const message = await inbox.next();

    const sandbox = await sandboxes.work.get();

    const checkout = await repo(sandbox, {
      repo: trigger?.data.repo ?? "",
      path: "/work/app",
      token: () => {
        return process.env.GITHUB_READ_TOKEN ?? "";
      },
      push: {
        token: () => {
          return process.env.GITHUB_WRITE_TOKEN ?? "";
        },
        policy,
      },
    });

    const result = await agent.loop({
      model: claude,
      system: `Make the change on a branch named agent/<short-name>, run the tests, then push the branch. Say which branch you pushed. The repo is at ${checkout.path}`,
      prompt: message ?? "",
      tools: checkout.tools,
      ...control,
    });

    return result.text;
  },
);
```

```typescript {{ title: "inngest/policy.ts" }}
import type { GitPolicy } from "inngest/experimental/agents";

export const policy: GitPolicy = async (push) => {
  if (!push.branch?.startsWith("agent/")) {
    return { refuse: "Branches for the agent start with agent/" };
  }

  const touched = push.paths.filter((path) => {
    return path.startsWith(".github/");
  });

  if (touched.length > 0) {
    return { refuse: `Not allowed to change ${touched.join(", ")}` };
  }

  return { notes: [`${push.commits.length} commits to ${push.ref}`] };
};
```

```typescript {{ title: "inngest/sandboxes/workbench.ts" }}
import { sandbox } from "inngest/experimental/agents";

export const workbench = sandbox({
  id: "workbench",
  vcpu: 2,
  memoryMb: 4096,
  tools: sandbox.tools.code({ cwd: "/work/app", timeout: "10m" }),
});
```

```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({
  id: "coding-agent",
  middleware: [sandboxMiddleware()],
});

export const agents = createAgents(inngest);
```

## What it shows off

- A full machine to edit, run and test on. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-coding-agent)
- A push policy you write, so the model cannot touch what you protect. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-coding-agent)
- A one-shot agent that returns a value. [Agents and triggers](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-coding-agent)

## Run it

`$DEV_SERVER` is a Dev Server with `step.subscribe`; [build it once](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-coding-agent#see-the-run).

```bash
$DEV_SERVER dev --no-discovery -u http://localhost:3000/api/inngest
export GITHUB_READ_TOKEN=ghp_... GITHUB_WRITE_TOKEN=ghp_... ANTHROPIC_API_KEY=sk-ant-... INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
node --import tsx inngest/serve.ts
node --import tsx send.ts
```

It needs an environment with Sandboxes. This recipe was type-checked against the SDK and not run.
