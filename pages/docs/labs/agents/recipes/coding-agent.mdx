# Coding agent

> An agent that changes a repository on a branch and never holds the write token.

Ask for a change in plain words and get a branch your policy approved.

```text
request-change   acme/web   "Fix the off-by-one in pagination"

  coder  work_run   sed -i 's/offset + 1/offset/' src/pagination.ts
  coder  work_run   npm test                  58 passed
  coder  work_push  agent/fix-pagination-offset

Returned: Pushed agent/fix-pagination-offset. The tests pass.
```

## The code

<AnnotatedCode>

{/* not type-checked: repo as a function of the event, repo auth as { read, write }, policy */}
```typescript {{ title: "inngest/sandboxes/work.ts" }}
import { secret } from "inngest/experimental";
import { sandbox } from "inngest/experimental/agents";

export const work = sandbox({
  id: "work",
  repo: ({ event }) => {
    return {
      url: `https://github.com/${event.data.repo}`,
      auth: {
        read: secret("GITHUB_READ_TOKEN"),
        write: secret("GITHUB_WRITE_TOKEN"),
      },
      policy: (push) => {
        if (!push.branch?.startsWith("agent/")) {
          return { refuse: "Branches for the agent start with agent/" };
        }

        const touched = push.paths.filter((path) => {
          return path.startsWith(".github/");
        });

        if (touched.length > 0) {
          return { refuse: `Not allowed to change ${touched.join(", ")}` };
        }
      },
    };
  },
});
```

```typescript {{ title: "inngest/agents/coder.ts" }}
import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";
import { claude } from "../models/claude";
import { work } from "../sandboxes/work";

export const changeRequest = z.object({ repo: z.string(), task: z.string() });

export const coder = agents.agent({
  id: "coder",
  triggers: [invoke(changeRequest)],
  model: claude,
  system:
    "Work on a branch named agent/<name>, run tests, push, say which branch.",
  sandboxes: { work },
});
```

```typescript {{ title: "inngest/functions/requestChange.ts" }}
import { invoke } from "inngest";
import { inngest } from "../client";
import { changeRequest, coder } from "../agents/coder";

export const requestChange = inngest.createFunction(
  { id: "request-change", triggers: [invoke(changeRequest)] },
  async ({ event }) => {
    return await coder.start(event.data).result();
  },
);
```

import { createServer } from "inngest/node";
import { agents, inngest } from "./client";
import { requestChange } from "./functions/requestChange";

createServer({

The [model](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-coding-agent#pick-a-model) is the quick start's, and [the client](/docs/labs/agents/structure?ref=docs-labs-agents-recipes-coding-agent#the-client) adds `sandboxMiddleware()`. Importing `requestChange` imports the agent, so `agents.functions()` includes it.

## What it shows off

- [A repository in the sandbox](/docs/labs/agents/sandboxes?ref=docs-labs-agents-recipes-coding-agent#a-repo) is cloned for you, and the request picks which one.
- [A push policy](/docs/labs/agents/sandboxes?ref=docs-labs-agents-recipes-coding-agent#a-repo) lets your code decide what may leave the sandbox.
- [A typed input](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-coding-agent#a-second-agent) gives callers a checked request.
- [Start and wait](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-coding-agent#call-it-from-code) is one line in a plain function.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-coding-agent#install), with Sandboxes.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_READ_TOKEN=ghp_...
export GITHUB_WRITE_TOKEN=ghp_...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

At [localhost:8288](http://localhost:8288), open `request-change`, choose **Invoke** and send `{ "repo": "acme/web", "task": "Fix the off-by-one in pagination" }`. The run returns the summary.
