# Lead and specialists

> A lead that finds the right specialists by what they do, hands each its part and combines the answers.

<Info>
  Inngest Agents is an Inngest Labs project: early, moving fast, and shaped by your feedback. [What's Labs?](/docs/labs?ref=docs-labs-agents-recipes-agent-teams)
</Info>

The lead doesn't import the specialists. Its model reads their cards, starts the ones that fit the request, and waits for their results. Because the lead started them, it can also message them while they work.

```text
You         What does HTTP 429 mean? Then write a fetch wrapper
            that waits and retries on it.

lead        list_agents: researcher, coder
lead        start_agent researcher: What does HTTP 429 mean?
lead        start_agent coder: Write fetchWithRetry for Retry-After.
researcher  finished: Too Many Requests. Wait for Retry-After.
coder       finished: Wrote and ran fetchWithRetry.ts. Its test passes.

lead        429 means Too Many Requests. Here is fetchWithRetry: ...
```

<AnnotatedCode>

```typescript {{ title: "inngest/agents/lead.ts" }}
import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";
import { claude } from "../models/claude";

export const teamRequest = z.object({
  request: z.string(),
  requestedBy: z.string().optional(),
});

export const lead = agents.agent({
  id: "lead",
  triggers: [invoke(teamRequest)],
  model: claude,
  system: "Find specialists, start them, then combine their results.",
  discovery: {
    prepare: ({ input, event }) => {
      return { ...input, requestedBy: event.data.requestedBy };
    },
  },
});
```

<Annotation id="prepare" lines="16-20" tease="fills in requestedBy for every start" title="discovery.prepare" href="/docs/labs/agents/reference?ref=docs-labs-agents-recipes-agent-teams#turn-discovery-off" linkText="Reference: discovery.prepare">

```typescript {{ title: "inngest/functions/askTeam.ts" }}
import { invoke } from "inngest";
import { lead, teamRequest } from "../agents/lead";
import { inngest } from "../client";

export const askTeam = inngest.createFunction(
  { id: "ask-team", triggers: [invoke(teamRequest)] },
  async ({ event }) => {
    return await lead.start(event.data).result();
  },
);
```

## How it works

- [Agent discovery](/docs/labs/agents/agent-discovery?ref=docs-labs-agents-recipes-agent-teams#how-a-model-finds-agents) lets the lead find specialists by `capabilities`, with no imports between them.
- [Start and wait](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-agent-teams#start-an-agent-from-code) lets a plain function wait for the lead's answer.
- [`discovery.prepare`](/docs/labs/agents/reference?ref=docs-labs-agents-recipes-agent-teams#cards-and-discovery) adds the caller's identity to every start, without relying on the model.
- [`limits.depth`](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-agent-teams#cap-delegation-depth) limits how many levels of agents the specialists can start below them.
- [A sandbox](/docs/labs/agents/sandboxes?ref=docs-labs-agents-recipes-agent-teams) gives the coder a machine to run its code.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-agent-teams#1-install-the-packages), with Sandboxes for the coder.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

At [localhost:8288](http://localhost:8288), open `ask-team`, choose **Invoke** and send `{ "request": "What does HTTP 429 mean? Then write a retrying fetch.", "requestedBy": "maya" }`. `ask-team` returns the combined answer. Open the lead's run to see its `list_agents` and `start_agent` calls. Open a specialist's run to see `requestedBy: "maya"` in its input, which your code added.

## Variations

- [`discovery.agents`](/docs/labs/agents/agent-discovery?ref=docs-labs-agents-recipes-agent-teams#limit-who-it-may-start) limits who the lead may find and start Use it once there are agents the lead shouldn't start.
- [Reports](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-agent-teams#receive-reports-while-an-agent-works) let the lead ask each specialist for typed updates while it works, instead of waiting for one `agent/finished` at the end.
- [`share: "team"`](/docs/labs/agents/agent-discovery?ref=docs-labs-agents-recipes-agent-teams#choose-who-can-find-it) lets other apps find the researcher once its card refreshes.
