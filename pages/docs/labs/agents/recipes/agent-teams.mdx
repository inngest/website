# Agent teams

> A lead that finds the right specialists, hands each its part and combines the answers.

No agent imports another: the lead finds the specialists by their cards.

```text
You         What does HTTP 429 mean? Then write a fetch wrapper
            that waits and retries on it.

lead        list_agents: researcher, coder
lead        start_agent researcher: What does HTTP 429 mean?
lead        start_agent coder: Write fetchWithRetry for Retry-After.
researcher  finished: Too Many Requests. Wait for Retry-After.
coder       finished: Wrote and ran fetchWithRetry.ts. Its test passes.

lead        429 means Too Many Requests. Here is fetchWithRetry: ...
```

Screenshot needed: the lead's run beside both specialists' runs.

## The code

The specialists have a model, a prompt, a budget and a card, and no code.

import { agents } from "../client";
import { claude } from "../models/claude";

export const researcher = agents.agent({
  id: "researcher",
  model: claude,

    "Answer in five sentences or fewer, and say what you are unsure of.",

A plain function calls the lead and waits for the combined answer.

<AnnotatedCode>

{/* not type-checked: start().result() on an agent with an invoke() trigger, from a plain function */}
```typescript {{ title: "inngest/functions/askTeam.ts" }}
import { invoke } from "inngest";
import { lead, teamRequest } from "../agents/lead";
import { inngest } from "../client";

export const askTeam = inngest.createFunction(
  { id: "ask-team", triggers: [invoke(teamRequest)] },
  async ({ event }) => {
    return await lead.start(event.data).result();
  },
);
```

The [model](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-agent-teams#pick-a-model) is the quick start's.

## What it shows off

- [Discovery](/docs/labs/agents/discovery?ref=docs-labs-agents-recipes-agent-teams#find-agents) lets the lead find specialists with no imports between them.
- [Start and wait](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams#wait-for-the-result) lets a plain function wait for the lead's answer.
- [Limits](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams#limit-the-team) keep delegation one level deep by default.
- [A sandbox](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-agent-teams) belongs to the coder only.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-agent-teams#install), with Sandboxes for the coder.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

In the Dev Server, open `ask-team`, choose **Invoke** and send `{ "request": "What does HTTP 429 mean? Then write a retrying fetch." }`. The run shows the lead's searches, both `start_agent` calls and the answer.

## Variations

- [`agents.reference`](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams#call-an-agent-in-another-app) calls the lead by address from another app.
- [`limits.mayCall`](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams#limit-the-team) limits who the lead may start.
- [`share: "team"`](/docs/labs/agents/discovery?ref=docs-labs-agents-recipes-agent-teams) lets other apps use the researcher.
