# Agent teams

> A lead that finds the right specialists, hands each its part and combines the answers.

```text
You         What does HTTP 429 mean? Then write a fetch wrapper
            that waits and retries on it.

lead        list_agents: researcher, coder
lead        start_agent researcher: What does HTTP 429 mean?
lead        start_agent coder: Write fetchWithRetry for Retry-After.
researcher  finished: Too Many Requests. Wait for Retry-After.
coder       finished: Wrote and ran fetchWithRetry.ts. Its test passes.

lead        429 means Too Many Requests. Here is fetchWithRetry: ...
```

## The code

{/* not type-checked: createAgents with the store from the environment */}
```typescript {{ title: "inngest/client.ts" }}
import { Inngest } from "inngest";
import { sandboxMiddleware } from "inngest/experimental";
import { createAgents } from "inngest/experimental/agents";

export const inngest = new Inngest({
  id: "agent-teams",
  middleware: [sandboxMiddleware()],
});

export const agents = createAgents(inngest);
```

The two specialists have a model, a prompt, a budget and a card, and no code. The coder also has a sandbox.

The lead takes a typed request and finds the specialists itself. It has no handler either.

import { agents } from "../client";

export const lead = agents.agent({
  id: "lead",

  limits: { depth: 1 },

Any plain function can call the lead and wait for the combined answer.

<AnnotatedCode>

{/* not type-checked: start().result() on an agent with an invoke() trigger, from a plain function */}
```typescript {{ title: "inngest/functions/askTeam.ts" }}
import { eventType } from "inngest";
import { z } from "zod";
import { lead } from "../agents/lead";
import { inngest } from "../client";

const teamRequest = eventType("team/request", {
  schema: z.object({ request: z.string() }),
});

export const askTeam = inngest.createFunction(
  { id: "ask-team", triggers: [teamRequest] },
  async ({ event }) => {
    return await lead.start({ request: event.data.request }).result();
  },
);
```

<Annotation id="result" lines="13" tease="wait for the answer" title="Start and wait" href="/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams" linkText="Teams of agents">
`start()` opens a thread for the lead. `result()` resolves with the answer it gives after the specialists it started have finished.
</Annotation>

</AnnotatedCode>

{/* not type-checked: agents.functions() */}
```typescript {{ title: "inngest/serve.ts" }}
import { createServer } from "inngest/node";
import { agents, inngest } from "./client";
import "./agents/coder";
import "./agents/lead";
import "./agents/researcher";
import { askTeam } from "./functions/askTeam";

createServer({
  client: inngest,
  functions: [...agents.functions(), askTeam],
}).listen(3000);
```

`inngest/models/claude.ts` is the one from the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-agent-teams#pick-a-model). No agent imports another: the lead finds the others by their cards.

## What it shows off

- One agent finds others and uses their results, with no imports between them. [Discovery](/docs/labs/agents/discovery?ref=docs-labs-agents-recipes-agent-teams)
- A plain function that calls the lead and waits for the answer. [Teams of agents](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams)
- A budget on every agent and a depth limit on the lead. [Reliability](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-agent-teams)
- A sandbox for the coder only. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-agent-teams)

## Run it

You need the setup from the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-agent-teams#install). The coder's sandbox needs an environment with Sandboxes.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

On the Dev Server, send `team/request` with `{ "request": "What does HTTP 429 mean? Then write a fetch wrapper that retries on it." }`, or invoke `lead` with the same data from its Functions page. The run shows the lead's searches, both `start_agent` calls and the answer. Cards reach discovery when the app syncs; on Cloud, an agent that was just deployed can take a few minutes to appear.

## Variations

- Call the lead by address from another app with `agents.reference`. [Teams of agents](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams)
- Limit who the lead may start with `limits: { mayCall: [...] }`. [Teams of agents](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams)
- Let other apps use the researcher with `share: "team"` on its card. [Discovery](/docs/labs/agents/discovery?ref=docs-labs-agents-recipes-agent-teams)
