# Lead and specialists

> A lead that finds the right specialists by what they do, hands each its part and combines the answers.

The point of this recipe isn't a hierarchy with special powers at the top — it's that agents can find each other and work together without ever being wired together in code. "Team" here means two things, and nothing more: lineage (the lead started these two, so it can talk to them and wait on them) and discovery (the lead found them by reading their cards, not by importing them).

```text
You         What does HTTP 429 mean? Then write a fetch wrapper
            that waits and retries on it.

lead        list_agents: researcher, coder
lead        start_agent researcher: What does HTTP 429 mean?
lead        start_agent coder: Write fetchWithRetry for Retry-After.
researcher  finished: Too Many Requests. Wait for Retry-After.
coder       finished: Wrote and ran fetchWithRetry.ts. Its test passes.

lead        429 means Too Many Requests. Here is fetchWithRetry: ...
```

<AnnotatedCode>

```typescript {{ title: "inngest/agents/lead.ts" }}
import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";
import { claude } from "../models/claude";

export const teamRequest = z.object({
  request: z.string(),
  requestedBy: z.string().optional(),
});

export const lead = agents.agent({
  id: "lead",
  triggers: [invoke(teamRequest)],
  model: claude,
  system: "Find specialists, start them, then combine their results.",
  discovery: {
    prepare: ({ input, event }) => {
      return { ...input, requestedBy: event.data.requestedBy };
    },
  },
});
```

<Annotation id="invoke" lines="7-10" tease="a typed request" title="invoke()" href="/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-agent-teams#a-second-agent" linkText="Take a typed input">
Checks what callers send, and goes on the agent's card.
</Annotation>

<Annotation id="system" lines="15" tease="no names in code" title="Discovery" href="/docs/labs/agents/agent-discovery?ref=docs-labs-agents-recipes-agent-teams#finding" linkText="Find agents">
The lead has `list_agents` and `start_agent` by default. Each result comes back as an `agent/finished` message.
</Annotation>

<Annotation id="prepare" lines="16-20" tease="fills in requestedBy for every start" title="discovery.prepare" href="/docs/labs/agents/reference?ref=docs-labs-agents-recipes-agent-teams#turn-discovery-off" linkText="Reference: discovery.prepare">
The model never sees or sets `requestedBy` — it's filled in by the host before every `start_agent` call the lead's model makes, from whoever actually called the lead. Neither specialist has to trust the model to pass caller identity through honestly.

```typescript {{ title: "inngest/functions/askTeam.ts" }}
import { invoke } from "inngest";
import { lead, teamRequest } from "../agents/lead";
import { inngest } from "../client";

export const askTeam = inngest.createFunction(
  { id: "ask-team", triggers: [invoke(teamRequest)] },
  async ({ event }) => {
    return await lead.start(event.data).result();
  },
);
```

## What it shows off

- [Agent discovery](/docs/labs/agents/agent-discovery?ref=docs-labs-agents-recipes-agent-teams#finding) lets the lead find specialists by `capabilities`, with no imports between them.
- [Start and wait](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-agent-teams#call-it-from-code) lets a plain function wait for the lead's answer.
- [`discovery.prepare`](/docs/labs/agents/reference?ref=docs-labs-agents-recipes-agent-teams#turn-discovery-off) injects the caller's identity into every start, without the model's cooperation.
- [`limits.depth`](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-agent-teams#cap-delegation-depth) bounds how many more levels a specialist could start below itself, if it chose to.
- [A sandbox](/docs/labs/agents/sandboxes?ref=docs-labs-agents-recipes-agent-teams) gives the coder a machine to run its code.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-agent-teams#install), with Sandboxes for the coder.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

At [localhost:8288](http://localhost:8288), open `ask-team`, choose **Invoke** and send `{ "request": "What does HTTP 429 mean? Then write a retrying fetch.", "requestedBy": "maya" }`. `ask-team` returns the combined answer; open the lead's run to see its searches and both `start_agent` calls, and open a specialist's run to see `requestedBy: "maya"` arrive in its input even though the lead's model never wrote it there.

## Variations

- [`discovery.agents`](/docs/labs/agents/agent-discovery?ref=docs-labs-agents-recipes-agent-teams#who-it-may-start) limits who the lead may find and start — useful once there are specialists the lead shouldn't reach for.
- [Reports](/docs/labs/agents/agent-teams?ref=docs-labs-agents-recipes-agent-teams#reports-along-the-way) let the lead ask each specialist for typed updates while it works, instead of waiting for one `agent/finished` at the end.
- [`share: "team"`](/docs/labs/agents/agent-discovery?ref=docs-labs-agents-recipes-agent-teams#who-can-find-it) lets other apps find the researcher once its card refreshes.
