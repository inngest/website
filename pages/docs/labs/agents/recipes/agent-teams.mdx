# Agent teams

> A lead agent that splits a request between a researcher and a coder.

```text
You         What does HTTP 429 mean? Then write a fetch wrapper that waits and retries on it.

lead        asks researcher: What does HTTP 429 mean?
researcher  Too Many Requests. Wait for the Retry-After header before retrying.
lead        asks coder: Write fetchWithRetry that honors Retry-After.
coder       Wrote and ran fetchWithRetry.ts. Its test passes.

lead        429 means Too Many Requests. Here is fetchWithRetry, tested: ...
```

## The code

<AnnotatedCode>

```typescript {{ title: "inngest/agents/lead.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { coder } from "./coder";
import { researcher } from "./researcher";

export const lead = agents.agent(
  {
    id: "lead",
    limits: {
      depth: 1,
      spawn: 4,
      budget: { usd: 2 },
      price: { "*": { input: 3, output: 15 } },
    },
  },
  async ({ inbox, control }) => {
    const message = await inbox.next();

    const result = await agent.loop({
      model: claude,
      system:
        "Split the request. Ask the researcher for facts and the coder for code, then combine their answers.",
      prompt: message ?? "",
      tools: { researcher, coder },
      ...control,
    });

    return result.text;
  },
);
```

```typescript {{ title: "inngest/agents/researcher.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const researcher = agents.agent(
  {
    id: "researcher",
    description: "Answers a factual question",
    limits: { price: { "*": { input: 3, output: 15 } } },
  },
  async ({ inbox, control }) => {
    const message = await inbox.next();

    const result = await agent.loop({
      model: claude,
      system: "Answer in five sentences or fewer, and say what you are unsure of.",
      prompt: message ?? "",
      ...control,
    });

    return result.text;
  },
);
```

```typescript {{ title: "inngest/agents/coder.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { workbench } from "../sandboxes/workbench";

export const coder = agents.agent(
  {
    id: "coder",
    description: "Writes and tests code in a sandbox",
    sandboxes: { work: workbench },
    limits: { price: { "*": { input: 3, output: 15 } } },
  },
  async ({ inbox, sandboxTools, control }) => {
    const message = await inbox.next();

    const result = await agent.loop({
      model: claude,
      prompt: message ?? "",
      tools: sandboxTools,
      ...control,
    });

    return result.text;
  },
);
```

```typescript {{ title: "inngest/sandboxes/workbench.ts" }}
import { sandbox } from "inngest/experimental/agents";

export const workbench = sandbox({
  id: "workbench",
  tools: sandbox.tools.code({ cwd: "/work" }),
});
```

`inngest/client.ts` is the one from the [Coding agent](/docs/labs/agents/recipes/coding-agent?ref=docs-labs-agents-recipes-agent-teams), with `id: "agent-teams"`. `inngest/models/claude.ts` and `inngest/serve.ts` follow the [Slack assistant](/docs/labs/agents/recipes/slack-assistant?ref=docs-labs-agents-recipes-agent-teams).

## What it shows off

- One agent calls another and gets its result. [Teams of agents](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams)
- Only the coder gets a sandbox. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-agent-teams)
- A dollar budget on the lead, and prices for each child. [Reliability](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-agent-teams)

## Run it

`$DEV_SERVER` is a Dev Server with `step.subscribe`; [build it once](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-agent-teams#see-the-run).

```bash
$DEV_SERVER dev --no-discovery -u http://localhost:3000/api/inngest
export ANTHROPIC_API_KEY=sk-ant-... INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
node --import tsx inngest/serve.ts
```

Send the lead a message with `lead.thread("t1").send("...")`. The coder needs an environment with Sandboxes. This recipe was type-checked against the SDK and not run.

## Variations

- Let the lead's sub-agents cancel with it using `agentInvokeCancelOn`. [Teams of agents](/docs/labs/agents/teams-of-agents?ref=docs-labs-agents-recipes-agent-teams)
