# Issue triage

> An agent that labels every new issue and links duplicates.

Each GitHub call is its own step, so a retry repeats only the call that failed.

```text
Issue #214   Dev server crashes when a step returns undefined
Labels       bug
Comment      Thanks. This looks like #198, which has a fix in review.
```

## The code

<AnnotatedCode>

{/* not type-checked: github.thread with repos, events and if; github.tools() in a tools record */}
```typescript {{ title: "inngest/agents/triage.ts" }}
import { github } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { findSimilar } from "../tools/findSimilar";
import { repoName } from "../tools/githubRest";
import { label } from "../tools/label";

export const triage = agents.agent({
  id: "triage",
  triggers: [
    github.thread({
      repos: [repoName],
      events: ["issues"],
      if: 'event.data.action == "opened"',
    }),
  ],
  model: claude,
  system:
    "Find similar issues, label this one, comment once. Link duplicates.",
  tools: { findSimilar, label, ...github.tools() },
});
```

```typescript {{ title: "inngest/tools/findSimilar.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { githubRest, repoName } from "./githubRest";

export const findSimilar = tool.step({
  description: "Search open issues for similar reports",
  input: z.object({ query: z.string() }),
  run: async ({ query }) => {
    const search = encodeURIComponent(
      `repo:${repoName} is:issue is:open ${query}`,
    );

    const found = await githubRest<{
      items: { number: number; title: string }[];
    }>(`/search/issues?q=${search}&per_page=5`);

    return found.items.map((item) => {
      return { number: item.number, title: item.title };
    });
  },
});
```

```typescript {{ title: "inngest/tools/label.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { githubRest, repoName } from "./githubRest";

export const label = tool.step({
  description: "Label the issue",
  input: z.object({
    number: z.number(),
    labels: z.array(z.enum(["bug", "feature", "question", "duplicate"])),
  }),
  run: async ({ number, labels }) => {
    await githubRest(`/repos/${repoName}/issues/${number}/labels`, {
      method: "POST",
      body: JSON.stringify({ labels }),
    });

    return { labeled: labels };
  },
});
```

```typescript {{ title: "inngest/tools/githubRest.ts" }}
export const repoName = "acme/app";

export const githubRest = async <T>(path: string, init?: RequestInit) => {
  const token = process.env.GITHUB_TOKEN;

  if (!token) {
    throw new Error("Set GITHUB_TOKEN");
  }

  const response = await fetch(`https://api.github.com${path}`, {
    ...init,
    headers: {
      accept: "application/vnd.github+json",
      authorization: `Bearer ${token}`,
      "content-type": "application/json",
    },
  });

  if (!response.ok) {
    throw new Error(`GitHub ${response.status}: ${await response.text()}`);
  }

  return (await response.json()) as T;
};
```

The [client](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-issue-triage#create-the-client) and [model](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-issue-triage#pick-a-model) are the quick start's. ## What it shows off

- [GitHub as a trigger](/docs/labs/agents/slack-and-github?ref=docs-labs-agents-recipes-issue-triage#work-on-git-hub) starts the agent from the repos and events you choose.
- [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-issue-triage) are the functions the model calls to search and label.
- [An agent with no handler](/docs/labs/agents/models?ref=docs-labs-agents-recipes-issue-triage) needs only a model, a prompt and tools.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-issue-triage#install), in a Next.js app.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_TOKEN=ghp_...
export GITHUB_WEBHOOK_SECRET=...
npm run dev
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

Add a webhook to `acme/app` for **Issues** events, pointing at `https://<your-host>/api/github` with `GITHUB_WEBHOOK_SECRET` as its secret. A tunnel works for local runs. Open an issue and watch the run at [localhost:8288](http://localhost:8288).

## Variations

- [`github_ask`](/docs/labs/agents/slack-and-github?ref=docs-labs-agents-recipes-issue-triage#work-on-git-hub) lets the model ask a maintainer when unsure; say so in the prompt.
- [Scheduled watcher](/docs/labs/agents/recipes/scheduled-watcher?ref=docs-labs-agents-recipes-issue-triage) watches for stale issues on a schedule.
- [Coding agent](/docs/labs/agents/recipes/coding-agent?ref=docs-labs-agents-recipes-issue-triage) opens a branch for simple bugs.
