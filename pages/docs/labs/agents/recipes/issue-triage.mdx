# Issue triage

> An agent that labels every new issue and links the ones you have seen before.

GitHub sends the issue; the agent searches, labels and comments. Each GitHub call is its own retried step, so a retry never repeats another call.

```text
Issue #214   Dev server crashes when a step returns undefined
Labels       bug
Comment      Thanks. This looks like #198, which has a fix in review.
```

```typescript {{ title: "inngest/agents/triage.ts" }}
import { github } from "inngest/experimental/agents";
import { agents } from "../client";
import { repo } from "../lib/githubRest";
import { claude } from "../models/claude";
import { findSimilar } from "../tools/findSimilar";
import { label } from "../tools/label";

export const triage = agents.agent({
  id: "triage",
  triggers: [
    github.thread({
      repos: [repo],
      events: ["issues"],
      if: 'event.data.action == "opened"',
    }),
  ],
  model: claude,
  system:
    "Find other similar issues, label this one, comment once. Link duplicates.",
  tools: { findSimilar, label, ...github.tools() },
});
```

The two tools call GitHub's REST API through one small helper.

```typescript {{ title: "inngest/tools/findSimilar.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { githubRest, repo } from "../lib/githubRest";

export const findSimilar = tool.step({
  description: "Search open issues for similar reports",
  input: z.object({ query: z.string() }),
  run: async ({ query }) => {
    const q = encodeURIComponent(`repo:${repo} is:issue is:open ${query}`);

    const found = await githubRest<{
      items: { number: number; title: string }[];
    }>(`/search/issues?q=${q}&per_page=5`);

    return found.items.map((item) => {
      return { number: item.number, title: item.title };
    });
  },
});
```

```typescript {{ title: "inngest/tools/label.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { githubRest, repo } from "../lib/githubRest";

export const label = tool.step({
  description: "Label the issue",
  input: z.object({
    number: z.number(),
    labels: z.array(z.enum(["bug", "feature", "question", "duplicate"])),
  }),
  run: async ({ number, labels }) => {
    await githubRest(`/repos/${repo}/issues/${number}/labels`, {
      method: "POST",
      body: JSON.stringify({ labels }),
    });

    return { labeled: labels };
  },
});
```

```typescript {{ title: "inngest/lib/githubRest.ts" }}
export const repo = "acme/app";

export const githubRest = async <T>(path: string, init?: RequestInit) => {
  const response = await fetch(`https://api.github.com${path}`, {
    ...init,
    headers: {
      accept: "application/vnd.github+json",
      authorization: `Bearer ${process.env.GITHUB_TOKEN}`,
      "content-type": "application/json",
    },
  });

  if (!response.ok) {
    throw new Error(`GitHub ${response.status}: ${await response.text()}`);
  }

  return (await response.json()) as T;
};
```

`inngest/client.ts` and `inngest/models/claude.ts` are the ones from the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-issue-triage). `app/api/inngest/route.ts` serves the agents as in the [Slack assistant](/docs/labs/agents/recipes/slack-assistant?ref=docs-labs-agents-recipes-issue-triage), importing `inngest/agents/triage`.

## What it shows off

- [GitHub as a trigger](/docs/labs/agents/slack-and-github?ref=docs-labs-agents-recipes-issue-triage) starts the agent on an issue, with one thread per issue.
- [The comment tool](/docs/labs/agents/slack-and-github?ref=docs-labs-agents-recipes-issue-triage) comes from `github.tools()`, bound to the issue.
- [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-issue-triage) run as steps, so label and comment retry on their own.
- [An agent with no handler](/docs/labs/agents/models-and-the-loop?ref=docs-labs-agents-recipes-issue-triage) needs nothing beyond a model, a prompt and these tools.

## Run it

Set the project up as in the quick start, in a Next.js app. Start the Dev Server, pointed at the app:

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_TOKEN=ghp_...
export GITHUB_WEBHOOK_SECRET=...
npm run dev
```

Add a webhook to `acme/app` for **Issues** events, pointing at `https://<your-host>/api/github` with `GITHUB_WEBHOOK_SECRET` as its secret; a tunnel works for local runs. Open an issue and watch the run in the Dev Server at [localhost:8288](http://localhost:8288).
