# Recipes

> Complete projects to copy and adapt, each with the code, how it works, and how to run it.

<Info>
  Inngest Agents is an Inngest Labs project: early, moving fast, and shaped by your feedback. [What's Labs?](/docs/labs?ref=docs-labs-agents-recipes)
</Info>

## Conversations

- [Support assistant](/docs/labs/agents/recipes/support-assistant?ref=docs-labs-agents-recipes) answers each support ticket on its own thread and looks up orders.
- [MCP assistant](/docs/labs/agents/recipes/mcp-assistant?ref=docs-labs-agents-recipes) works in each person's own account on a remote MCP server.

## Code and repositories

- [Issue triage](/docs/labs/agents/recipes/issue-triage?ref=docs-labs-agents-recipes) labels new issues and links duplicates.
- [PR reviewer](/docs/labs/agents/recipes/pr-reviewer?ref=docs-labs-agents-recipes) checks out a pull request, runs its tests, and posts a review.
- [Coding agent](/docs/labs/agents/recipes/coding-agent?ref=docs-labs-agents-recipes) changes a repository on a branch, without the write token in its sandbox.
- [Sandbox tools](/docs/labs/agents/recipes/sandbox-tools?ref=docs-labs-agents-recipes) answers a question by writing one script that calls your tools.

## Teams and schedules

- [Lead and specialists](/docs/labs/agents/recipes/agent-teams?ref=docs-labs-agents-recipes) finds specialist agents by their cards and combines their answers.
- [Scheduled watcher](/docs/labs/agents/recipes/scheduled-watcher?ref=docs-labs-agents-recipes) posts a weekday digest from a plain function with one model call.
