# Recipes

> Complete examples you can copy, each with the result first.

- [Slack assistant](/docs/labs/agents/recipes/slack-assistant?ref=docs-labs-agents-recipes): answers in a thread and remembers what the team tells it.
- [Issue triage](/docs/labs/agents/recipes/issue-triage?ref=docs-labs-agents-recipes): labels new issues and links duplicates.
- [PR reviewer](/docs/labs/agents/recipes/pr-reviewer?ref=docs-labs-agents-recipes): checks out a pull request, runs its tests and reviews it.
- [Coding agent](/docs/labs/agents/recipes/coding-agent?ref=docs-labs-agents-recipes): changes a repository on a branch without holding the write token.
- [Scheduled watcher](/docs/labs/agents/recipes/scheduled-watcher?ref=docs-labs-agents-recipes): a weekday digest, as a plain function.
- [Lead and specialists](/docs/labs/agents/recipes/agent-teams?ref=docs-labs-agents-recipes): a lead that finds specialists and combines their answers.
- [MCP assistant](/docs/labs/agents/recipes/mcp-assistant?ref=docs-labs-agents-recipes): works in each person's own account on a remote MCP server.
- [Sandbox tools](/docs/labs/agents/recipes/sandbox-tools?ref=docs-labs-agents-recipes): answers by writing a script that calls your tools.

New to agents? Start with the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes), then read the [concepts](/docs/labs/agents?ref=docs-labs-agents-recipes#concepts).
