# Recipes

> Complete agents you can copy, each with the result first.

- [Slack assistant](/docs/labs/agents/recipes/slack-assistant?ref=docs-labs-agents-recipes). Answers in a Slack thread and remembers the conversation.
- [Issue triage](/docs/labs/agents/recipes/issue-triage?ref=docs-labs-agents-recipes). Labels every new issue and links duplicates.
- [PR reviewer](/docs/labs/agents/recipes/pr-reviewer?ref=docs-labs-agents-recipes). Runs a pull request's tests and reviews it in a comment.
- [Coding agent](/docs/labs/agents/recipes/coding-agent?ref=docs-labs-agents-recipes). Changes a repository on a branch your policy approves.
- [Approvals](/docs/labs/agents/recipes/approvals?ref=docs-labs-agents-recipes). Asks in Slack before it merges.
- [Scheduled watcher](/docs/labs/agents/recipes/scheduled-watcher?ref=docs-labs-agents-recipes). Posts a digest every weekday and stays quiet when there is no news.
- [Agent teams](/docs/labs/agents/recipes/agent-teams?ref=docs-labs-agents-recipes). A lead that splits work between a researcher and a coder.
- [MCP assistant](/docs/labs/agents/recipes/mcp-assistant?ref=docs-labs-agents-recipes). Works in each person's own account on a remote MCP server.
- [Sandbox tools](/docs/labs/agents/recipes/sandbox-tools?ref=docs-labs-agents-recipes). Answers by writing code that calls your tools.
- [Testing](/docs/labs/agents/recipes/testing?ref=docs-labs-agents-recipes). Tests a whole agent with no model key and no Slack.

New to agents? Start with the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes), then read the [concepts](/docs/labs/agents?ref=docs-labs-agents-recipes).
