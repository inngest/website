# Sandbox tools

> An agent that answers by writing one script that calls your tools.

The model writes the script once, and each call it makes runs your tool as a step.

```text
You      How many pull requests did each person open in acme/app?
analyst  maya 41, dan 27, priya 19, sam 8.
```

The model writes and runs a script like this in the sandbox:

```python
counts = {}
page = 1

while True:
    pulls = await tools.listPullRequests(repo="acme/app", page=page)

    if not pulls:
        break

    for pull in pulls:
        counts[pull["author"]] = counts.get(pull["author"], 0) + 1

    page += 1

print(counts)
```

## The code

```typescript {{ title: "inngest/tools/listPullRequests.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";

export const listPullRequests = tool.step({
  description: "List a page of pull requests, newest first",
  input: z.object({ repo: z.string(), page: z.number().default(1) }),
  run: async ({ repo, page }) => {
    const token = process.env.GITHUB_TOKEN;

    if (!token) {
      throw new Error("Set GITHUB_TOKEN");
    }

    const base = `https://api.github.com/repos/${repo}/pulls`;
    const query = `state=all&per_page=100&page=${page}`;

    const response = await fetch(`${base}?${query}`, {
      headers: { authorization: `Bearer ${token}` },
    });

    if (!response.ok) {
      throw new Error(`GitHub ${response.status}: ${await response.text()}`);
    }

    const pulls = (await response.json()) as {
      number: number;
      user: { login: string };
    }[];

    return pulls.map((pull) => {
      return { number: pull.number, author: pull.user.login };
    });
  },
});
```

import { invoke } from "inngest";

import { agents } from "../client";

export const analyst = agents.agent({

  model: claude,
  system:

});

## What it shows off

- [Code that calls tools](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-sandbox-tools#let-code-call-your-tools) makes many calls in one model turn.
- [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-sandbox-tools) keep the GitHub token in your app, never in the sandbox.
- [A typed input](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-sandbox-tools#take-a-typed-input) starts an agent with no handler.

## Run it

Set the project up as in the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-sandbox-tools#install), with Sandboxes.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_TOKEN=ghp_...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

At [localhost:8288](http://localhost:8288), invoke `analyst` with `{ "question": "How many pull requests did each person open in acme/app?" }`. The run shows one `analysis_run_code` call and a step for every `listPullRequests` call inside it.

## Variations

- [Group tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-sandbox-tools#wait-for-a-reply) can wait for a person with `waits: true`.
- [Handlers](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-sandbox-tools#let-code-call-your-tools) run the same tools with `sandboxes.analysis.commands.run` and `{ tools }`.
