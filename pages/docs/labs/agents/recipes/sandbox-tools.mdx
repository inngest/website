# Sandbox tools

> An agent that answers by writing one script that calls your tools.

```text
You      How many pull requests did each person open in acme/app?
analyst  maya 41, dan 27, priya 19, sam 8.
```

The model writes and runs a script like this in the sandbox:

```python
counts = {}
page = 1

while True:
    pulls = await tools.listPullRequests(repo="acme/app", page=page)

    if not pulls:
        break

    for pull in pulls:
        counts[pull["author"]] = counts.get(pull["author"], 0) + 1

    page += 1

print(counts)
```

## The code

The tool is an ordinary tool. The GitHub token is read in your app, so it never reaches the sandbox.

```typescript {{ title: "inngest/tools/listPullRequests.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";

export const listPullRequests = tool.step({
  description: "List a page of pull requests, newest first",
  input: z.object({ repo: z.string(), page: z.number().default(1) }),
  run: async ({ repo, page }) => {
    const base = `https://api.github.com/repos/${repo}/pulls`;
    const query = `state=all&per_page=100&page=${page}`;
    const response = await fetch(`${base}?${query}`, {
      headers: { authorization: `Bearer ${process.env.GITHUB_TOKEN}` },
    });

    const pulls = (await response.json()) as {
      number: number;
      user: { login: string };
    }[];

    return pulls.map((pull) => {
      return { number: pull.number, author: pull.user.login };
    });
  },
});
```

The sandbox hands the tool to the script.

import { invoke } from "inngest";
import { z } from "zod";
import { agents } from "../client";
import { claude } from "../models/claude";

export const analyst = agents.agent({
  id: "analyst",
  triggers: [invoke(z.object({ question: z.string() }))],
  model: claude,
  system:
    "Answer with one analysis_run_code script that loops over every page.",
  sandboxes: { analysis },
});

## What it shows off

- Many tool calls in one model turn. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-sandbox-tools)
- The GitHub token stays in your app, never in the sandbox. [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-sandbox-tools)
- Every call from the script retries on its own. [Reliability](/docs/labs/agents/reliability?ref=docs-labs-agents-recipes-sandbox-tools)
- An agent with no handler and a typed input. [Agents and triggers](/docs/labs/agents/agents-and-triggers?ref=docs-labs-agents-recipes-sandbox-tools#take-a-typed-input)

## Run it

You need the setup from the [quick start](/docs/labs/agents/quick-start?ref=docs-labs-agents-recipes-sandbox-tools#install), a GitHub token and an environment with Sandboxes.

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export INNGEST_EXPERIMENTAL_KV_URL=redis://localhost:6379
export GITHUB_TOKEN=ghp_...
npx tsx inngest/serve.ts
```

```bash
npx inngest-cli@latest dev -u http://localhost:3000/api/inngest
```

On the Dev Server's Functions page, invoke `analyst` with `{ "question": "How many pull requests did each person open in acme/app?" }`. The run shows one `analysis_run_code` call and a step for every `listPullRequests` call inside it.

## Variations

- Give the model only the script tool with `only: ["run_code"]` in `sandbox.tools.code`. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-sandbox-tools)
- Let a tool wait for a person with `waits: true`. [Tools](/docs/labs/agents/tools?ref=docs-labs-agents-recipes-sandbox-tools)
- Run the same tools from a handler with `sandboxes.analysis.commands.run` and `{ tools }`. [Sandboxes and code](/docs/labs/agents/sandboxes-and-code?ref=docs-labs-agents-recipes-sandbox-tools)
