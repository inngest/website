# Scores

> See how fast, how costly and how well your agents work, with no extra steps.

- **Get timing and cost for free.** Model and tool steps score themselves. [Built-in scores →](#built-in-scores)
- **Add your own.** `scores.score(name, value)` takes a number or a boolean. [Your scores →](#record-your-own)
- **Turn them off.** `scores: false` stops the built-in ones. [Opt out →](#turn-scores-off)
- **Analyze anywhere.** Scores show in traces and in Insights. [Where they show up →](#where-scores-show-up)

## Record your own

Call `scores.score` from the agent body or from a tool. Inside a tool it lands on that tool's step.

```typescript {{ title: "inngest/tools/escalate.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";

export const escalate = tool.step({
  description: "Hands the thread to a person",
  input: z.object({ reason: z.string() }),
  run: async ({ reason }) => {
    return `escalated: ${reason}`;
  },
});
```

```typescript {{ title: "inngest/agents/support.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { escalate } from "../tools/escalate";

export const support = agents.agent(
  { id: "support" },
  async ({ inbox, control, scores }) => {
    for await (const message of inbox) {
      const result = await agent.loop({
        model: claude,
        prompt: message.content ?? "",
        tools: { escalate },
        ...control,
      });

      await scores.score("support.answered", result.text.length > 0);

      await scores.score("support.turns", result.turns);
    }
  },
);
```

## Built-in scores

The loop and `report()` score the steps that already run, so none adds a step.

- `agent.model_ms`, `agent.input_tokens`, `agent.output_tokens`, `agent.tool_calls` and `agent.steers` are on each model step. `agent.cache_read_tokens` and `agent.cache_write_tokens` join them when the model reported cache usage, as `agent.anthropic()` does.
- `agent.tool_ms` and `agent.tool_error` are on each tool step. `agent.tool_error` is `1` when the tool threw or returned an error.
- `agent.first_output_ms` is on the first `report()` post: trigger event to post.
- `agent.output_gap_ms` is on each later post: previous post to this one.
- `agent.stopped` is `1` on the step that records a stop request.

A group from `tool.group()` is not one step, so it is not scored.

## Turn scores off

```typescript {{ title: "inngest/agents/quiet.ts" }}
import { agents } from "../client";

export const quiet = agents.agent({ id: "quiet", scores: false }, async () => {
  return undefined;
});
```

`scores.score()` still works in the body.

## Where scores show up

Scores appear on the run's trace, on the step that earned them. Query them over time in [Insights](/docs/platform-and-operations/insights?ref=docs-labs-agents-scores), and compare variants with [agent evals](/docs/agent-evals/overview?ref=docs-labs-agents-scores).

## How it works

- A score rides in the metadata of a step that is already running. It is written once, when the step really runs, never on replay.
- Outside a step, `scores.score` sets a score on the run. Call it with values that do not change between replays.
- A score never fails a run. If the server refuses it, one warning is logged and the run goes on.
- Rolling scores up into averages, percentiles or rates is left to Insights.
