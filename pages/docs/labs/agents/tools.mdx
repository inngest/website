# Tools

> Give the model functions that run in your app, as durable steps.

- **Typed from your schema.** Bad input never runs. [Define a tool →](#define-a-tool)
- **Many steps in one tool.** Invoke, send events, wait. [Tool groups →](#run-several-steps)
- **Readable errors.** Return one, or throw. [Return an error →](#return-an-error-the-model-can-read)
- **Listen for events.** Wait on a pull request. [Inbox tools →](#let-the-model-listen-for-events)

<AnnotatedCode>

```typescript {{ title: "inngest/agents/billing.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { getCustomer } from "../tools/getCustomer";
import { getOrder } from "../tools/getOrder";
import { refund } from "../tools/refund";

export const billing = agents.agent(
  { id: "billing" },
  async ({ inbox, control }) => {
    for await (const message of inbox) {
      await agent.loop({
        model: claude,
        prompt: message.data.content ?? "",
        tools: { getCustomer, getOrder, refund },
        onToolResult: (run) => {
          if (!run.isError && run.name === "getCustomer") {
            console.log(run.output.plan);
          }
        },
        ...control,
      });
    }
  },
);
```

## Define a tool

`tool.step()` runs its body as one durable step. A retry never repeats a finished call.

```typescript {{ title: "inngest/tools/getOrder.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";
import { db } from "../db";

export const getOrder = tool.step({
  description: "Find an order by ID",
  input: z.object({ id: z.string() }),
  run: async ({ id }) => {
    return db.orders.find(id);
  },
});
```

## Check input and output

`tool()` adds an `id` and an `output` schema.

<AnnotatedCode>

```typescript {{ title: "inngest/tools/getCustomer.ts" }}
import { tool } from "inngest/experimental";
import { z } from "zod";

export const getCustomer = tool({
  id: "getCustomer",
  description: "Find a customer by email",
  input: z.object({ email: z.string().email() }),
  output: z.object({ id: z.string(), plan: z.string() }),
  displayName: ({ email }) => {
    return `Look up: ${email}`;
  },
  run: async ({ email }, { idempotencyKey, signal }) => {
    const found = await fetch(`https://api.acme.test/customers/${email}`, {
      headers: { "idempotency-key": idempotencyKey },
      signal,
    });

    return found.json() as Promise<{ id: string; plan: string }>;
  },
});
```

## Run several steps

`tool.group()` runs its body as a group of steps instead of one. Use the global `step` inside it.

<AnnotatedCode>

```typescript {{ title: "inngest/tools/refund.ts" }}
import { step } from "inngest";
import { tool } from "inngest/experimental";
import { agent } from "inngest/experimental/agents";
import { z } from "zod";
import { db } from "../db";

export const refund = tool.group({
  description: "Refund an order and tell the customer",
  input: z.object({ orderId: z.string() }),
  run: async ({ orderId }) => {
    const order = await db.orders.find(orderId);

    if (order.status !== "shipped") {
      return agent.toolError({ message: "Only shipped orders", orderId });
    }

    const refunded = await step.run("refund", async () => {
      return { orderId, amount: order.total };
    });

    await step.sendEvent("notify", {
      name: "order/refunded",
      data: refunded,
    });

    return refunded;
  },
});
```

## Return an error the model can read

`agent.toolError(body)` gives the model `body` as an error. A throw does the same with its message.

```typescript {{ title: "inngest/tools/getTicket.ts" }}
import { tool } from "inngest/experimental";
import { agent } from "inngest/experimental/agents";
import { z } from "zod";
import { db } from "../db";

export const getTicket = tool.step({
  input: z.object({ id: z.string() }),
  run: async ({ id }) => {
    const ticket = await db.tickets.find(id);

    return ticket ?? agent.toolError({ message: "No such ticket", id });
  },
});
```

## Pass tools to a loop

`agent.loop()` takes tools by name. `agentTools()` names a list by their `id`s and fails on two with one name.

```typescript {{ title: "inngest/agents/triage.ts" }}
import { agent, agentTools } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";
import { getCustomer } from "../tools/getCustomer";
import { listIssues } from "../tools/listIssues";

const tools = agentTools([getCustomer, listIssues]);

export const triage = agents.agent(
  { id: "triage" },
  async ({ inbox, control }) => {
    for await (const message of inbox) {
      await agent.loop({
        model: claude,
        prompt: message.data.content ?? "",
        tools,
        ...control,
      });
    }
  },
);
```

Spread in [`sandboxTools`](/docs/labs/agents/sandboxes?ref=docs-labs-agents-tools) too.

## Give the model JSON Schema

`input` also takes a JSON Schema object, for a schema you already hold as JSON. `run` gets the arguments unchecked.

```typescript {{ title: "inngest/tools/lookupSchema.ts" }}
import { tool } from "inngest/experimental";

export const lookup = tool.step({
  description: "Query a table",
  input: {
    type: "object",
    properties: { table: { type: "string" } },
    required: ["table"],
  },
  run: async ({ table }) => {
    return { table, rows: 0 };
  },
});
```

## Call your own model

`toolDefinitions()` gives the shape for a provider call outside the loop. It needs Zod 4 or Standard JSON Schema.

```typescript {{ title: "inngest/agents/definitions.ts" }}
import { toolDefinitions } from "inngest/experimental";
import { getOrder } from "../tools/getOrder";

export const definitions = toolDefinitions({ getOrder });
```

```json {{ title: "definitions" }}
[
  {
    "name": "getOrder",
    "description": "Find an order by ID",
    "input_schema": {
      "type": "object",
      "properties": { "id": { "type": "string" } },
      "required": ["id"]
    }
  }
]
```

## Let the model listen for events

Set `inboxTools` on an agent and the model can start listeners, wait on them and read what arrives. It only hears the sources you list.

<AnnotatedCode>

```typescript {{ title: "inngest/agents/releaseWatcher.ts" }}
import { agent } from "inngest/experimental/agents";
import { agents } from "../client";
import { claude } from "../models/claude";

export const releaseWatcher = agents.agent(
  {
    id: "release-watcher",
    inboxTools: {
      listen: [
        {
          event: "github/check_run",
          thread: "event.data.thread",
          if: "event.data.conclusion != 'neutral'",
          maxPerRun: 2,
        },
      ],
      maxListeners: 3,
      maxWait: "20m",
      maxTotalWait: "1h",
    },
  },
  async ({ inbox, inboxTools, control }) => {
    for await (const message of inbox) {
      await agent.loop({
        model: claude,
        prompt: message.data.content ?? "",
        tools: { ...inboxTools },
        ...control,
      });
    }
  },
);
```

## How it works

- Each call is one durable step. A group is a set of steps under the call's ID.
- Arguments are checked against `input` before a step starts.
- Calls in one reply run together. `parallelTools: false` runs them in order.
- A result over `maxToolOutput` (8000 characters) keeps its start and end.
