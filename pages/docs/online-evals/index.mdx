# Online Evals

> Find out whether your agent or workflow helped users by linking outcome scores to durable runs.

For example, a support agent can finish a run before a customer rates its answer. Online Evals links that later score to the run and experiment variant that produced the answer. Compare the new path with the current one, then open individual traces to explain the results.

## From execution to outcome

1. **Group related work with sessions.** Use a conversation, ticket, or job ID to find the runs behind one outcome.
2. **Score what you know.** Record a named numeric or true/false score for a run or step. Start with a guardrail result or a product outcome.
3. **Defer scoring when the result comes later.** Wait for feedback, a review, or a conversion. Inngest attributes the score to the original run.
4. **Test a change with ****`group.experiment()`****.** Put alternative steps or whole workflow paths in variant callbacks. Score the selected variant and compare outcomes.

You can score a run without an experiment. Add sessions and deferred scoring when the work spans runs or the outcome arrives later. Inngest's durable execution preserves the run, step, and variant context that connects an eventual score to the work behind it.
